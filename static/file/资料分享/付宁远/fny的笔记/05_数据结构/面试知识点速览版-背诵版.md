# 数据结构 - 面试背诵版（仅问题）

> [!tip]+ 使用方式
> 本文件**只列问题不列答案**，按 Q 重要度从高到低分组，专供背诵。
> 做题流程：
> 1. 默看问题，脑中尝试完整陈述答案（定义 + 条件 + 公式 + 对比 / 反例）。
> 2. 卡壳或答完后，去 [[面试知识点速览版]] 找对应 Q（用编号 `节.Q号` 定位，如 `1.1.Q1`）核对。
> 3. 带 **北航真题** 标记的是北航软院复试问过的题，务必能张口就来。
> 4. 每背出一题就打勾 ✅，没把握的保持空框，第二遍只看空框项。

> [!note] 评级与定位
> - **[⭐⭐⭐]** 高频 / 北航真题核心 → 第 1 轮必背
> - **[⭐⭐]** 中频 / 常用 → 第 2 轮复习
> - **[⭐]** 低频可救场 → 临考扫一遍
>
> 章节定位：`1.x = 薄弱点速攻`、`2.x = 线性结构`、`3.x = 哈希表`、`4.x = 树形结构`、`5.x = 图`、`6.x = 排序算法`、`7.x = 算法思想专题`、`8.x = C 语言基础（面试常问）`。编号与 [[面试知识点速览版]] 完全一致，可点对点互查。
>
> **第 1 章是自评薄弱点（速攻章）**，建议每一轮都从它开始背。

## 自测方法建议

> [!example]+ 三轮背诵法
> 1. **第 1 轮（⭐⭐⭐）**：先把这 67 题连背 3 次；卡壳 ≥ 3 次的题加入「卡点清单」，次日重背。
> 2. **第 2 轮（⭐⭐）**：过完这 37 题；重点区分**容易混的对比类**（Prim/Dijkstra、AVL/红黑树、B 树/B+ 树、栈/队列/堆、数组名/数组指针/指针数组、struct/union、稳定/不稳定排序）。
> 3. **第 3 轮（⭐）**：考前最后 30 分钟扫一遍这 2 题，能说出关键词即可。
>
> 自测时用三个角度各默想一遍：
> - **定义**：概念/术语的准确定义与公式（哈希、WPL、生成树、稳定排序、数组退化、静态存储期）；
> - **对比**：凡是「XX vs YY」都要能说出 3 条以上区别并点明**为什么**（Prim 与 Dijkstra 差在 `d[v]` 的含义、Dijkstra 为什么不能负权、Floyd 的 k 为什么必须在最外层、快排为什么不稳定）；
> - **复述**：凡是手写题都要能默出结构（并查集 `find`/`unite`、归并的 `merge`、堆的上浮下沉、变长参数的 `va_*` 四件套、C 模拟多态的函数指针表）。
