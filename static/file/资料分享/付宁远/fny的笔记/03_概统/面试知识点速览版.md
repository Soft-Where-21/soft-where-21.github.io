## 1. 随机事件与概率

### 1.1 概率的定义与条件概率 ⭐⭐

**Q [⭐⭐]【1.1.Q1】：概率有哪三种定义（三种概型）？**

A：

- **古典概型**：$P(A)=\frac{\text{有利事件数}}{\text{总事件数}}$，适用**有限个等可能**结果（掷骰子、抽牌）；
- **几何概型**：$P(A)=\frac{\text{有利区域度量}}{\text{总区域度量}}$，适用**无限等可能**，用长度/面积/体积比（随机落点）；
- **统计概型**：$P(A)=\frac{f_n(A)}{n}$，用**频率的稳定值**定义概率，依据是频率稳定性。

**Q [⭐⭐]【1.1.Q2】：条件概率的定义是什么？**

A：$P(A|B)=\frac{P(AB)}{P(B)}$（要求 $P(B)>0$）——"已知 $B$ 已发生"的前提下 $A$ 发生的概率。**理解**：$B$ 成为新的样本空间，把 $A$ 在 $B$ 中的占比重新归一化。由它得**乘法公式** $P(AB)=P(A|B)P(B)$，推广到 $n$ 个事件：$P(A_1\cdots A_n)=P(A_1)P(A_2|A_1)\cdots P(A_n|A_1\cdots A_{n-1})$。

### 1.2 全概率公式 ⭐⭐⭐【北航真题】

**Q [⭐⭐⭐]【1.2.Q1】：全概率公式和贝叶斯公式分别是什么？（北航真题）**

A：

- **全概率公式**：$P(B)=\sum_{i=1}^{n}P(B|A_i)P(A_i)$——**分情况讨论**，把 $B$ 的概率拆成"在各种原因 $A_i$ 下发生"的**加权平均**，权重是先验 $P(A_i)$；
- **贝叶斯公式**：$P(A_i|B)=\frac{P(B|A_i)P(A_i)}{\sum_{j}P(B|A_j)P(A_j)}$——**由果推因**，已知结果 $B$ 反推原因 $A_i$ 的概率，分母正是全概率公式；
- 一句话记忆：**后验 = 似然 × 先验 / 归一化常数**。

**Q [⭐⭐⭐]【1.2.Q2】：全概率公式成立的条件是什么？（北航真题）**

A：

1. $A_1,\dots,A_n$ 构成**完备事件组（划分）**：两两互斥 $A_iA_j=\varnothing$，且 $\bigcup_{i=1}^{n}A_i=\Omega$——**既互斥、又穷尽**；
2. 每个 $P(A_i)>0$（保证分母不为零）；
3. $B$ 是同一概率空间中的任一事件。

不满足"互斥且穷尽"就**不能直接用**；若只知若干个互斥事件而没覆盖全空间，可补上剩余部分 $A_{n+1}=\Omega-\bigcup_{i\leq n}A_i$ 再用。贝叶斯公式额外要求 $P(B)>0$。

### 1.3 贝叶斯公式与先验/后验 ⭐⭐⭐【北航真题】

**Q [⭐⭐⭐]【1.3.Q1】：贝叶斯公式是什么？为什么要用它？（北航真题）**

A：$P(A_i|B)=\frac{P(B|A_i)P(A_i)}{\sum_{j}P(B|A_j)P(A_j)}$。**为什么要用**：实际中我们往往知道"**原因导致结果**"的概率（$P(B|A_i)$，容易测量），却想知道"**结果反推原因**"的概率（$P(A_i|B)$）——贝叶斯公式就是把前者转成后者的桥梁。它也是**贝叶斯学派**的起点：承认参数有先验，用数据不断修正信念。

**Q [⭐⭐⭐]【1.3.Q2】：贝叶斯公式有什么应用？（北航真题）**

A：

- **疾病检测（假阳性悖论）**：患病率 0.1%、检测灵敏度 99%、特异度 99%，一人查出阳性后**真实患病概率只有约 9%**——因为先验极低，大量假阳性把后验压了下去；
- **垃圾邮件分类**：朴素贝叶斯用"词语 → 邮件类别"的后验判断是否为垃圾邮件；
- **拼写纠错 / 语音识别**：候选答案 = 先验（语言模型/词典）× 似然（编辑/声学模型），取后验最大者；
- **贝叶斯统计与机器学习**：把参数视为随机变量，先验 → 后验，用于参数估计、贝叶斯网络、贝叶斯优化。

**Q [⭐⭐⭐]【1.3.Q3】：先验概率和后验概率是什么？两者的关系？**

A：

| | 先验概率 $P(A_i)$ | 后验概率 $P(A_i\lvert B)$ |
| -- | -- | -- |
| 含义 | 观测数据**之前**对原因的判断 | 观测到 $B$ **之后**修正过的判断 |
| 来源 | 经验、历史数据或主观设定 | 由贝叶斯公式算出 |
| 作用 | 贝叶斯公式的**输入** | 贝叶斯公式的**输出** |

关系：**后验 ∝ 似然 × 先验**，即 $P(A_i|B)\propto P(B|A_i)P(A_i)$。一句话：**先验代表已有信念，数据（似然）负责修正它。**

### 1.4 互斥、独立、相关 ⭐⭐⭐【北航真题】

**Q [⭐⭐⭐]【1.4.Q1】：独立性、相关性、互斥性有什么区别？（北航真题）**

A：

| 概念 | 定义 | 关键区别 |
| -- | -- | -- |
| **互斥** | $AB=\varnothing$ | 不可能同时发生，$P(AB)=0$；是**事件**层面的关系 |
| **独立** | $P(AB)=P(A)P(B)$ | 一个发生不影响另一个；是**概率**层面的关系 |
| **相关** | $\rho_{XY}\neq0$ | 随机变量之间有**线性**关系 |

三条要点：

- **互斥 ≠ 独立**：在 $P(A)>0,P(B)>0$ 时，互斥事件一定**不**独立（因为 $P(AB)=0\neq P(A)P(B)$）；
- **独立 → 不相关，但不相关不一定独立**（可能只有非线性关系）；
- **例外**：二维正态下 不相关 $\iff$ 独立。

**Q [⭐⭐]【1.4.Q2】：为什么"互斥"和"独立"在概率非 0 时矛盾？**

A：互斥给出的是"一个发生则另一个**必不发生**"——这恰恰是强相关（负相关）的信息：知道 $A$ 就推翻了 $B$；而独立要求"知道 $A$ **不改变** $B$ 的概率"。前提 $P(A)P(B)>0$，故 $P(A)P(B)\neq0=P(AB)$，二者不可能同时成立（除非其中至少一个概率为 0）。

## 2. 随机变量及其分布

### 2.1 随机变量与离散/连续 ⭐⭐

**Q [⭐⭐]【2.1.Q1】：什么是随机变量？它的分布函数如何定义？**

A：随机变量 $X$ 是**样本空间到实数的映射** $X:\Omega\to\mathbb{R}$——把随机结果"数值化"，从而能用微积分等工具处理。其**分布函数** $F(x)=P(X\leq x),\ x\in\mathbb{R}$，是对随机变量概率规律**最完整**的描述（离散型、连续型都适用）。

**Q [⭐⭐]【2.1.Q2】：离散型和连续型随机变量的描述方式有什么不同？**

A：

| | 离散型 | 连续型 |
| -- | -- | -- |
| 描述工具 | 分布律 $P(X=x_k)=p_k$ | 概率密度 $f(x)$，$F(x)=\int_{-\infty}^{x}f(t)dt$ |
| 取值 | 有限或可列 | 不可列（区间） |
| 单点概率 | $P(X=x_k)=p_k$（可以 $>0$） | $P(X=x_0)=0$（**连续型单点概率为 0**） |

**Q [⭐⭐]【2.1.Q3】："连续型随机变量取单点的概率为 0"，能否推出该点不可能发生？**

A：**不能**。"不可能事件 $\Rightarrow$ 概率为 0"成立，**反之不成立**——连续型随机变量取任意单点的概率都是 0，但每个点都可能被取到。由此可得实用结论：算区间概率时**端点无所谓**，$P(a<X<b)=P(a\leq X\leq b)=P(a<X\leq b)$。

### 2.2 分布函数 vs 概率密度 ⭐⭐⭐

**Q [⭐⭐⭐]【2.2.Q1】：概率分布函数和概率密度函数的定义和区别？**

A：

- **分布函数（CDF）**：$F(x)=P(X\leq x)$，**一切**随机变量（离散/连续）都有；
- **概率密度（PDF）**：只对**连续型**随机变量存在，是非负可积函数，满足 $F(x)=\int_{-\infty}^{x}f(t)dt$。

|      | 分布函数 $F(x)$                            | 概率密度 $f(x)$                                    |
| ---- | -------------------------------------- | ---------------------------------------------- |
| 存在范围 | 一切随机变量                                 | 仅连续型随机变量                                       |
| 取值含义 | 是概率 $P(X\leq x)$，必在 $[0,1]$            | **不是概率**，$f(x)$ 可以大于 1                         |
| 算概率  | $P(a<X\leq b)=F(b)-F(a)$               | $P(a<X\leq b)=\int_a^b f(x)dx$                 |
| 基本性质 | 单调不减、右连续、$F(-\infty)=0$、$F(+\infty)=1$ | $f(x)\geq0$，$\int_{-\infty}^{+\infty}f(x)dx=1$ |

关系：$F$ 是 $f$ 的**积分**，$f$ 是 $F$ 的**导数**（在 $f$ 的连续点处）。

**Q [⭐⭐]【2.2.Q2】：为什么概率密度的值可以大于 1？**

A：密度是"**单位长度上的概率**"（概率的密度），量纲是"每单位 $x$"，本身不是概率。例如 $X\sim U(0,0.5)$ 时 $f(x)=2>1$，但积分 $\int_0^{0.5}2\,dx=1$，任何区间的概率都不会超过 1。同理，密度的量纲取决于 $x$ 的单位（换成厘米密度值会变），只有**积分后**才是真正的概率。

### 2.3 连续型分布函数是否处处可导 ⭐⭐⭐

**Q [⭐⭐⭐]【2.3.Q1】：连续型随机变量的分布函数是不是处处可导？**

A：**不一定**。

- 连续型随机变量的 $F(x)$ **一定连续**，但**不一定处处可导**——**只保证在密度 $f(x)$ 的连续点处可导**，且 $F'(x)=f(x)$；
- 在 $f$ 的**间断点处 $F$ 不可导**（左右导数不相等）。例：均匀分布 $U(a,b)$ 的 $F$ 在 $x=a$ 和 $x=b$ 处就不可导；
- 反过来，若 $F$ **处处可导**，则密度必为 $F'(x)$；另外**改动 $f$ 在有限个点上的取值不影响分布**，所以密度**不唯一**；
- （对比）**离散型**的 $F$ 是**阶梯函数**，在跳跃点处同样不可导。

### 2.4 常用概率分布 ⭐⭐⭐【北航真题】

**Q [⭐⭐⭐]【2.4.Q1】：有哪些常用的概率分布？（北航真题：常见分布）**

A：**离散型**：0-1 分布、二项分布 $B(n,p)$、超几何分布 $H(N,M,n)$、泊松分布 $P(\lambda)$；**连续型**：均匀分布 $U(a,b)$、指数分布 $Exp(\lambda)$、正态分布 $N(\mu,\sigma^2)$。

| 分布 | 概率/密度 | 期望 | 方差 | 典型场景 |
| -- | -- | -- | -- | -- |
| 0-1 分布 | $P(X=k)=p^k(1-p)^{1-k}$ | $p$ | $p(1-p)$ | 一次伯努利试验 |
| 二项 $B(n,p)$ | $P(X=k)=C_n^kp^k(1-p)^{n-k}$ | $np$ | $np(1-p)$ | $n$ 次独立重复试验 |
| 超几何 $H(N,M,n)$ | $P(X=k)=\frac{C_M^kC_{N-M}^{n-k}}{C_N^n}$ | $\frac{nM}{N}$ | $n\frac{M}{N}(1-\frac{M}{N})\frac{N-n}{N-1}$ | 无放回抽样的命中数 |
| 泊松 $P(\lambda)$ | $P(X=k)=\frac{\lambda^ke^{-\lambda}}{k!}$ | $\lambda$ | $\lambda$ | 稀有事件计数 |
| 均匀 $U(a,b)$ | $f(x)=\frac{1}{b-a}$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ | 等可能取值 |
| 指数 $Exp(\lambda)$ | $f(x)=\lambda e^{-\lambda x}\ (x>0)$ | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ | 寿命、等待时间 |
| 正态 $N(\mu,\sigma^2)$ | $f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$ | $\sigma^2$ | 万能分布（CLT） |

**Q [⭐⭐⭐]【2.4.Q2】：二项分布的定义和实际应用是什么？**

A：**定义**：$n$ 次**独立**重复的伯努利试验中成功次数 $X\sim B(n,p)$，$P(X=k)=C_n^kp^k(1-p)^{n-k}$，$E(X)=np$，$D(X)=np(1-p)$。**应用**：抛 $n$ 次硬币的正面数、一批产品抽检的合格数、$n$ 次投篮命中数、$n$ 个用户中下单的人数。**要点**：二项要求"**独立 + 每次成功概率不变**"，一旦无放回抽样（各次不再独立）就变成超几何分布。

**Q [⭐⭐⭐]【2.4.Q3】：泊松分布的定义和实际应用是什么？**

A：**定义**：$P(X=k)=\frac{\lambda^ke^{-\lambda}}{k!}$，$E(X)=D(X)=\lambda$，描述**单位时间/空间内稀有事件发生的次数**。**应用**：单位时间电话呼叫数、网站访问量、放射性衰变计数、排队论中的到达过程、交通事故数。**与二项的关系**：泊松定理——$n$ 大、$p$ 小、$np=\lambda$ 适中时 $B(n,p)\approx P(\lambda)$（稀有事件近似）。

**Q [⭐⭐]【2.4.Q4】：超几何分布的定义是什么？与二项分布有什么区别？**

A：**定义**：$N$ 个个体中有 $M$ 个"目标"，**不放回**抽取 $n$ 个，其中目标数 $X\sim H(N,M,n)$，$P(X=k)=\frac{C_M^kC_{N-M}^{n-k}}{C_N^n}$，$E(X)=n\frac{M}{N}$，$D(X)=n\frac{M}{N}(1-\frac{M}{N})\frac{N-n}{N-1}$。**与二项的区别**：二项是**有放回**（各次独立、概率恒为 $p$），超几何是**无放回**（各次不独立）；当 $N$ 很大、$n$ 相对很小时超几何**趋近**二项（校正因子 $\frac{N-n}{N-1}\to1$）。**典型场景**：从一批产品中不放回抽检的次品数、彩票中奖个数。

**Q [⭐⭐⭐]【2.4.Q5】：指数分布的定义和实际应用是什么？什么是无记忆性？**

A：**定义**：$f(x)=\lambda e^{-\lambda x}(x>0)$，$F(x)=1-e^{-\lambda x}$，$E(X)=\frac{1}{\lambda}$，$D(X)=\frac{1}{\lambda^2}$；$\lambda$ 是单位时间发生次数，$\frac{1}{\lambda}$ 是平均等待时间。**应用**：元件寿命、服务台排队等待时间、放射性衰变的时间间隔。**无记忆性**：$P(X>s+t|X>s)=P(X>t)$——已正常工作 $s$ 小时，再撑 $t$ 小时的概率"和新的一样"，过去的运行历史不提供任何信息；**指数分布是唯一具有无记忆性的连续分布**（离散型中泊松分布/几何分布具有对应性质）。

**Q [⭐⭐⭐]【2.4.Q6】：正态分布的定义和实际应用是什么？**

A：**定义**：$X\sim N(\mu,\sigma^2)$，$f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$，$E(X)=\mu$，$D(X)=\sigma^2$，图像是**关于 $\mu$ 对称的钟形曲线**；标准化后 $\frac{X-\mu}{\sigma}\sim N(0,1)$，可查表算概率（如 $3\sigma$ 原则：约 99.7% 落在 $\mu\pm3\sigma$）。**应用**：测量误差、身高体重、考试成绩、金融收益率。**为什么这么普遍**：由 CLT，大量独立同分布随机变量之和近似正态，所以它被称为"**万能分布**"。

**Q [⭐⭐⭐]【2.4.Q7】：二项分布、正态分布、指数分布、泊松分布之间有什么联系？**

A：

- **二项 → 泊松**：$n$ 大、$p$ 小、$np=\lambda$ 适中时 $B(n,p)\approx P(\lambda)$（稀有事件近似）；
- **二项 → 正态**：$n$ 大时由**棣莫弗-拉普拉斯**定理 $B(n,p)\approx N(np,np(1-p))$；
- **泊松 ↔ 指数**：同一**泊松过程**的两种视角——泊松描述"单位时间事件的**次数**"，指数描述"两次事件之间的**等待时间**"；
- **超几何 ↔ 二项**：无放回 vs 有放回，$N$ 大时超几何趋近二项；
- **正态是终点**：CLT 使大量独立同分布之和近似正态，它是其余分布的"共同极限"。

**Q [⭐]【2.4.Q8】：均匀分布的定义、期望方差是什么？**

A：$X\sim U(a,b)$，$f(x)=\frac{1}{b-a}$（区间内为常数，区间外为 0），$E(X)=\frac{a+b}{2}$，$D(X)=\frac{(b-a)^2}{12}$。"均匀"指落在 $[a,b]$ 内**等长子区间**的概率相等；它是取整误差、随机数生成、等可能落点的模型。

## 3. 二维随机变量

### 3.1 联合、边缘、条件 ⭐⭐⭐

**Q [⭐⭐⭐]【3.1.Q1】：条件概率、联合概率、边缘概率的定义和区别？**

A：

| 概率类型     | 记法                                           | 含义                   | 特征            |
| -------- | -------------------------------------------- | -------------------- | ------------- |
| **联合概率** | $P(X=x,Y=y)$                                 | 两个变量**同时**取某值        | 描述整体，信息最完整    |
| **边缘概率** | $P(X=x)=\sum_y P(X=x,Y=y)$                   | 只关心 $X$，把 $Y$ 累加/积分掉 | 由联合分布"投影"得到   |
| **条件概率** | $P(X=x\lvert Y=y)=\frac{P(X=x,Y=y)}{P(Y=y)}$ | 已知 $Y=y$ 后 $X$ 的概率   | 信息更多，重新划定样本空间 |

关系链：**联合 = 边缘 × 条件**（乘法公式）；若 $X,Y$ **独立**，则 **联合 = 边缘 × 边缘**，此时条件 = 边缘。

**Q [⭐⭐]【3.1.Q2】：联合分布、边际分布、条件分布是什么关系？**

A：**联合分布** $F(x,y)=P(X\leq x,Y\leq y)$ 描述两个变量的整体概率规律；**边际分布** $F_X(x)=F(x,+\infty)$ 是"**积分掉**另一个变量"后的投影，信息**变少**；**条件分布** $F_{X|Y}(x|y)=\frac{F(x,y)}{F_Y(y)}$ 是在 $Y$ 固定的切片上重新归一化，信息**更聚焦**。三者与概率层面一一对应：联合 = 边缘 × 条件。

### 3.2 独立性判断 ⭐⭐⭐

**Q [⭐⭐⭐]【3.2.Q1】：如何判断两个随机变量是否独立？**

A：$X,Y$ 独立 $\iff F(x,y)=F_X(x)F_Y(y)$ 对**一切** $x,y$ 成立；连续型等价于 $f(x,y)=f_X(x)f_Y(y)$，离散型等价于 $p_{ij}=p_i\cdot p_j$。注意必须是"**对一切点**成立"，**只要有一个点不成立就不独立**——常见反例是联合密度只在三角形区域上非零，此时边缘相乘无法还原联合。

**Q [⭐⭐]【3.2.Q2】：为什么"不相关不一定独立"？请举反例。**

A：独立是**概率层面**（联合 = 边缘乘积），不相关只是**线性**层面（$\rho=0$，等价于 $\text{Cov}(X,Y)=0$、$E(XY)=E(X)E(Y)$）。**反例**：$X\sim U(-1,1)$，$Y=X^2$——$E(XY)=E(X^3)=0=E(X)E(Y)$，故不相关；但 $Y$ 完全由 $X$ 决定，显然不独立。**例外**：二维正态下 $\rho=0\iff$ 独立，因为正态分布完全由一阶、二阶矩决定。

## 4. 数字特征

### 4.1 期望与方差 ⭐⭐⭐【北航真题】

**Q [⭐⭐⭐]【4.1.Q1】：期望和方差的定义是什么？（北航真题）**

A：

- **期望**（数学期望/均值）：离散型 $E(X)=\sum_k x_kp_k$；连续型 $E(X)=\int_{-\infty}^{+\infty}xf(x)dx$——描述随机变量的**中心位置**，可理解为"以概率为权的加权平均"或"重心"；
- **方差**：$D(X)=E\big[(X-E(X))^2\big]$，计算常用公式 $D(X)=E(X^2)-[E(X)]^2$——描述**离散程度**，即取值相对均值的平均平方偏离；
- 直观：期望是"平均水平"，方差是"波动大小"；$D(X)\geq0$，且 $D(X)=0\iff X$ 几乎处处取常数。

**Q [⭐⭐]【4.1.Q2】：什么是标准差？它和方差有什么区别？**

A：**标准差** $\sigma_X=\sqrt{D(X)}$。区别：标准差与 $X$ **同量纲**（方差是平方量纲，例如数据单位是米则方差单位是"米²"），所以描述离散程度时更直观、更便于比较；正态分布 $N(\mu,\sigma^2)$ 中那个 $\sigma$ 就是标准差。

**Q [⭐⭐⭐]【4.1.Q3】：期望和方差有哪些常用性质？**

A：

- **期望无条件线性**：$E(aX+bY)=aE(X)+bE(Y)$，$E$ 与求和可交换；
- **期望可乘需条件**：$E(XY)=E(X)E(Y)$ 只在独立（或至少不相关）时成立；
- **方差平移不变、缩放平方**：$D(aX+b)=a^2D(X)$（常数项 $b$ 不影响力度的波动）；
- **和差公式**：$D(aX+bY)=a^2D(X)+b^2D(Y)+2ab\,\text{Cov}(X,Y)$；独立（不相关）时退化为 $D(X+Y)=D(X)+D(Y)$；
- **常用特例**：$E(X^2)=D(X)+[E(X)]^2$；$D(\bar X)=\frac{\sigma^2}{n}$（样本均值的方差随 $n$ 减小）。

### 4.2 协方差、协方差矩阵与相关系数 ⭐⭐⭐

**Q [⭐⭐⭐]【4.2.Q1】：什么是协方差？什么是协方差矩阵？**

A：

- **协方差**：$\text{Cov}(X,Y)=E\big[(X-E(X))(Y-E(Y))\big]=E(XY)-E(X)E(Y)$，衡量两个变量**线性关联的方向**：正 → 同增同减，负 → 反向变化，0 → 不相关；
- **协方差矩阵**：对 $n$ 维随机向量 $X=(X_1,\dots,X_n)^T$，$\Sigma=\text{Cov}(X)=E\big[(X-EX)(X-EX)^T\big]$，其第 $(i,j)$ 元为 $\text{Cov}(X_i,X_j)$，**对角线上是各分量的方差** $\Sigma_{ii}=D(X_i)$；
- **性质**：对称、**半正定**；
- **用途**：多元正态 $N(\mu,\Sigma)$ 的核心参数、PCA（对 $\Sigma$ 做特征分解找主方向）、卡尔曼滤波、投资组合风险。

**Q [⭐⭐⭐]【4.2.Q2】：协方差与方差有什么关系？协方差有哪些性质？**

A：**关系**：$D(X)=\text{Cov}(X,X)$——**方差是协方差"自己与自己"的特例**，协方差是方差的推广；协方差矩阵的对角元也正好是各方差，所以可以说"协方差矩阵是方差的多维版本"。**性质**：

- **对称性**：$\text{Cov}(X,Y)=\text{Cov}(Y,X)$；
- **双线性**：$\text{Cov}(aX+b,cY+d)=ac\,\text{Cov}(X,Y)$，$\text{Cov}(X_1+X_2,Y)=\text{Cov}(X_1,Y)+\text{Cov}(X_2,Y)$；
- $\text{Cov}(X,X)=D(X)\geq0$；常数与任何变量的协方差为 0。

**Q [⭐⭐]【4.2.Q3】：相关系数是什么？取值范围和意义是什么？**

A：$\rho_{XY}=\frac{\text{Cov}(X,Y)}{\sqrt{D(X)D(Y)}}$——把协方差**标准化**、消去量纲，衡量**线性关联的强度**。性质：$\lvert\rho\rvert\leq1$；$\lvert\rho\rvert=1\iff Y=aX+b$ 几乎必然成立（完全线性）；$\rho=0$ 称为**不相关**。**注意**：相关系数只刻画**线性**关系，$\rho=0$ 仍可能存在很强的非线性依赖（如 $Y=X^2$）。

## 5. 大数定律与中心极限定理 ⭐⭐⭐【北航真题】

### 5.1 大数定律 ⭐⭐⭐【北航真题】

**Q [⭐⭐⭐]【5.1.Q1】：大数定律的定义是什么？（北航真题）**

A：**辛钦大数定律**（面试最常考）：设 $X_1,X_2,\dots$ 独立同分布，$E(X_i)=\mu$ 存在，则样本均值**依概率收敛**于 $\mu$：

$$\bar{X}_n=\frac{1}{n}\sum_{i=1}^{n}X_i\xrightarrow{P}\mu$$

即 $\forall\varepsilon>0,\ \lim_{n\to\infty}P(\lvert\bar{X}_n-\mu\rvert<\varepsilon)=1$。**含义**：$n$ 很大时"**平均趋于期望**"，这是"**频率稳定于概率**"的理论基础——偶然中蕴含必然。

**Q [⭐⭐]【5.1.Q2】：伯努利大数定律说的是什么？**

A：$n$ 重独立重复试验，单次成功概率为 $p$，$n_A$ 为 $n$ 次试验的成功总次数，则频率 $\frac{n_A}{n}\xrightarrow{P}p$——即**频率依概率收敛于概率**。它是辛钦大数定律在 $X_i\sim B(1,p)$ 时的特例，也是"用频率估计概率"的合法性依据。

**Q [⭐⭐]【5.1.Q3】：依概率收敛和依分布收敛有什么区别？**

A：**依概率收敛**（$\xrightarrow{P}$）：$\forall\varepsilon>0$，$P(\lvert X_n-X\rvert>\varepsilon)\to0$——"$X_n$ 远离 $X$ 的可能性趋于 0"，说的是**随机变量本身**越来越近；**依分布收敛**（$\xrightarrow{d}$）：分布函数逐点收敛 $F_n(x)\to F(x)$——只说"**分布形状**趋同"，不要求随机变量接近。关系：$X_n\xrightarrow{P}X\Rightarrow X_n\xrightarrow{d}X$（反之不成立，除非 $X$ 为常数）。大数定律用前者，CLT 用后者。

### 5.2 中心极限定理 ⭐⭐⭐【北航真题】

**Q [⭐⭐⭐]【5.2.Q1】：中心极限定理的定义是什么？（北航真题）**

A：**独立同分布 CLT（林德伯格-列维）**：设 $X_1,X_2,\dots$ 独立同分布，$E(X_i)=\mu$，$D(X_i)=\sigma^2>0$，则

$$\frac{\sum_{i=1}^{n}X_i-n\mu}{\sigma\sqrt{n}}\xrightarrow{d}N(0,1)$$

等价地：$\sum_{i=1}^{n}X_i$ 近似服从 $N(n\mu,n\sigma^2)$，样本均值 $\bar{X}_n$ 近似服从 $N(\mu,\frac{\sigma^2}{n})$。**含义**：$n$ 个独立同分布随机变量之**和**，标准化后近似标准正态——**不管原来服从什么分布**；这正是正态分布如此普遍的根源，也是区间估计、假设检验的理论基础。

**Q [⭐⭐⭐]【5.2.Q2】：大数定律和中心极限定理有什么区别和联系？**

A：**区别**：大数定律说"**平均趋于期望**"（依概率收敛，讲极限**值**）；CLT 说"**和（标准化后）趋于正态**"（依分布收敛，讲分布**形状**）。**联系**：二者都是独立同分布序列的极限刻画，都需要期望/方差存在；大数定律给出"平均值稳定"的一阶结论，CLT 进一步刻画了**波动的大小与形状**；它们共同构成统计推断的两大支柱——有了保证，第 6–8 章才敢用样本推断总体。

**Q [⭐⭐]【5.2.Q3】：什么是棣莫弗-拉普拉斯定理？**

A：它是 CLT 在二项分布上的特例：若 $X\sim B(n,p)$，$n$ 大时 $\frac{X-np}{\sqrt{np(1-p)}}\xrightarrow{d}N(0,1)$，即 $B(n,p)\approx N(np,np(1-p))$——这就是**二项分布的正态近似**，也解释了"抛 1000 次硬币，正面数近似正态分布"。

## 6. 数理统计基础

### 6.1 统计量与抽样分布 ⭐⭐⭐

**Q [⭐⭐⭐]【6.1.Q1】：什么是统计量？什么是抽样分布？**

A：**统计量**是**样本的函数**，且**不含任何未知参数**（如 $\bar X$、$S^2$、$\max X_i$ 都是统计量，而 $\frac{X_1-\mu}{\sigma}$ 不是）。**抽样分布**指统计量作为随机变量的分布（如 $\bar X\sim N(\mu,\frac{\sigma^2}{n})$），它是"用样本推断总体"的计算工具。

**Q [⭐⭐⭐]【6.1.Q2】：为什么样本方差要除以 $n-1$ 而不是 $n$？**

A：因为 $\bar X$ 本身就是用样本算出来的，它比真值 $\mu$ "更贴合"这组样本，导致 $\sum(X_i-\bar X)^2$ 系统性偏小：

$$E\left[\frac{1}{n}\sum_{i=1}^{n}(X_i-\bar X)^2\right]=\frac{n-1}{n}\sigma^2<\sigma^2$$

**除以 $n-1$ 恰好把这个偏差补回来**，使 $E(S^2)=\sigma^2$（**无偏性**）。**自由度解释**：$n$ 个偏差满足约束 $\sum(X_i-\bar X)=0$，只有 $n-1$ 个可以自由变化。

**Q [⭐⭐]【6.1.Q3】：三大抽样分布是什么？各有什么用途？**

A：

| 分布 | 构造 | 典型用途 |
| -- | -- | -- |
| **$\chi^2(n)$** | $n$ 个标准正态的平方和 | 方差估计、卡方检验（拟合优度、独立性） |
| **$t(n)$** | $\frac{N(0,1)}{\sqrt{\chi^2(n)/n}}$ | 小样本均值检验与区间估计（$n<30$、$\sigma$ 未知） |
| **$F(n_1,n_2)$** | 两个独立 $\chi^2$ 之比 $\frac{W_1/n_1}{W_2/n_2}$ | 两方差比较、方差分析（ANOVA） |

补充：$n$ 大时 $t(n)\to N(0,1)$；$\chi^2(n)$ 的 $E=n$、$D=2n$。

## 7. 参数估计

### 7.1 点估计与矩估计 ⭐⭐

**Q [⭐⭐]【7.1.Q1】：什么是点估计？矩估计的思想是什么？**

A：**点估计**是用样本算出的**一个数值** $\hat\theta$ 去估计总体未知参数 $\theta$（对照：区间估计给的是一个**区间**）。**矩估计**的思想是"**用样本矩替代总体矩**"：令 $E(X^k)=\frac{1}{n}\sum_iX_i^k$（$k=1,2,\dots$），解方程即得参数估计；它**不需要假定分布形式**，通用、计算简单，但不够精细（只用了矩信息）。

### 7.2 最大似然估计 ⭐⭐⭐【北航真题】

**Q [⭐⭐⭐]【7.2.Q1】：最大似然估计的思想是什么？（北航真题）**

A：已知这组样本**已经发生**了——那就选一个参数，使**这组样本出现的概率最大**："**既然发生了，它就该是最可能的**"。形式化：构造似然函数 $L(\theta)=\prod_{i=1}^{n}f(x_i;\theta)$（离散型用 $\prod_iP(X=x_i;\theta)$），取 $\hat\theta=\arg\max_\theta L(\theta)$。

**Q [⭐⭐⭐]【7.2.Q2】：最大似然估计的步骤是什么？**

A：

1. 写出**似然函数** $L(\theta)=\prod_{i=1}^{n}f(x_i;\theta)$；
2. 取**对数** $\ln L(\theta)=\sum_i\ln f(x_i;\theta)$（化乘为加，便于求导；对数单调故极值点不变）；
3. 对 $\theta$ **求导**并令 $\frac{d\ln L}{d\theta}=0$（**对数似然方程**）；
4. 解出 $\hat\theta$，并验证（或由二阶导/单调性说明）确实是极大值点。

**Q [⭐⭐]【7.2.Q3】：最大似然估计和矩估计有什么区别？**

A：**矩估计**只用一二阶矩的信息、**不需要知道分布形式**，计算简单、直观；**MLE** 需要知道**分布形式**、利用整个似然函数的信息，通常**更有效**（渐近方差更小），且具有一致性、渐近正态性等优良性质；代价是可能无解析解（要数值优化），且**可能是有偏的**（如正态方差的 MLE $\frac1n\sum(X_i-\bar X)^2$ 就有偏）。

### 7.3 无偏估计与有偏估计 ⭐⭐⭐

**Q [⭐⭐⭐]【7.3.Q1】：无偏估计和有偏估计的定义是什么？**

A：

- **无偏估计**：$E(\hat\theta)=\theta$——反复抽样、每次都算估计值，这些估计值的**平均**恰好等于真参数，**没有系统偏差**；
- **有偏估计**：$E(\hat\theta)\neq\theta$，偏差量 $\text{bias}(\hat\theta)=E(\hat\theta)-\theta$（可正可负）；
- **典型例子**：样本二阶中心矩 $B_2=\frac{1}{n}\sum(X_i-\bar X)^2$ 估计 $\sigma^2$ 是**有偏**的，$E(B_2)=\frac{n-1}{n}\sigma^2<\sigma^2$（系统性偏小），改成除以 $n-1$ 才无偏；
- **补充**："无偏"不等于"最好"——均方误差 $\text{MSE}(\hat\theta)=D(\hat\theta)+[\text{bias}(\hat\theta)]^2$，若一个稍偏的估计方差小很多，总误差可能更低（如岭回归、收缩估计就是"用一点偏差换更小的方差"）。

**Q [⭐⭐]【7.3.Q2】：评价估计量好坏的标准有哪些？**

A：

| 标准 | 含义 | 记忆 |
| -- | -- | -- |
| **无偏性** | $E(\hat\theta)=\theta$ | 没有系统偏差 |
| **有效性** | 同为无偏时，方差越小越有效 | 更集中 = 更好 |
| **一致性（相合性）** | $n\to\infty$ 时 $\hat\theta\xrightarrow{P}\theta$ | 样本越多越准 |

### 7.4 区间估计 ⭐⭐

**Q [⭐⭐]【7.4.Q1】：什么是置信区间？怎么正确理解 $1-\alpha$？**

A：区间估计给出一个**随机区间** $(\hat\theta_L,\hat\theta_U)$ 使 $P(\hat\theta_L<\theta<\hat\theta_U)=1-\alpha$（$\alpha$ 通常取 0.05 或 0.01）。**正确理解**：$\theta$ 是**固定的未知常数**，**区间才是随机的**——"重复抽样很多次、每次算一个区间，大约有 $1-\alpha$ 比例的区间能**覆盖**真参数"；**不能**说"参数有 95% 的概率落在这个区间里"。参数未知时用 $t$ 分布（$\sigma$ 未知、小样本），$n$ 大时用 $Z$ 近似。

### 7.5 最小二乘法 ⭐⭐

**Q [⭐⭐]【7.5.Q1】：最小二乘法的思想与过程是什么？**

A：**思想**：给定数据 $(x_i,y_i)$，选参数使预测值与实测值的**残差平方和最小**——用平方是为了避免正负残差相消、并对大误差惩罚更重：

$$Q(\theta)=\sum_{i=1}^{n}\big(y_i-f(x_i;\theta)\big)^2\to\min$$

**过程（线性最小二乘）**：

1. 设线性模型 $Y=X\beta+\varepsilon$（$X$ 为设计矩阵，多项式拟合时即范德蒙德矩阵）；
2. 写出目标函数 $Q(\beta)=\lVert Y-X\beta\rVert^2$；
3. 对 $\beta$ 求导并令其为零 → **正规方程** $X^TX\beta=X^TY$；
4. 解出 $\hat\beta=(X^TX)^{-1}X^TY$（$X^TX$ 可逆时）。

**统计意义（加分点）**：在 $E(\varepsilon)=0$、$\text{Cov}(\varepsilon)=\sigma^2I$ 下，由 **Gauss-Markov 定理**它是最佳线性无偏估计（BLUE）；当 $\varepsilon\sim N(0,\sigma^2I)$ 时，**最小二乘 = 最大似然估计**；几何上 $\hat{Y}$ 是 $Y$ 在 $X$ 列空间上的**正交投影**，残差与列空间垂直。

## 8. 假设检验

### 8.1 基本思想与两类错误 ⭐⭐⭐

**Q [⭐⭐⭐]【8.1.Q1】：假设检验的基本思想是什么？步骤是什么？**

A：核心是**证伪而非证实**——先设立**原假设 $H_0$**（如"无罪推定"），在 $H_0$ 成立的前提下考察样本是否"极端到反常"，若落入**拒绝域**就拒绝 $H_0$（依据**小概率原理**：小概率事件在一次试验中几乎不发生）。**步骤**：建立 $H_0/H_1$ → 选取检验统计量（$Z/t/\chi^2/F$）→ 由显著性水平 $\alpha$ 确定拒绝域 → 用样本计算并作判断。它可以看作区间估计的"镜像"。

**Q [⭐⭐⭐]【8.1.Q2】：什么是两类错误？它们的关系是什么？**

A：

| 错误类型 | 含义 | 概率 | 类比 |
| -- | -- | -- | -- |
| 第一类错误（**弃真**） | $H_0$ 为真却拒绝 | $\alpha$（显著性水平） | 冤枉好人 |
| 第二类错误（**取伪**） | $H_0$ 为假却接受 | $\beta$ | 放过坏人 |

**关系**：样本量固定时二者**此消彼长**，不能同时减小；**Neyman-Pearson 原则**是先控制 $\alpha$，再尽量减小 $\beta$；$1-\beta$ 称为检验的**功效**；**增大样本量**才能同时改善两者。

## 9. 随机过程初步

### 9.1 马尔可夫链 ⭐⭐

**Q [⭐⭐]【9.1.Q1】：马尔可夫链的定义是什么？核心性质是什么？**

A：设随机过程 $\{X_n\}$ 的**状态空间 $S$** 是有限集或可列集，若对任意 $n$ 和任意状态 $j_1,\dots,j_{n+1}$ 恒有

$$P(X_{n+1}=j_{n+1}|X_1=j_1,\dots,X_n=j_n)=P(X_{n+1}=j_{n+1}|X_n=j_n)$$

则称 $\{X_n\}$ 为**马尔可夫链**。核心性质是**无后效性（马尔可夫性）**：**未来只依赖现在，与过去无关**——"已知现在，将来与过去条件独立"。

**Q [⭐⭐⭐]【9.1.Q2】：马尔可夫链有哪些相关性质和公式？**

A：

| 概念 | 公式 | 说明 |
| -- | -- | -- |
| 一步转移概率 | $p_{ij}=P(X_{n+1}=j\lvert X_n=i)$ | 由状态 $i$ 下一步转到 $j$ 的概率 |
| 转移概率矩阵 | $P=(p_{ij})$ | 元素非负、**每行和为 1**（随机矩阵） |
| C-K 方程 | $p_{ij}^{(n+l)}=\sum_{k\in S}p_{ik}^{(n)}p_{kj}^{(l)}$ | 切普曼-柯尔莫哥洛夫方程 |
| $n$ 步转移矩阵 | $P^{(n)}=P^n$ | 齐次链下即一步矩阵的 $n$ 次幂 |
| 绝对分布 | $\pi_n=\pi_0P^{(n)}$ | 某时刻分布 = 初始分布 × $n$ 步矩阵 |
| 平稳分布 | $\pi=\pi P$，即 $\pi_j=\sum_i\pi_ip_{ij}$ | 分布不再随步数变化 |

**齐次性**：若 $p_{ij}$ 与时刻 $n$ 无关，称**齐次马尔可夫链**（时齐），此时才有 $P^{(n)}=P^n$。**典型应用**：天气状态转移预测、**PageRank**（网页重要性就是随机游走的平稳分布）、**隐马尔可夫模型 HMM**（分词、语音识别、生物序列标注）、MCMC 采样。

**Q [⭐⭐]【9.1.Q3】：无后效性和齐次性有什么区别？**

A：**无后效性**管"**依赖谁**"——预测下一个状态时只看当前状态，不看更早的历史；**齐次性**管"**转移概率会不会随时间变**"——从 $i$ 转到 $j$ 的概率 $p_{ij}$ 不随时刻 $n$ 改变。两者相互独立：可以无后效但不齐次（转移概率随时刻变）。

### 9.2 白噪声 ⭐⭐

**Q [⭐⭐]【9.2.Q1】：白噪声是什么？有什么特点？**

A：**定义**：白噪声是一列**均值为 0、方差恒定、不同时刻互不相关**的随机变量：

$$E(\varepsilon_t)=0,\quad D(\varepsilon_t)=\sigma^2,\quad \text{Cov}(\varepsilon_t,\varepsilon_s)=0\ (t\neq s)$$

若进一步要求各时刻**相互独立**且服从正态分布，称为**高斯白噪声**（独立比不相关更强，条件也更苛刻）。

**特点**：

- **零均值、同方差**——是（弱）平稳序列；
- **任意两个不同时刻不相关**——不含任何可利用的时间结构，因此**无法被预测**；
- **功率谱密度是常数**——各频率成分功率均等，这正是"白"的由来（类比白光包含各种颜色的光）；
- 高斯白噪声经过任意**线性系统**后仍服从正态分布。

**Q [⭐⭐]【9.2.Q2】：白噪声在统计与信号处理中有什么意义？**

A：它是**随机性的"标准件"**——把一切可利用的信息抽走后剩下的纯粹噪声，因此被当作模型的**扰动项基准**：

- 时间序列模型（AR / MA / ARMA）把它作为**基本假设**：可预测部分建成确定性模型，剩下不可预测的扰动即白噪声；
- 回归与最小二乘假设误差项 $\varepsilon$ 是白噪声（$E\varepsilon=0$、互不相关、同方差），这也是 Gauss-Markov 定理的前提；
- 实际做**残差诊断**时：若拟合后的残差**不是白噪声**（仍存在自相关），说明模型没把信息抽干，需要改进模型。
