## 1. 随机事件与概率

> [!note]+ 章节导引  
> **本章知识点之间的关系**：本章是概统的"字母表"——定义后续所有讨论所需的基础语言。逻辑链：先定义**样本空间和事件**（随机现象的基本元素）→ 再定义**概率**（事件发生可能性的数值度量，三种概型）→ 然后引入**条件概率**（已知部分信息后重新评估概率）→ 由条件概率引出**三大公式**（乘法、全概率、贝叶斯）。贝叶斯公式是本章的高潮——它实现"由果推因"，是机器学习贝叶斯方法的源头。
>
> **与上一章的关系**：无（这是起点）。
>
> **与学科的关系**：本章提供概统的基础语言，后续所有章节都建立在这些概念之上。

### 1.1 三大概率定义

| 定义       | 核心                                          | 适用范围          |
| -------- | ------------------------------------------- | ------------- |
| **古典概型** | $P(A) = \frac{\text{有利事件数}}{\text{总事件数}}$   | 有限个等可能结果      |
| **几何概型** | $P(A) = \frac{\text{有利区域度量}}{\text{总区域度量}}$ | 无限等可能，用长度/面积比 |
| **统计概型** | $P(A) = \frac{f_n(A)}{n}$（频率→概率）            | 频率稳定性         |

### 1.2 条件概率与三大公式 ⭐⭐⭐

**条件概率**：$P(A|B) = \frac{P(AB)}{P(B)}$，即"已知 B 发生后 A 的概率"

**乘法公式**：$P(AB) = P(A|B) \cdot P(B)$ → 推广到 $n$ 个事件

**全概率公式**：$P(B) = \sum_{i=1}^{n} P(B|A_i) P(A_i)$

> [!tip]+ 全概率的直觉  
> 全概率 = "分情况讨论"——把 B 的概率拆成在各种原因 $A_i$ 下的加权平均。

> [!warning]+ 全概率公式成立的条件（面试常追问）
>
> 1. $A_1,\dots,A_n$ 构成**完备事件组（划分）**：两两互斥 $A_iA_j=\emptyset$，且 $\bigcup_{i=1}^{n} A_i = \Omega$（既互斥、又穷尽）；
> 2. 每个 $P(A_i) > 0$（保证分母不为零）；
> 3. $B$ 是同一概率空间中的任一事件。
>
> 不满足"互斥且穷尽"就不能用；贝叶斯公式额外要求 $P(B) > 0$。

**贝叶斯公式**：$P(A_i|B) = \frac{P(B|A_i) P(A_i)}{\sum_{j} P(B|A_j) P(A_j)}$

> [!tip]+ 贝叶斯的直觉  
> 贝叶斯 = "由果推因"——已知结果 B 发生了，反推是哪个原因 $A_i$ 导致的概率。先验 $P(A_i)$ → 后验 $P(A_i|B)$

**先验概率 vs 后验概率** ⭐⭐⭐：

|    | 先验概率 $P(A_i)$    | 后验概率 $P(A_i\lvert B)$ |
| -- | ---------------- | --------------------- |
| 含义 | 观测数据**之前**对原因的判断 | 观测到 $B$ **之后**修正过的判断  |
| 来源 | 经验、历史数据或主观设定     | 由贝叶斯公式算出              |
| 作用 | 贝叶斯公式的**输入**     | 贝叶斯公式的**输出**          |

关系：**后验 ∝ 似然 × 先验**，写成 $P(A_i|B) \propto P(B|A_i) \cdot P(A_i)$

**贝叶斯公式的应用**：

- **疾病检测（假阳性悖论）**：患病率 0.1%、灵敏度 99%、特异度 99%，查出一例阳性后真实患病概率只有约 **9%**——极低的先验把后验拉了下来。
- **垃圾邮件分类**：朴素贝叶斯用"词语 → 邮件类别"的后验判断是否为垃圾邮件。
- **拼写纠错、语音识别**：候选答案 = 先验（语言模型）× 似然（声学/编辑模型），取后验最大者。
- **贝叶斯统计**：把参数视为随机变量，先验 → 后验，用于参数估计与决策。

### 1.3 三个"独立"概念的辨析 ⭐⭐⭐（面试高频）

| 概念     | 定义                 | 关键区别                                   |
| ------ | ------------------ | -------------------------------------- |
| **互斥** | $AB = \emptyset$   | 不可能同时发生；$P(AB)=0$                      |
| **独立** | $P(AB) = P(A)P(B)$ | 一个发生不影响另一个；**与互斥矛盾**（互斥事件一定不独立，除非概率为0） |
| **相关** | $\rho_{XY} \neq 0$ | 有线性关系；独立→不相关，但**不相关不一定独立**             |

> [!tip]+ 面试一句话  
> 互斥 = 不能同时发生；独立 = 互不影响；互斥和独立（在概率非0时）互斥！

## 2. 随机变量及其分布

> [!note]+ 章节导引  
> **本章知识点之间的关系**：上一章用"事件"描述随机，但事件不够好操作——我们需要一个"数值化"的工具，这就是**随机变量**。逻辑链：定义**随机变量**（把样本点映射到实数）→ 用**分布函数**完整描述它的概率规律 → 离散型用**分布律**，连续型用**概率密度** → 再学习**七大常见分布**（0-1、二项、超几何、泊松、均匀、指数、正态），它们是后续所有建模的"积木"。
>
> **与上一章的关系**：随机变量把第1章的"事件"数值化，使得概率论可以用微积分工具来处理。
>
> **与学科的关系**：本章建立"分布"的概念，后续章节（多维、数字特征、极限定理）都在分布之上展开。

### 2.1 离散 vs 连续

|      | 离散型                  | 连续型                                         |
| ---- | -------------------- | ------------------------------------------- |
| 描述   | 分布律 $P(X=x_k) = p_k$ | 概率密度 $f(x)$，$F(x)=\int_{-\infty}^{x}f(t)dt$ |
| 取值   | 有限或可列                | 不可列（区间）                                     |
| 某点概率 | $P(X=x_k) = p_k$     | $P(X=x_0) = 0$（连续型单点概率为0！）                  |

### 2.2 常见分布（七大）⭐⭐⭐

| 分布                         | 概率/密度                                                              | 期望                  | 方差                                           | 典型场景       |
| -------------------------- | ------------------------------------------------------------------ | ------------------- | -------------------------------------------- | ---------- |
| **0-1 分布**                 | $P(X=k)=p^k(1-p)^{1-k}$                                            | $p$                 | $p(1-p)$                                     | 一次伯努利试验    |
| **二项分布 $B(n,p)$**          | $P(X=k)=C_n^k p^k(1-p)^{n-k}$                                      | $np$                | $np(1-p)$                                    | $n$ 次独立伯努利 |
| **泊松分布 $P(\lambda)$**      | $P(X=k)=\frac{\lambda^k e^{-\lambda}}{k!}$                         | $\lambda$           | $\lambda$                                    | 稀有事件计数     |
| **超几何分布 $H(N,M,n)$**       | $P(X=k)=\frac{C_M^k C_{N-M}^{n-k}}{C_N^n}$                         | $\frac{nM}{N}$      | $n\frac{M}{N}(1-\frac{M}{N})\frac{N-n}{N-1}$ | 无放回抽样的命中数  |
| **均匀分布 $U(a,b)$**          | $f(x)=\frac{1}{b-a}$                                               | $\frac{a+b}{2}$     | $\frac{(b-a)^2}{12}$                         | 等可能        |
| **指数分布 $Exp(\lambda)$**    | $f(x)=\lambda e^{-\lambda x}$                                      | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$                        | 无记忆性（寿命）   |
| **正态分布 $N(\mu,\sigma^2)$** | $f(x)=\frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$               | $\sigma^2$                                   | 万能分布（CLT）  |

> [!tip]+ 分布之间的联系（面试爱问"有什么联系"）
>
> - **二项 ↔ 超几何**：二项 = **有放回**抽样（各次独立），超几何 = **无放回**抽样；$N$ 很大、$n$ 相对小时，超几何 $\approx$ 二项。
> - **二项 → 泊松**：$n$ 大、$p$ 小、$np=\lambda$ 适中时，$B(n,p) \approx P(\lambda)$（稀有事件近似）。
> - **二项 → 正态**：$n$ 大时由 CLT，$B(n,p) \approx N(np, np(1-p))$（棣莫弗-拉普拉斯）。
> - 泊松 ↔ 指数：同一泊松过程的两种视角——泊松描述"单位时间事件数"，指数描述"两次事件的间隔时间"。
> - **正态是终点**：CLT 使大量独立同分布之和近似正态，所以它是"万能分布"。

> [!tip]+ 各分布的典型应用
>
> - **二项分布**：$n$ 次独立重复试验的成功次数（抛硬币正面数、抽检合格数）。
> - **超几何分布**：同一问题但**不放回**（从 $N$ 件产品中不放回抽 $n$ 件，其中的次品数）。
> - **泊松分布**：稀有事件计数（单位时间电话呼叫数、放射性衰变、网站点击量）。
> - **指数分布**：等待时间/寿命，满足**无记忆性** $P(X > s+t | X > s) = P(X > t)$——设备已运行 $s$ 小时无故障，再运行 $t$ 小时无故障的概率和新的一样。
> - **正态分布**：测量误差、身高、考试成绩等大量自然与社会现象。

### 2.3 分布函数 vs 概率密度 ⭐⭐⭐

**分布函数（CDF）**：$F(x) = P(X \leq x)$。**一切**随机变量（离散/连续）都有分布函数。

**概率密度（PDF）**：只对**连续型**随机变量存在，是非负可积函数，满足 $F(x) = \int_{-\infty}^{x} f(t)dt$。

|      | 分布函数 $F(x)$                            | 概率密度 $f(x)$                                         |
| ---- | -------------------------------------- | --------------------------------------------------- |
| 存在范围 | 一切随机变量                                 | 仅连续型随机变量                                            |
| 取值含义 | 是概率 $P(X \leq x)$                      | **不是概率**，$f(x)$ 的值可以大于 1                            |
| 算概率  | $P(a<X \leq b) = F(b)-F(a)$            | $P(a<X \leq b) = \int_a^b f(x)dx$                   |
| 基本性质 | 单调不减、右连续、$F(-\infty)=0$、$F(+\infty)=1$ | $f(x) \geq 0$，$\int_{-\infty}^{+\infty} f(x)dx = 1$ |

**连续性随机变量的分布函数是不是处处可导？** —— **不一定**（面试常考陷阱）：

- 连续型随机变量的 $F(x)$ **一定连续**，但**不一定处处可导**，**只保证在 $f(x)$ 的连续点处可导**，且 $F'(x) = f(x)$；
- 在 $f$ 的**断点处 $F$ 不可导**（左右导数不相等）。例：均匀分布 $U(a,b)$ 的 $F$ 在 $x=a$ 和 $x=b$ 处就不可导；
- 反过来说，若 $F$ 处处可导，则密度必为 $F'(x)$。另外，**改动 $f$ 在有限个点上的取值不影响分布**，所以密度不唯一。
- （对比）离散型的 $F$ 是**阶梯函数**，在跳跃点处也不可导。

## 3. 二维随机变量

> [!note]+ 章节导引  
> **本章知识点之间的关系**：现实中的随机现象往往涉及多个变量，本章把第2章从"一维"扩展到"二维"。逻辑链：先定义**联合分布**（两个变量一起的概率规律）→ 再"聚焦"得到**边际分布**（只看一个变量，积分掉另一个）→ 再"限定"得到**条件分布**（已知一个变量时另一个的分布）→ 最后讨论**独立性**（联合 = 边积）。
>
> **与上一章的关系**：本章是第2章的多维推广，所有概念都有一维对应。
>
> **与学科的关系**：多维随机变量是后续"协方差、相关系数"（第4章）的基础。

### 3.1 联合→边际→条件：信息逐步聚焦

**联合分布** $F(x,y) = P(X \leq x, Y \leq y)$ 描述两个变量一起的概率规律

**边际分布**：$F_X(x) = F(x, +\infty)$——只关注 X，"积分掉"Y

**条件分布**：$F_{X|Y}(x|y) = \frac{F(x,y)}{F_Y(y)}$——已知 Y 时 X 的分布

**三种概率的定义与区别** ⭐⭐⭐：

| 概率类型     | 记法                                               | 含义                   | 特征            |
| -------- | ------------------------------------------------ | -------------------- | ------------- |
| **联合概率** | $P(X=x, Y=y)$                                    | 两个变量**同时**取某值        | 描述整体，最完整      |
| **边缘概率** | $P(X=x) = \sum_{y} P(X=x, Y=y)$                  | 只关心 $X$，把 $Y$ 累加/积分掉 | 由联合分布"投影"得到   |
| **条件概率** | $P(X=x \lvert Y=y) = \frac{P(X=x, Y=y)}{P(Y=y)}$ | 已知 $Y=y$ 时 $X$ 的概率   | 信息更多后重新划定样本空间 |

关系链：**联合 = 边缘 × 条件**（乘法公式）；若 $X,Y$ 独立，则 **联合 = 边缘 × 边缘**，条件 = 边缘。

### 3.2 独立性判断 ⭐⭐⭐

$X, Y$ 独立 $\iff$ $F(x,y) = F_X(x) \cdot F_Y(y)$ 对所有 $x,y$

## 4. 数字特征

> [!note]+ 章节导引  
> **本章知识点之间的关系**：分布函数虽然"完整"，但信息太多不好比较。本章用几个数字来"概括"分布的核心特征。逻辑链：**期望**（中心在哪）→ **方差**（散布多远）→ **协方差**（两个变量线性关联的方向）→ **相关系数**（线性关联的强度）。这四个量从"自身特征"到"关系特征"逐步递进。
>
> **与上一章的关系**：数字特征是第2-3章分布的"浓缩版"——知道分布就能算这些数，但知道这些数不一定能还原分布。
>
> **与学科的关系**：数字特征是第5章极限定理和第7章参数估计的基础。

### 4.1 四大数字特征 ⭐⭐⭐

| 特征                        | 定义                                        | 意义       | 性质                                       |
| ------------------------- | ----------------------------------------- | -------- | ---------------------------------------- |
| **期望 $E(X)$**             | 离散：$\sum x_k p_k$；连续：$\int xf(x)dx$       | 中心位置（均值） | 线性：$E(aX+bY)=aE(X)+bE(Y)$                |
| **方差 $D(X)$**             | $E[(X-EX)^2]$                             | 离散程度     | $D(X)=E(X^2)-[E(X)]^2$；$D(aX+b)=a^2D(X)$ |
| **协方差 $\text{Cov}(X,Y)$** | $E[(X-EX)(Y-EY)]$                         | 线性关联方向   | $\text{Cov}(X,Y)=E(XY)-E(X)E(Y)$         |
| **相关系数 $\rho_{XY}$**      | $\frac{\text{Cov}(X,Y)}{\sqrt{D(X)D(Y)}}$ | 线性关联强度   | $\lvert \rho \rvert \leq 1$；$\rho=0$ 不相关 |

### 4.2 独立 vs 不相关 ⭐⭐⭐

> [!tip]+ 辨析  
> **独立 → 不相关，但不相关不一定独立**
>
> - 独立：$P(XY) = P(X)P(Y)$（概率层面）
> - 不相关：$\rho_{XY} = 0$（只是**没有线性关系**，可能有非线性关系）
>
> 例外：**正态分布下，不相关 = 独立**

### 4.3 期望和方差的常用性质 ⭐⭐⭐

$E(aX + bY) = aE(X) + bE(Y) \quad \text{（无条件成立）}$

$D(aX + bY) = a^2D(X) + b^2D(Y) + 2ab\text{Cov}(X,Y)$

独立时协方差为0：$D(X+Y) = D(X) + D(Y)$

### 4.4 标准差、协方差矩阵 ⭐⭐

**标准差**：$\sigma_X = \sqrt{D(X)}$。与 $X$ **同量纲**（方差是平方量纲），所以描述"离散程度"时更直观，也是正态分布 $N(\mu,\sigma^2)$ 里那个 $\sigma$。

**方差与协方差的关系**：$D(X) = \text{Cov}(X, X)$——方差是协方差在"自己与自己"时的特例，协方差是方差的推广。

**协方差矩阵**：设 $n$ 维随机向量 $X = (X_1,\dots,X_n)^T$，则  
$\Sigma = \text{Cov}(X) = E\big[(X-EX)(X-EX)^T\big]$

- 第 $(i,j)$ 元为 $\text{Cov}(X_i,X_j)$，**对角线上是各分量的方差**：$\Sigma_{ii} = D(X_i)$；
- 性质：**对称**、**半正定**（$D(X_i) \geq 0$ 的矩阵推广）；
- 用途：多元正态 $N(\mu,\Sigma)$ 的核心参数、主成分分析 PCA（对 $\Sigma$ 做特征分解）、卡尔曼滤波。


**协方差的性质**：对称 $\text{Cov}(X,Y)=\text{Cov}(Y,X)$；双线性 $\text{Cov}(aX+b, cY+d) = ac\,\text{Cov}(X,Y)$。

## 5. 大数定律与中心极限定理

> [!note]+ 章节导引  
> **本章知识点之间的关系**：前4章都在描述"个体"和"分布"，本章回答两个根本问题——概率论为什么能用频率估计概率？为什么正态分布这么重要？逻辑链：**大数定律**说"平均趋于期望"→ **中心极限定理**说"和趋于正态"。前者是统计推断的理论保证，后者解释了为什么自然界的各种分布都近似正态。这两个定理是概统的"理论高潮"，也是连接概率论和数理统计的桥梁。
>
> **与上一章的关系**：大数定律和CLT都是对"随机变量之和"或"样本均值"的行为刻画，需要第4章的期望和方差作为工具。
>
> **与学科的关系**：本章是概率论→数理统计的转折点——有了极限定理的保证，第6-8章才敢用样本推断总体。

### 5.1 大数定律 ⭐⭐⭐

**辛钦大数定律**（面试最常考）：  
$\bar{X}_n = \frac{1}{n}\sum_{i=1}^{n}X_i \xrightarrow{P} \mu$

> [!tip]+ 含义
>
> $\stackrel{P}{\longrightarrow}$ ：依概率收敛  
> $n$ 个独立同分布的随机变量的**算术平均**，当 $n$ 很大时，依概率收敛于**数学期望**。这就是"频率稳定于概率"的理论基础。

**伯努利大数定律**：辛钦在 $X_i$ 为 0-1 分布时的特例。n 重伯努利试验，每次独立，单次成功概率 p。设 $n_A$ 为 $n$ 次试验成功总次数，则频率 $\frac{n_A}{n}$ 依概率收敛于 $p$。

### 5.2 中心极限定理（CLT）⭐⭐⭐

**独立同分布 CLT**：  
$\frac{\sum_{i=1}^{n}X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)$

> [!tip]+ 面试一句话  
> 大数定律说"平均趋于期望"，CLT 说"和趋于正态"。这是统计推断的两大理论支柱。
>
> **含义**：$n$ 个独立同分布随机变量之**和**，标准化后近似标准正态——**不管原来什么分布**。
>
> $\stackrel{d}{\longrightarrow}$：**依分布收敛**。意思：n 很大时，左边这个标准化随机变量的分布函数无限逼近标准正态分布函数。

**棣莫弗-拉普拉斯**：二项分布的正态近似——$B(n,p) \approx N(np, np(1-p))$

## 6. 数理统计基础

> [!note]+ 章节导引  
> **本章知识点之间的关系**：从本章开始，方向反转——不再是"已知分布推概率"，而是"已知数据推分布"。逻辑链：先定义**统计量**（样本的函数，推断的工具）→ 再研究统计量的分布（**抽样分布**：$\chi^2$、$t$、$F$）。这三大分布是第7章区间估计和第8章假设检验的计算工具。
>
> **与上一章的关系**：第5章保证了"样本均值趋于总体均值"，本章才敢用样本统计量来推断总体参数。
>
> **与学科的关系**：本章是数理统计的"工具箱"，后续估计和检验都要用到抽样分布。

### 6.1 关键概念 ⭐⭐⭐

**统计量**：样本的函数，不含未知参数。

| 统计量            | 定义                                   | 意义                     |
| -------------- | ------------------------------------ | ---------------------- |
| 样本均值 $\bar{X}$ | $\frac{1}{n}\sum X_i$                | 估计总体均值                 |
| 样本方差 $S^2$     | $\frac{1}{n-1}\sum(X_i - \bar{X})^2$ | 估计总体方差（**无偏**，除 $n-1$） |

> [!tip]+ 为什么除 n-1 而非 n？  
> 因为 $\bar{X}$ 本身是用样本估计的，会"缩小"偏差。除以 $n-1$ 才能保证 $E(S^2) = \sigma^2$（无偏性）。面试必考！

### 6.2 三大抽样分布 ⭐⭐⭐

| 分布              | 构造                                                                                         | 典型用途            |
| --------------- | ------------------------------------------------------------------------------------------ | --------------- |
| **$\chi^2$ 分布** | $n$ 个标准正态的平方和$\chi^2(n)=X_1^2+X_2^2+\dots+X_n^2$                                           | 方差估计、卡方检验       |
| **$t$ 分布**      | $\frac{N(0,1)}{\sqrt{\chi^2(n)/n}}$                                                        | 小样本均值检验（$n<30$） |
| **$F$ 分布**      | 设 $W_1\sim\chi^2(n_1),W_2\sim\chi^2(n_2)$，相互独立，则<br />$F(n_1,n_2)=\frac{W_1/n_1}{W_2/n_2}$ | 两方差比较、方差分析      |

> [!tip]+ 记住  
> $n$ 大时，$t$ 分布 → $N(0,1)$；$\chi^2(n)$ 的期望 = $n$，方差 = $2n$。

## 7. 参数估计

> [!note]+ 章节导引  
> **本章知识点之间的关系**：参数估计是数理统计最核心的应用——用样本推断总体的未知参数。逻辑链：**点估计**（用一个值估计参数）→ 两种方法（**矩估计** vs **最大似然估计**）→ 评价标准（**无偏、有效、一致**）→ **区间估计**（给参数一个范围，比点估计更稳健）。
>
> **与上一章的关系**：点估计的"估计量"就是第6章定义的"统计量"，区间估计需要第6章的抽样分布来确定置信区间。
>
> **与学科的关系**：参数估计是数理统计最直接的应用，也是机器学习中"参数拟合"的统计基础。

### 7.1 点估计 ⭐⭐⭐

点估计：一类方法，目标是算出**一个数值**估计总体未知参数。

矩估计：点估计的一种，拿样本矩代替总体矩解方程，不用知道分布。  
（思路：**样本的特征≈总体的特征**。）

MLE：点估计的一种，已知分布，找让当前样本发生概率最大的参数  
（思路：**现在这组样本已经出现了，哪个参数会让这组样本最有可能发生？就选这个参数作为猜测值。）**

| 方法                  | 思想             | 步骤                                             |
| ------------------- | -------------- | ---------------------------------------------- |
| **矩估计法**            | 用样本矩替代总体矩      | 令 $E(X^k) = \frac{1}{n}\sum X_i^k$，解方程         |
| **最大似然估计（MLE）** ⭐⭐⭐ | 选择使样本出现概率最大的参数 | 构造似然函数 $L(\theta)$，求 $\hat{\theta}=\arg\max L$ |

> [!tip]+ 最大似然的思想（面试常问）  
> 已知样本发生了，那么参数取什么值时，这个样本出现的概率最大？——"既然发生了，那它就该是最可能的"。

**MLE 步骤**：

1. 写似然函数 $L(\theta) = \prod f(x_i;\theta)$
2. 取对数 $\ln L(\theta)$（化乘为加）
3. 对 $\theta$ 求导，令导数为 0
4. 解出 $\hat{\theta}$

### 7.2 估计量的评价标准 ⭐⭐⭐

| 标准           | 含义                                                     | 记忆       |
| ------------ | ------------------------------------------------------ | -------- |
| **无偏性**      | $E(\hat{\theta}) = \theta$                             | 估计没有系统偏差 |
| **有效性**      | 两个无偏估计中方差小的更优                                          | 更集中 = 更好 |
| **一致性（相合性）** | $n \to \infty$ 时 $\hat{\theta} \xrightarrow{P} \theta$ | 样本越多越准   |

> [!tip]+ 有偏估计 vs 无偏估计 ⭐⭐⭐  
> **无偏估计**：$E(\hat{\theta}) = \theta$——多次重复抽样，估计值的**平均**正好等于真参数，没有系统偏差。  
> **有偏估计**：$E(\hat{\theta}) \neq \theta$，偏差 $\text{bias}(\hat{\theta}) = E(\hat{\theta}) - \theta$。
>
> **典型例子**：样本二阶中心矩 $B_2 = \frac{1}{n}\sum(X_i-\bar{X})^2$ 估计 $\sigma^2$ 是**有偏**的，$E(B_2) = \frac{n-1}{n}\sigma^2 < \sigma^2$（系统性偏小），改除 $n-1$ 才无偏——这正是样本方差 $S^2$ 除 $n-1$ 的原因。
>
> 注意："无偏"不等于"最好"。有偏估计有时方差更小、总误差（均方误差 = 方差 + 偏差²）更低，所以实践中会**用一点偏差换更小的方差**（如岭回归、收缩估计）。

### 7.3 区间估计

$P(\hat{\theta}_L < \theta < \hat{\theta}_U) = 1 - \alpha$

> [!tip]+ 置信区间的正确理解  
> 置信区间不是"参数有 95% 概率落在这个区间"——参数是固定值，区间是随机的！是"如果我们重复抽样很多次，每次抽一组样本，算出一个置信区间；在这么多区间里，大约有 95% 的区间能够包住真实参数 $\theta$。"。

### 7.4 最小二乘法（Least Squares）⭐⭐

**思想**：给定数据 $(x_i, y_i)$，找参数使模型预测值与实测值的**残差平方和最小**——用平方是为了正负残差不相消、且对大误差惩罚更重。

$Q(\theta) = \sum_{i=1}^{n}\big(y_i - f(x_i;\theta)\big)^2 \to \min$

**过程（线性最小二乘）**：

1. 设线性模型 $Y = X\beta + \varepsilon$（$X$ 为设计矩阵，如多项式拟合的范德蒙德矩阵）；
2. 写目标函数 $Q(\beta) = \lVert Y - X\beta \rVert^2$；
3. 对 $\beta$ 求导并令为零 → **正规方程** $X^T X \beta = X^T Y$；
4. 解出 $\hat{\beta} = (X^T X)^{-1} X^T Y$（$X^T X$ 可逆时）。

**统计意义（面试加分点）**：

- **Gauss-Markov 定理**：在 $E(\varepsilon)=0$、$\text{Cov}(\varepsilon)=\sigma^2 I$ 的条件下，最小二乘估计是**最佳线性无偏估计（BLUE）**——线性无偏类里方差最小；
- 当误差 $\varepsilon \sim N(0,\sigma^2 I)$ 时，**最小二乘 = 最大似然估计**（正态密度的指数里正好是残差平方和）；
- 几何解释：$\hat{Y}$ 是 $Y$ 在 $X$ 的列空间上的**正交投影**，残差与列空间垂直。

> [!tip]+ 面试一句话  
> 最小二乘 = "让残差平方和最小的拟合"，解是正规方程 $X^TX\beta = X^TY$；它是正态误差假设下最大似然估计的特例，本质是正交投影。

## 8. 假设检验

> [!note]+ 章节导引  
> **本章知识点之间的关系**：假设检验是"统计决策"——根据样本数据决定是否接受某个假设。逻辑链：先建立**原假设 $H_0$**（无罪推定）→ 选**检验统计量**（$Z/t/\chi^2/F$）→ 确定**拒绝域**（由显著性水平 $\alpha$ 决定）→ 做决策。核心难点是**两类错误**（弃真 vs 取伪），它们此消彼长。
>
> **与上一章的关系**：假设检验可以看作区间估计的"镜像"——如果参数的置信区间不包含 $H_0$ 的值，就拒绝 $H_0$。
>
> **与学科的关系**：假设检验是实验科学和 A/B 测试的统计基础。

### 8.1 核心思想：证伪而非证实

> [!tip]+ 类比  
> 假设检验 = 法庭审判。$H_0$ = "无罪推定"，只有在证据极强时才判有罪。

### 8.2 两类错误 ⭐⭐⭐

| 错误类型          | 含义          | 概率              | 类比   |
| ------------- | ----------- | --------------- | ---- |
| **第一类错误（弃真）** | $H_0$ 为真却拒绝 | $\alpha$（显著性水平） | 冤枉好人 |
| **第二类错误（取伪）** | $H_0$ 为假却接受 | $\beta$         | 放过坏人 |

> [!tip]+ 关键  
> 降低 $\alpha$ → $\beta$ 升高（此消彼长，不能同时减小，除非增大样本量）。**Neyman-Pearson 原则**：先控制 $\alpha$，再尽量减小 $\beta$。$1-\beta$ = 检验的"功效"。

## 9. 拓展：随机过程初步（马尔可夫链与白噪声）

> [!note]+ 章节导引  
> 前 8 章研究"一个或几个随机变量"，本章研究"一族随时间变化的随机变量"——**随机过程**（教材第 9–12 章）。这里只覆盖面试最常被问到的两个概念：**马尔可夫链**（离散状态、无后效性）和**白噪声**（最基础的平稳序列）。

### 9.1 马尔可夫链 ⭐⭐

**定义**：设随机过程 $\{X_n, n=0,1,2,\dots\}$ 的状态空间 $S$ 是有限集或可列集。若对任意 $n$ 和任意状态 $j_1,\dots,j_{n+1}$，都有  
$P(X_{n+1}=j_{n+1} \mid X_1=j_1,\dots,X_n=j_n) = P(X_{n+1}=j_{n+1} \mid X_n=j_n)$  
则称它为**马尔可夫链**。其核心是**无后效性（马尔可夫性）**：**未来只依赖现在，与过去无关**——"已知现在，将来与过去条件独立"。

**基本公式与性质**：

| 概念        | 公式                                                          | 说明                      |
| --------- | ----------------------------------------------------------- | ----------------------- |
| 一步转移概率    | $p_{ij} = P(X_{n+1}=j \lvert X_n=i)$                        | 从状态 $i$ 下一步到 $j$ 的概率    |
| 转移概率矩阵    | $P = (p_{ij})$                                              | 元素非负，**每行和为 1**（随机矩阵）   |
| C-K 方程    | $p_{ij}^{(n+l)} = \sum_{k \in S} p_{ik}^{(n)} p_{kj}^{(l)}$ | 切普曼-柯尔莫哥洛夫方程            |
| $n$ 步转移矩阵 | $P^{(n)} = P^n$n 步转移矩阵 = 一步转移矩阵的 n 次幂                       | 齐次链下直接是矩阵幂              |
| 绝对分布      | $\pi_n = \pi_0 P^{(n)}$                                     | 某时刻分布 = 初始分布 × $n$步转移矩阵 |
| 平稳分布      | $\pi = \pi P$，即 $\pi_j = \sum_i \pi_i p_{ij}$               | 分布不再随步数变化               |

**齐次性**：若 $p_{ij}$ 与时刻 $n$ 无关，称**齐次马尔可夫链**（时齐），此时才有 $P^{(n)} = P^n$。

**典型应用**：天气状态转移预测、**PageRank**（网页重要性 = 随机游走的平稳分布）、**隐马尔可夫模型 HMM**（分词、语音识别、生物序列标注）、MCMC 采样。

> [!tip]+ 面试一句话  
> 马尔可夫链 = "状态离散 + 无后效性"的随机过程；记住两个公式：$P^{(n)} = P^n$ 和 平稳分布 $\pi = \pi P$。
>
> - **无后效性（马尔可夫性）：管「依赖谁」**预测下一个状态，**只看当前，不看更早历史**；和时间本身没关系。
> - **齐次性（时齐性）：管「转移概率会不会随时间变」**从 i 跳到 j 的概率 $p_{ij}$，**不随时刻 n 改变**。

### 9.2 白噪声 ⭐⭐

**定义**：白噪声是一列**均值为 0、方差恒定、不同时刻互不相关**的随机变量：  
$E(\varepsilon_t) = 0, \quad D(\varepsilon_t) = \sigma^2, \quad \text{Cov}(\varepsilon_t, \varepsilon_s) = 0 \ (t \neq s)$

若进一步要求各时刻**相互独立**且服从正态分布，称为**高斯白噪声**（独立比不相关更强）。

**特点**：

- **零均值、同方差**——是（弱）平稳序列；
- **任意两个不同时刻不相关**——不含任何可利用的时间结构，因此**无法被预测**；
- **功率谱密度是常数**——各频率成分功率均等，这正是"白"的由来（类比白光包含各种颜色的光）；
- 高斯白噪声经过任意线性系统后仍是高斯分布。

**为什么重要**：

- 是时间序列模型（AR / MA / ARMA）的**基本假设**：把可预测部分建为确定性模型，剩下的不可预测扰动即白噪声；
- 是回归与最小二乘中误差项 $\varepsilon$ 的标准假设（$E\varepsilon=0$、互不相关、同方差），也是 Gauss-Markov 定理的前提；
- 若拟合后的**残差不是白噪声**（仍有自相关），说明模型没把信息抽干，需要改进模型。

> [!tip]+ 面试一句话  
> 白噪声 = 零均值、同方差、**不相关**的随机序列，频谱平坦、不可预测；它是所有时间序列模型里"扰动项"的标准模型。

| 问题             | 一句话回答                                       |
| -------------- | ------------------------------------------- |

| 独立 vs 不相关      | 独立→不相关，不相关不一定独立；正态下等价                       |

| 样本方差除 n-1      | 保证无偏性，$E(S^2)=\sigma^2$                     |
| MLE 思想         | 使已观测样本出现概率最大的参数值                            |
| 两类错误           | 弃真(α) vs 取伪(β)，此消彼长                         |
| 置信区间           | 随机区间有 $1-\alpha$ 概率覆盖参数                     |
| 指数分布特点         | 无记忆性                                        |
| 泊松近似条件         | $n$ 大 $p$ 小，$B(n,p)≈P(np)$                  |
| 全概率公式条件        | $A_i$ 两两互斥且并集为全集（完备事件组），$P(A_i)>0$          |
| 先验 vs 后验       | 观测前 vs 观测后；后验 ∝ 似然 × 先验                     |
| 超几何 vs 二项      | 无放回 vs 有放回；$N$ 大时超几何趋近二项                    |
| 连续型 $F$ 是否处处可导 | 不一定，只保证连续；在密度连续点处 $F'=f$                    |
| 分布函数 vs 概率密度   | $F$ 是概率、一切变量都有；$f$ 只连续型有、本身不是概率、可大于 1       |
| 联合 / 边缘 / 条件概率 | 联合 = 边缘 × 条件；独立时联合 = 边缘 × 边缘                |
| 协方差与方差的关系      | $D(X)=\text{Cov}(X,X)$                      |
| 有偏 vs 无偏       | $E(\hat{\theta})=\theta$ 为无偏；样本二阶矩估方差有偏（偏小） |
| 最小二乘           | 残差平方和最小；解正规方程 $X^TX\beta=X^TY$，正态误差下 = MLE  |
| 马尔可夫链          | 无后效性；$P^{(n)}=P^n$，平稳分布 $\pi=\pi P$         |
| 白噪声            | 零均值、同方差、不相关；谱平坦、不可预测                        |
