# 算法 - 保研面试知识点总结

> [!info]+ 复习策略
> 算法的核心逻辑是"如何高效解决问题"。面试不会考你推公式，考的是**思想**——为什么用分治？为什么用 DP？贪心什么时候适用？记住每种范式解决什么类型的问题，比记住具体代码更重要。
>
> 重点标注：⭐⭐⭐ 高频 | ⭐⭐ 中频 | ⭐ 低频但重要

---

> [!abstract]+ 学科总览
> 算法按"解决问题的策略"分为几大范式，每个范式都不是凭空出现的，而是前一个范式"不够用"时的升级：
>
> - **分治**：大问题拆成独立小问题。简单直观，但子问题可能重叠导致重复计算。
> - **动态规划（DP）**：分治的升级——子问题重叠时，用"记忆化"避免重复。但需要问题满足"最优子结构"。
> - **贪心**：DP 的简化——如果局部最优能导向全局最优，就不需要 DP 的全局规划，直接每步贪心。
> - **图算法**：分治/DP/贪心在图这种特殊结构上的应用。
> - **排序**：可以看作分治思想的经典实例（归并、快排）。
>
> 暗线：**分治（通用拆解）→ DP（处理重叠）→ 贪心（如果够简单）→ 在特定结构上应用**。范式之间不是并列的，而是"通用→特殊"的递进关系。

---

## 1. 算法分析基础

> [!note]+ 章节导引
> **本章知识点之间的关系**：在学具体算法之前，先建立"衡量算法好坏"的语言。**渐进复杂度**（O/Ω/Θ）描述增长趋势，**主定理**是分析递归式复杂度的工具。两者是后续所有算法分析的"尺子"。
>
> **与上一章的关系**：无（这是起点）。
>
> **与学科的关系**：复杂度分析是算法的"评判标准"——后续每个算法都要用它来衡量。

### 1.1 主定理 ⭐⭐⭐

解递归式 $T(n) = aT(n/b) + f(n)$：

| 情况 | 条件 | 结论 | 例子 |
|------|------|------|------|
| 1 | $f(n) = O(n^{\log_b a - \epsilon})$ | $T(n) = \Theta(n^{\log_b a})$ | Strassen: $O(n^{2.81})$ |
| 2 | $f(n) = \Theta(n^{\log_b a} \log^k n)$ | $T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$ | 归并: $O(n\log n)$ |
| 3 | $f(n) = \Omega(n^{\log_b a + \epsilon})$ | $T(n) = \Theta(f(n))$ | / |

## 2. 分治法

> [!note]+ 章节导引
> **本章知识点之间的关系**：分治是最朴素的"大事化小"策略——**分解**→**递归求解**→**合并**。关键条件是子问题**相互独立**。经典实例：归并排序（对半分，O(n) 合并）、快速排序（按基准分，O(n) 分区）、二分查找（对半分，O(1) 查找）。分治的问题在于子问题可能**重叠**——这引出下一章的 DP。
>
> **与上一章的关系**：分治的复杂度用第1章的主定理来分析。
>
> **与学科的关系**：分治是所有算法范式的起点，DP 和贪心都是对分治的"改进"或"简化"。

### 2.1 分治 vs DP 的核心区别 ⭐⭐⭐

> [!tip]+ 关键辨析
> 分治的子问题**互相独立**（不重叠），DP 的子问题**重叠**（有公共子问题）。分治可能重复计算，DP 用记忆化避免重复。

| 问题 | 分解方式 | 合并代价 | 复杂度 |
|------|----------|----------|--------|
| 归并排序 | 对半分 | O(n) | O(n log n) |
| 快速排序 | 按基准分 | O(n) | 平均 O(n log n)，最坏 O(n²) |
| 二分查找 | 对半分 | O(1) | O(log n) |

---

## 3. 动态规划（DP）

> [!note]+ 章节导引
> **本章知识点之间的关系**：DP = 分治 + 记忆化。当分治的子问题重叠时，重复计算浪费巨大——DP 通过"存表"避免重复。逻辑链：**两大要素**（最优子结构 + 重叠子问题）→ **两种实现**（自顶向下记忆化 vs 自底向上递推）→ **解题框架**（定义状态→写转移方程→初始化→遍历→返回）→ **经典问题**（背包、LCS、LIS、矩阵链乘、编辑距离）。
>
> **与上一章的关系**：DP 是分治在子问题重叠时的升级版。
>
> **与学科的关系**：DP 是面试算法的"重镇"，也是运筹学、控制论的核心方法。

### 3.1 DP 解题框架 ⭐⭐⭐

1. **定义状态**：$dp[i]$ 或 $dp[i][j]$ 代表什么？
2. **状态转移方程**：$dp[i]$ 如何从更小的子问题推导？
3. **初始条件**：$dp[0] = ?$
4. **遍历顺序**：确保计算 $dp[i]$ 时它依赖的子问题已经算好
5. **返回结果**

### 3.2 经典 DP 问题

| 问题 | 状态定义 | 转移方程 | 复杂度 |
|------|----------|----------|--------|
| **0-1 背包** | $dp[i][w]$：前 i 个物品容量 w 的最大价值 | $dp[i][w]=\max(dp[i-1][w], dp[i-1][w-w_i]+v_i)$ | O(nW) |
| **LCS** | $dp[i][j]$：A前i和 B前j 的 LCS | 若 $A_i=B_j$：$dp[i][j]=dp[i-1][j-1]+1$；否则 $\max$ | O(mn) |
| **LIS** | $dp[i]$：以 $a_i$ 结尾的 LIS | $dp[i]=\max(dp[j]+1)$ for $j<i, a_j<a_i$ | O(n²)→O(n log n) |
| **编辑距离** | $dp[i][j]$：A前i→B前j 最少操作 | 插/删/改取 min | O(mn) |

> [!tip]+ 背包辨析
> 0-1 背包（物品不可分割）→ DP；分数背包（可分割）→ 贪心！

### 3.3 三大范式对比 ⭐⭐⭐

| | 分治 | DP | 贪心 |
|---|---|---|---|
| 子问题关系 | **独立** | **重叠** | 不分（直接选） |
| 保证全局最优 | ✅ | ✅ | ❌（不一定） |
| 时间 | 可能有重复计算 | 避免重复 | 最快 |
| 典型 | 归并排序 | 背包、LCS | 活动选择、Huffman |

## 4. 贪心算法

> [!note]+ 章节导引
> **本章知识点之间的关系**：贪心是 DP 的"简化版"——如果局部最优选择能导向全局最优，就不需要 DP 的全局规划。但贪心**不是万能的**，能用贪心需要两个前提：**贪心选择性质**（局部最优→全局最优）+ **最优子结构**。逻辑链：活动选择→Huffman 编码→分数背包→Dijkstra→Prim/Kruskal。贪心失效的例子：0-1 背包、硬币找零（某些面值）。
>
> **与上一章的关系**：贪心是 DP 的简化——当贪心选择性质成立时，DP 退化为贪心。
>
> **与学科的关系**：贪心是"最快的"算法范式，但适用范围最窄。工程中常用启发式贪心。

> [!tip]+ 面试一句话
> 贪心不是万能的——能用贪心的关键在于"局部最优能导向全局最优"，这需要证明（通常用交换论证法）。

## 5. 图算法

> [!note]+ 章节导引
> **本章知识点之间的关系**：图算法是分治/DP/贪心在图结构上的具体应用。逻辑链：**图的遍历**（BFS/DFS，所有图算法的基础）→ **最短路径**（Dijkstra=贪心、Bellman-Ford=DP、Floyd=DP）→ **最小生成树**（Kruskal=贪心+并查集、Prim=贪心）→ **拓扑排序**（DAG 的应用）。每种算法对应一种范式在图上的实例。
>
> **与上一章的关系**：Dijkstra、Prim/Kruskal 就是贪心算法在图上的应用。
>
> **与学科的关系**：图算法是导航、路由、社交网络分析的基础。

### 5.1 BFS vs DFS ⭐⭐⭐

| | BFS | DFS |
|---|---|---|
| 数据结构 | **队列** | **栈**（递归调用栈） |
| 最短路 | 无权图最短路 | 不保证 |
| 应用 | 无权最短路、层次遍历 | 拓扑排序、连通分量、环检测 |

### 5.2 最短路径算法 ⭐⭐⭐

| 算法 | 适用 | 复杂度 | 核心思想 |
|------|------|--------|----------|
| **Dijkstra** | 单源、**非负权** | $O(E+V\log V)$ | 贪心：每次选最近的 |
| **Bellman-Ford** | 单源、**可有负权** | $O(VE)$ | DP：松弛 $V-1$ 轮 |
| **Floyd-Warshall** | **全源** | $O(V^3)$ | DP：$d_{ij}=\min(d_{ij}, d_{ik}+d_{kj})$ |

> [!tip]+ Dijkstra 的局限
> Dijkstra **不能处理负权边**！因为贪心策略"已确定最短路的节点不会再更新"在负权下可能错误。有负权→用 Bellman-Ford。

### 5.3 最小生成树 ⭐⭐⭐

| 算法 | 核心 | 复杂度 | 适用 |
|------|------|--------|------|
| **Kruskal** | 按边权从小到大选，用并查集判环 | $O(E\log E)$ | **稀疏图** |
| **Prim** | 从一个顶点扩展，每次选最近的 | $O(E+V\log V)$ | **稠密图** |

### 5.4 拓扑排序 ⭐⭐⭐

**适用**：有向无环图（DAG），用于确定任务执行顺序

**方法**：Kahn 算法（BFS）——不断删除入度为 0 的节点

> [!tip]+ 面试要点
> 能拓扑排序 → 图无环；不能 → 图有环。拓扑排序可用于检测 DAG。

## 6. 海量数据处理 ⭐⭐⭐

> [!note]+ 章节导引
> **本章知识点之间的关系**：这类问题不考具体算法，考**思维**——如何利用有限内存处理远超内存的数据。核心策略：**分治**（hash 分片到不同文件）+ **外排**（磁盘友好）+ **小数据结构**（堆/位图/布隆过滤器）。

| 问题 | 核心思路 |
|------|----------|
| **Top-K** | 维护大小为 K 的**小根堆**，O(n log K) |
| **海量排序** | 外部排序：分块内排序 → 多路归并 |
| **去重** | 哈希分片各自去重 / 位图法 / 布隆过滤器 |

> [!tip]+ 万能思路
> 海量数据 = 分治（hash 分片）+ 外排（磁盘友好）+ 小数据结构（堆/位图/布隆）。

## 附：算法面试速查表

| 问题 | 一句话回答 |
|------|-----------|
| 主定理 | 递归式 $aT(n/b)+f(n)$，比较 $f(n)$ 和 $n^{\log_b a}$ |
| 分治 vs DP | 分治子问题独立，DP 子问题重叠 |
| DP 两要素 | 最优子结构 + 重叠子问题 |
| 贪心能用？ | 需要贪心选择性质（局部→全局），通常需证明 |
| Dijkstra 局限 | 不能有负权边（贪心假设被打破） |
| MST 两种 | Kruskal（选最短边+并查集），Prim（从一点扩展） |
| 拓扑排序 | 只适用于 DAG，Kahn 算法不断删入度为0的节点 |
| 快排为什么快 | 缓存友好+原地+常数因子小 |
| Top-K | 维护 K 大小的小根堆，O(n log K) |
