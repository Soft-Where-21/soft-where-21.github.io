# 离散数学 - 面试背诵版（仅问题）

> [!tip]+ 使用方式
> 本文件**只列问题不列答案**，按 Q 重要度从高到低分组，专供背诵。
> 做题流程：
> 1. 默看问题，脑中尝试完整陈述答案（定义 + 条件 + 公式 + 对比 / 反例）。
> 2. 卡壳或答完后，去 [[面试知识点速览版]] 找对应 Q（用编号 `节.Q号` 定位，如 `1.1.Q1`）核对。
> 3. 带 **北航真题** 标记的是北航软院复试问过的题，务必能张口就来。
> 4. 每背出一题就打勾 ✅，没把握的保持空框，第二遍只看空框项。

> [!note] 评级与定位
> - **[⭐⭐⭐]** 高频 / 北航真题核心 → 第 1 轮必背
> - **[⭐⭐]** 中频 / 常用 → 第 2 轮复习
> - **[⭐]** 低频可救场 → 临考扫一遍
>
> 章节定位：`1.x = 数理逻辑：命题逻辑`、`5.x = 集合的基本概念及其运算`、`6.x = 关系`、`7.x = 函数`、`8.x = 自然数和基数`、`9.x = 基本概念`、`10.x = 通路问题`、`11.x = 图的矩阵表示`、`12.x = 树`、`13.x = 穿程问题`、`14.x = 二分图匹配`、`4.x = 抽象代数初步`。编号与 [[面试知识点速览版]] 完全一致，可点对点互查。

## 自测方法建议

> [!example]+ 三轮背诵法
> 1. **第 1 轮（⭐⭐⭐）**：先把这 31 题连背 3 次；卡壳 ≥ 3 次的题加入"卡点清单"，次日重背。
> 2. **第 2 轮（⭐⭐）**：过完中频题；重点区分**容易混的对比类**（偏序/全序/良序、等价/偏序、自反/反自反、对称/反对称、单射/满射/双射、欧拉回路/哈密顿回路、Dijkstra/Floyd、Prim/Kruskal、群/环/域）。
> 3. **第 3 轮（⭐）**：考前最后 30 分钟扫一遍，能说出关键词即可。
>
> 自测时用三个角度各默想一遍：
> - **定义**：概念/术语的定义与公式（如幂集 $2^{\#A}$、握手定理 $\sum d = 2m$、哈斯图、主析取范式、康托尔对角线法、Hall 定理）；
> - **对比**：凡是"XX vs YY"都要能说出 3 条以上区别，并点明**为什么**（如为什么 Dijkstra 不能有负权、为什么哈密顿回路没有简单充要条件、整除为什么不是等价关系、Prim 和 Dijkstra 差在哪）；
> - **反例**：每个"不一定"都要能举反例（整除是偏序不是等价（卡在对称性）；$\mathbb{Z}$ 上的 $\leq$ 是全序但不是良序；极大元可以有多个而最大元至多一个）。
