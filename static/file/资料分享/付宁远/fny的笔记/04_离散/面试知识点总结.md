> [!abstract]+ 学科总览  
> 离散数学研究的是"离散对象"——不同于微积分研究连续变化，离散数学处理的是可以一个个数清楚的对象（集合、图、逻辑命题等）。计算机处理的一切都是离散的（0/1、字符、对象），所以离散数学是 CS 的数学基础。
>
> 整门课可以按"**逻辑 → 集合 → 图 → 代数**"四块来理解：
>
> - **数理逻辑（命题逻辑）**是"推理的语言"——研究命题如何组合、如何从前提推出结论，是数学证明本身的规则说明书。**你的笔记没有这块**，但面试真题问过联结词、三段论、公理系统的完备性/独立性，本文第一部分补上了。
> - **集合论（第5-8章）**从"集合"这个最朴素的概念出发，一路构造出更复杂的抽象结构——集合 → 关系 → 函数 → 自然数/基数。这就像盖楼：集合是砖头，关系是梁柱，函数是门窗，一层层往上搭。每一步都是前一步的"特化"或"限制"（关系是有序对的集合，函数是单值的关系）。
> - **图论（第9-14章）**研究"点与点之间的连接关系"。表面上看图论和集合论无关，但**图本质上就是定义在顶点集合上的关系**——有向图的边集 $A$ 就是 $V$ 上的二元关系。所以图论其实可以看作集合论中"关系"概念的可视化呈现。
> - **抽象代数（群环域）**把"运算"本身作为研究对象，是"函数复合"思想的进一步抽象。笔记未覆盖，面试常考，本文最后单独补一节。
>
> 这几块之间的桥梁是**关系**：集合论里的关系可以画成关系图，关系图就是图论的研究对象；等价关系画简图、偏序关系画哈斯图；而"所有双射在复合下成群"又把函数和抽象代数连了起来。
>
> 所以整本书的暗线是：**从逻辑出发 → 用集合建模 → 通过关系搭桥 → 走向图论与代数**。所有概念在这条线上都能找到自己的位置。

## 一、数理逻辑：命题逻辑（笔记未覆盖，面试高频）

> [!warning]+ 重要提醒  
> 你的集合论/图论笔记里没有数理逻辑部分，但面试真题里出现过"命题逻辑的联结词有哪些""什么是三段论""公理系统的完备性、独立性"这类问题。以下是按教材数理逻辑编 + 面试真题整理的简版，**命题逻辑是整门课的开篇，建议把教材前两章看一遍**。

> [!note]+ 章节导引  
> **本部分知识点之间的关系**：命题逻辑是"把推理过程符号化"的尝试，逻辑链条是：  
> 先定义最基本的原子单位——**命题**（能判断真假的陈述句）→ 用**联结词**把原子命题拼成复合命题 → 讨论复合命题的两种"相等"：**等值式**（形式不同但真值相同）和**范式**（每个公式都能化成标准形式）→ 有了等值式就能做**推理**（从前提推出结论，三段论、假言推理都是推理规则）→ 最后为了回答"推理规则本身可靠吗、够不够用"，把整个命题逻辑**公理化**，得到公理系统，并研究它的**可靠性、完备性、独立性**。
>
> **面试常见问法**：命题逻辑的联结词有哪些？（1.1）什么是三段论？（1.3）公理系统的完备性是什么意思？（1.4）

### 1.1 命题与联结词 ⭐⭐⭐⭐（面试高频）

**命题**：能够判断真假的陈述句（真值只有真/假两种，是"二值逻辑"）。疑问句、祈使句、含自由变量的句子（如"$x>3$"）不是命题。

**五个基本联结词**（面试就考这五个）：

| 联结词    | 符号                    | 读法      | 含义                |
| ------ | --------------------- | ------- | ----------------- |
| **否定** | $\neg P$              | 非       | 真值取反              |
| **合取** | $P \land Q$           | 与       | 都真才真              |
| **析取** | $P \lor Q$            | 或       | 至少一个真就真（**可兼或**）  |
| **蕴含** | $P \to Q$             | 若 P 则 Q | 只有 $P$ 真 $Q$ 假时为假 |
| **等价** | $P \leftrightarrow Q$ | 当且仅当    | $P,Q$ 真值相同才真      |

**非基本联结词**（可由上面五个定义）：异或 $\oplus$、与非 $\uparrow$、或非 $\downarrow$。

**优先级**：$\neg > \land > \lor > \to > \leftrightarrow$（有括号先算括号）

> [!tip]+ 面试一句话  
> 命题逻辑有 **5 个基本联结词**：$\neg$（否定）、$\land$（合取）、$\lor$（析取）、$\to$（蕴含）、$\leftrightarrow$（等价）——它们是命题的"运算符"，把原子命题拼成复合命题。
>
> **蕴含 $P\to Q$ 的两个易错点**：① **前提为假时整个蕴含一定为真**（"若 $1+1=3$ 则太阳从西边升起"是真命题）；② $P\to Q$ 与 $Q\to P$ 不等值，但 $P\to Q$ 与逆否 $\neg Q\to\neg P$ **等值**。

### 1.2 等值式与范式 ⭐⭐⭐

**等值式** $A \Leftrightarrow B$：两个公式在任意赋值下真值都相同（即 $A \leftrightarrow B$ 是重言式）。

**常用等值式**（化简公式的工具，必须背熟）：

| 名称       | 公式                                                          |
| -------- | ----------------------------------------------------------- |
| 蕴含等值式    | $P \to Q \Leftrightarrow \neg P \lor Q$                     |
| 假言易位（逆否） | $P \to Q \Leftrightarrow \neg Q \to \neg P$                 |
| 等价等值式    | $P \leftrightarrow Q \Leftrightarrow (P\to Q)\land(Q\to P)$ |
| 德摩根律     | $\neg(P\land Q) \Leftrightarrow \neg P \lor \neg Q$         |
| 双重否定     | $\neg\neg P \Leftrightarrow P$                              |
| 分配律      | $P\land(Q\lor R) \Leftrightarrow (P\land Q)\lor(P\land R)$  |
| 吸收律      | $P\lor(P\land Q) \Leftrightarrow P$                         |

**范式**：任何命题公式都能化成标准形式

- **析取范式 / 合取范式**：分别写成"合取的析取""析取的合取"（**不唯一**）
- **主析取范式**（小项 $m_i$ 之析取）/ **主合取范式**（大项 $M_i$ 之合取）：**唯一**

**用途**：主析取范式中出现全部 $2^n$ 个小项 ⟺ 该公式是**重言式**；一个小项都不出现 ⟺ **矛盾式**。

> [!tip]+ 面试一句话  
> 范式的意义是"给每个命题公式一个唯一的标准写法"，从而把"判断两个公式是否等值""判断是不是重言式"变成机械的查表操作。

### 1.3 推理理论：三段论与推理规则 ⭐⭐⭐⭐（面试高频）

**推理形式**：$P_1, P_2, \dots, P_n \vdash Q$——若前提全真，则结论必真。

**基本推理规则**：

| 名称                | 形式                                                 |
| ----------------- | -------------------------------------------------- |
| **假言推理**（分离规则 MP） | $P \to Q,\ P \Rightarrow Q$                        |
| **拒取式**           | $P \to Q,\ \neg Q \Rightarrow \neg P$              |
| **假言三段论**（传递律）    | $P \to Q,\ Q \to R \Rightarrow P \to R$            |
| **析取三段论**         | $P \lor Q,\ \neg P \Rightarrow Q$                  |
| 附加律 / 化简律         | $P \Rightarrow P \lor Q$；$P \land Q \Rightarrow P$ |

**"三段论"的两层含义**（答全加分）：

1. **假言三段论**（命题逻辑内部）："若 $P$ 则 $Q$，若 $Q$ 则 $R$，故若 $P$ 则 $R$"——即蕴含的**传递性**，是最基本的推理规则之一。
2. **亚里士多德三段论**（传统逻辑的经典形式）：**大前提 + 小前提 ⟹ 结论**。如"所有人都会死（大前提），苏格拉底是人（小前提），故苏格拉底会死（结论）"——靠**中项**（"人"）把两个前提连接起来，是谓词逻辑的经典推理式。

**判断推理是否正确的三种方法**：真值表法、主析取范式法、形式证明法（构造证明，必要时用 CP 规则把结论的前提临时拿来用）。

> [!tip]+ 面试一句话  
> 三段论的核心是**传递**：$P\to Q$、$Q\to R$ 推出 $P\to R$。它和假言推理（$P\to Q, P\Rightarrow Q$）、拒取式（$P\to Q, \neg Q\Rightarrow \neg P$）一起构成最基本的三条推理规则。

### 1.4 公理系统、可靠性与完备性、独立性 ⭐⭐

**为什么要公理化**：靠真值表判断推理，公式一复杂就爆炸。于是把命题逻辑本身当成一个**形式系统**：只挑几条**公理**（推理的起点）+ 一条**推理规则**，其余全部由它推出来——这就是**命题逻辑的公理系统**（公理模型 / 希尔伯特系统）。

**一个经典的三公理系统**（公理模式，$A,B,C$ 为任意公式）：

$$A1:\ A \to (B \to A)$$
$$A2:\ (A \to (B \to C)) \to ((A \to B) \to (A \to C))$$
$$A3:\ (\neg B \to \neg A) \to (A \to B)$$

唯一推理规则：**MP**（由 $A$ 和 $A\to B$ 推出 $B$）。由公理 + MP 逐步推出的公式叫**定理**，记 $\vdash A$。

**三个元定理（面试考点）**：

| 性质                    | 含义                              | 一句话                     |
| --------------------- | ------------------------------- | ----------------------- |
| **可靠性（Soundness）**    | $\vdash A \Rightarrow \vDash A$ | 能证明的一定是重言式——系统"**不出错**" |
| **完备性（Completeness）** | $\vDash A \Rightarrow \vdash A$ | 重言式一定能被证明——系统"**不漏掉**"  |
| **独立性（Independence）** | 某条公理不能由其余公理 + 规则推出              | 少了它系统就变弱，说明这条公理**删不得**  |

**一致性（相容性）**：不存在公式 $A$，使 $A$ 与 $\neg A$ 都可证。

**其他公理化方式**（了解）：自然演绎系统、Gentzen 相继式演算、**归结原理**（自动定理证明的基础，Prolog 的推理内核）。

> [!tip]+ 面试一句话  
> **可靠性 + 完备性 = 语法与语义恰好吻合**：一个公式可证 ⟺ 它是重言式。可靠性保证"证出来的都对"，完备性保证"对的都证得出来"；独立性说"每条公理都删不得"。

## 二、集合论

### 第5章 集合的基本概念及其运算

> [!note]+ 章节导引  
> **本章知识点之间的关系**：这一章是整个离散数学的"原子工厂"——所有后续概念都建立在这。知识点是这样递进的：先定义**集合本身**（相等、包含）→ 然后从集合构造新集合，最关键的就是**幂集**（把子集当元素，造出"集合的集合"）→ 接着引入集合的**运算**（并交差补对称差），并发现这些运算满足一整套**恒等式**（和命题逻辑同构）→ 再引入**笛卡尔积**（把两个集合"配对"成新集合）→ 最后用归纳法定义形式语言，为后续编译原理埋伏笔。你可以看出，"幂集"和"笛卡尔积"是两个关键构造工具——幂集引出后续的"集合族"概念，笛卡尔积直接通往下一章的"关系"。
>
> **与上一章的关系**：无（这是起点）。
>
> **与学科的关系**：集合是离散数学的"砖头"，本章提供的就是造砖头和加工砖头的基本工具。

#### 5.1 集合、幂集与笛卡尔积 ⭐⭐⭐⭐（面试高频）

**集合**：无序、无重复元素的抽象容器。

**幂集** $\rho(A)$：A 的所有子集构成的集合。

$$\#\rho(A) = 2^{\#A}$$

**为什么 $2^{\#A}$？** 因为每个元素有"属于/不属于子集"2 种选择，$n$ 个元素 → $2^n$ 个子集（含 $\varnothing$ 和 $A$ 本身）。

**笛卡尔积** $A \times B = \{\langle x, y \rangle \mid x \in A, y \in B\}$（有序对集合，$\langle x,y\rangle$ 与 $\langle y,x\rangle$ 不同）

$$\#(A \times B) = \#A \cdot \#B$$

> [!tip]+ 面试一句话  
> 幂集把"子集"当作元素，是高阶构造；笛卡尔积把"有序对"当作元素，是构造关系的素材（下一章的"关系"就是 $A\times B$ 的子集）。
>
> 笛卡尔积**不满足交换律**（$A\times B \neq B\times A$，除非 $A=B$ 或有一个是空集）、**不满足结合律**；$A \times \varnothing = \varnothing$。

#### 5.2 集合的运算、恒等式与对偶定理 ⭐⭐⭐

**基本运算**：并 $\cup$、交 $\cap$、差 $-$（$A - B = \{x \mid x \in A \land x \notin B\}$）、补 $\sim A = U - A$。

**对称差** $A + B$（也叫布尔和；在布尔代数里它就是"加法"，在逻辑里就是**异或**）——**恰好属于 $A$、$B$ 之一**的元素集合，有三种等价写法：

$$A + B = (A - B) \cup (B - A) = (A \cup B) - (A \cap B) = (A \cap \sim B) \cup (\sim A \cap B)$$

**怎么理解**：先并起来，再把两者共有的部分（$A \cap B$）整个挖掉——只留下"你有我没有"和"我有你没有"的部分。**它是差运算的对称化**：差 $A - B$ 只管一边，对称差两边同等对待，所以交换 $A$、$B$ 结果不变。

**基本性质**（形式上几乎和数的加法一样，只是"1 加 1 等于 0"）：

| 名称       | 式子                                         |
| -------- | ------------------------------------------ |
| 交换律      | $A + B = B + A$                            |
| 结合律      | $(A + B) + C = A + (B + C)$                |
| 单位元      | $A + \varnothing = A$                      |
| 逆元（就是自己） | $A + A = \varnothing$                      |
| 与全集      | $A + U = \sim A$                           |
| 对交分配     | $A \cap (B + C) = (A \cap B) + (A \cap C)$ |
| 基数公式     | $\#(A + B) = \#A + \#B - 2\#(A \cap B)$    |

> [!tip]+ 为什么叫"对称差"  
> ① **对称**：交换 $A$、$B$ 结果不变（普通的差 $A-B$ 就不对称）；② **差**：本质仍是"减"，只是把公共部分 $A\cap B$ 从两边各减了一次，所以基数公式里减的是 $2\#(A\cap B)$。
>
> **与包含排斥原理的关系**：$\#(A \cup B) = \#(A + B) + \#(A \cap B)$——并集被"恰好属于其一"和"两者共有"两块**无重叠地**分完。所以对称差衡量的是两个集合的"**差异程度**"：$A+B = \varnothing$ 当且仅当 $A = B$。

> [!note]+ 特征函数视角（通向抽象代数）
>
> - **特征函数**：$\chi_{A+B} = \chi_A \oplus \chi_B$，就是逐点做**模 2 加法（异或）**。这正是它满足交换律、结合律、且"自己是自己的逆元"的根本原因——每个元素加两次就抵消为 0（不属于）。
> - **代数结构**：$\langle \rho(U),\ + \rangle$ 构成**阿贝尔群**（单位元 $\varnothing$，每个元素的阶都是 2），再配上与 $\cap$ 的分配律，则 $\langle \rho(U),\ +,\ \cap \rangle$ 是一个**布尔环**——这是"环"最经典的有限实例，第 7.3 节的"所有双射构成群"、第四部分的"群环域"都在这里和集合论接上了。
> - **应用**：奇偶校验 / 异或校验（两边做同一串异或，结果"全空/全 0"即无误）、比对两组数据的差异（版本 diff、权限差异）、经典算法题"只出现一次的数字"（全部异或，成对的互相抵消）。

> [!tip]+ 面试一句话  
> **对称差 $A+B$** = 恰好属于 $A$、$B$ 之一的元素 = $(A\cup B)-(A\cap B)$，是差运算的"对称化"。它在特征函数层面就是**模 2 加法（异或）**，所以满足交换律、结合律、$A+A=\varnothing$，并让幂集 $\rho(U)$ 在 $+$ 下构成阿贝尔群（配上 $\cap$ 就是布尔环）。用途上常拿它衡量两个集合的差异（$\#(A+B)$ 越小越像）。

**核心恒等式**（与命题逻辑同构，可以对照记忆）：

| 集合            | 命题逻辑     |
| ------------- | -------- |
| $\cup$        | $\lor$   |
| $\cap$        | $\land$  |
| ~             | $\neg$   |
| $\varnothing$ | 0        |
| $U$           | 1        |
| $+$（对称差）      | $\oplus$ |

**对偶定理**：不含 $-$ 和 $+$ 的恒等式中，互换 $\cup \leftrightarrow \cap$、$\varnothing \leftrightarrow U$，仍是恒等式。

#### 5.3 包含排斥原理 ⭐⭐⭐

$$\#(A \cup B) = \#A + \#B - \#(A \cap B)$$

$$\#(A_1 \cup \cdots \cup A_n) = \sum \#A_i - \sum \#(A_i \cap A_j) + \sum \#(A_i \cap A_j \cap A_k) - \cdots$$

> [!tip]+ 直觉  
> 直接相加会把"交集"重复算，要减回去；减多了再加；交替到 $n$ 项。

#### 5.4 集合的归纳（递归）定义与形式语言 ⭐⭐

**归纳定义 = 递归定义**（同一概念的两种叫法）：不直接列举元素，而是"**给起点 + 给由旧元素造新元素的规则**"。

**归纳定义的三部分**：

1. **基础语句**：指明原子元素（起点）
2. **归纳语句**：由已有元素生成新元素的规则
3. **极限语句**：声明"集合只包含有限次使用前两条得到的元素"（限定范围，防止混入多余元素）

**典型例子**：自然数集合 $\mathbb{N}$（$0\in\mathbb{N}$；若 $n\in\mathbb{N}$ 则后继 $n^+=n\cup\{n\}\in\mathbb{N}$——详见第8章）、阶乘 $n!$、斐波那契数列、下面要讲的形式语言。

**应用**：字母表 $\Sigma$ 上的语言

- $\Sigma^* = \Sigma^0 \cup \Sigma^1 \cup \cdots$（星闭包，含空串）
- $\Sigma^+ = \Sigma^* - \{\epsilon\}$（正闭包）

> 这是后续编译原理"正规式/自动机"的基础。

### 第6章 关系

> [!note]+ 章节导引  
> **本章知识点之间的关系**：这一章是集合论的"枢纽"，也是面试的重灾区。它的逻辑是这样的：上一章的笛卡尔积 $A \times A$ 的任何子集都叫 $A$ 上的"**二元关系**"——所以关系本质是"有序对的集合"。有了关系之后，我们关心两件事：**它有哪些性质**？**它能怎么运算**？
>
> - 性质方面，提炼出五大属性：自反、反自反、对称、反对称、传递。这五个属性就像五个标签，贴在不同组合上就得到不同类型的关系——**自反+反对称+传递 = 偏序**，**自反+对称+传递 = 等价**，**反自反+传递 = 严格偏序**。这是本章最核心的"组合产生分类"的思想。
> - 运算方面，关系可以做并交差补、复合、求逆，还可以"补全"成具有某性质的**闭包**（自反闭包、对称闭包、传递闭包）。
>
> 偏序和等价是两种最重要的关系，它们各自衍生出一个完整的小理论：偏序对应**哈斯图**和"特殊元"（最大元、极大元、上下界等），等价对应**划分**和"商集"。两者都和图论紧密相连——偏序画哈斯图，等价画简图，这就是集合论通往图论的桥。
>
> **与上一章的关系**：关系建立在第5章的笛卡尔积之上，关系本身就是集合（有序对的集合），所以集合的运算、恒等式都对关系适用。
>
> **与学科的关系**：关系是从集合论走向图论的桥梁，也是后续函数（第7章）的基础——函数就是"单值的关系"。


#### 6.1 关系及其五大性质 ⭐⭐⭐⭐（面试核心）

**关系的定义**：$A$ 到 $B$ 的**二元关系**是笛卡尔积的子集 $R \subseteq A \times B$；当 $A = B$ 时称 **$A$ 上的关系** $R \subseteq A \times A$。所以**关系本质上就是"有序对的集合"**——它本身也是集合，集合的运算（并、交、差、对称差）对关系统统适用。（推广：$n$ 元关系是 $A_1 \times \cdots \times A_n$ 的子集。）

**五大性质**（这是离散数学最常考的辨析！）：

| 性质      | 定义                         | 矩阵特征                                 | 图特征       |
| ------- | -------------------------- | ------------------------------------ | --------- |
| **自反**  | $\forall x, xRx$           | 主对角线全1                               | 每点有自环     |
| **反自反** | $\forall x, x\overline Rx$ | 主对角线全0                               | 每点无自环     |
| **对称**  | $xRy \to yRx$              | 对称矩阵                                 | 无单向边      |
| **反对称** | $xRy \land yRx \to x=y$    | $r_{ij} \land r_{ji} = 0$（$i\neq j$） | 无双向边      |
| **传递**  | $xRy \land yRz \to xRz$    | $M_R^2 \le M_R$                      | 有长路径必有短路径 |

> [!tip]+ 辨析要点
>
> - 自反 vs 反自反：**互斥但可同时不成立**（如 $\{<1,1>, <1,2>\}$ 既不自反也不反自反）
> - 对称 vs 反对称：**互斥但可同时成立**（如只有自环的关系 $\{<1,1>\}$ 两者都满足）
> - 传递是"最难凑齐"的性质，依赖前两条性质的存在

#### 6.2 关系的运算与闭包 ⭐⭐⭐

**基本运算**：$\cap, \cup, -, +$（对称差，矩阵对应异或）

**复合关系**：$R \circ S = \{\langle x, z \rangle \mid \exists y, xRy \land ySz\}$

- 矩阵：$M_{R \circ S} = M_R \cdot M_S$（布尔乘法）

**逆关系**：$R^{-1}$，矩阵转置

**闭包**——把关系"补全"为具有某性质的最小关系：

| 闭包          | 公式                      | 含义     |
| ----------- | ----------------------- | ------ |
| 自反闭包 $r(R)$ | $R \cup I_X$            | 加所有自环  |
| 对称闭包 $s(R)$ | $R \cup R^{-1}$         | 补所有反向边 |
| 传递闭包 $t(R)$ | $\bigcup_{i=1}^{n} R^i$ | 补所有可达边 |

> [!tip]+ 传递闭包的直觉  
> $R^i$ 表示"两步能到、三步能到..."，把所有步数的可达关系并起来，就是"任意步数能到"——即传递闭包。

#### 6.3 偏序关系 ⭐⭐⭐⭐（面试高频）

**偏序关系** = 自反 + 反对称 + 传递，记作 $\langle A, \leq \rangle$

**偏序的内部结构**——可以从三个视角看它的"特殊元"：

- **全集合视角**：最大元/最小元——与所有元素都可比且处于一端（至多1个）
- **局部视角**：极大元/极小元——没有元素比它更大/小（可多个）
- **子集视角**：上界/下界（子集的共同界限）、上确界/下确界（最小上界/最大下界）

**举例：整除偏序 $\langle \{2,3,4,6,12\}, \mid \rangle$**（哈斯图：$12$ 在顶（下接 $4$ 和 $6$），$4$ 下接 $2$，$6$ 下接 $2$ 和 $3$，$2$ 与 $3$ 在最底层且互不相连）

| 视角                  | 概念       | 本例的答案                              |
| ------------------- | -------- | ---------------------------------- |
| 全集合视角               | 最大元      | $12$——**唯一**，因为 $2,3,4,6$ 都整除它     |
| 全集合视角               | 最小元      | **不存在**——$2$ 与 $3$ 不可比，没有元素能整除所有元素 |
| 局部视角                | 极大元      | $12$——**唯一**，没有元素比它更大              |
| 局部视角                | 极小元      | $2$ 和 $3$——**两个**，没有元素比它们更小        |
| 子集视角（取 $S=\{2,3\}$） | 上界       | $6$ 和 $12$——**两个**（$2$、$3$ 都整除它们）  |
| 子集视角（取 $S=\{2,3\}$） | 上确界      | $6$——最小上界，**唯一**                   |
| 子集视角（取 $S=\{2,3\}$） | 下界 / 下确界 | 都**不存在**（集合里没有 $1$，$S$ 无任何下界）      |

**换两个例子看边界情况**：

- **去掉 $12$**，即 $\langle \{2,3,4,6\}, \mid \rangle$：**最大元不存在**（$4$ 与 $6$ 不可比），但**极大元有两个**（$4$、$6$）；此时子集 $S=\{4,6\}$ 也**没有上界**，故上确界不存在。→ 说明"最大元至多一个、极大元可多个"，且**上确界的存在性是有条件的**（只有上界存在才谈得上最小上界）。
- **子集偏序 $\langle \rho(U), \subseteq \rangle$**（$U=\{1,2,3\}$）：最大元 $=U$、最小元 $=\varnothing$；取 $S=\{\{1\},\{2\}\}$，上界是 $\{1,2\}$ 和 $\{1,2,3\}$，**上确界 $=\{1,2\}$**，下界只有 $\varnothing$，**下确界 $=\varnothing$**。→ 任意两元素都有上确界和下确界的偏序集，叫**格（lattice）**。

**哈斯图绘制步骤**：

1. 每个元素画一个点
2. 若 $x < y$，把 $y$ 画在 $x$ 上方
3. 若 $y$ **遮盖** $x$（$x < y$ 且中间无其他元素），连一条线
4. **省略自环**（偏序默认自反）

**特殊元对比**（面试易混淆）：

| 概念  | 范围   | 关键                 |
| --- | ---- | ------------------ |
| 最大元 | 整个集合 | 比所有元素都 ≥（**至多1个**） |
| 极大元 | 整个集合 | 没有元素比它更大（**可多个**）  |
| 上界  | 子集   | 子集中所有元素 ≤ 它        |
| 上确界 | 子集   | 最小上界（**至多1个**）     |

> [!tip]+ 辨析  
> 最大元一定唯一且是极大元；极大元可能有多个。上界/上确界是**对某个子集**说的，上界可以有多个，上确界至多一个、但**可能不存在**。

**四种"序"的辨析**（面试常混着问）：

- **偏序 = 半序**：同一概念的两种叫法（partial order，也译"半序"），偏序集也叫半序集。
- **全序/线序**：任意两元素都可比（如 $\mathbb{Z}$ 上的 $\leq$）。
- **良序**：**每个非空子集**都有最小元（如 $\mathbb{N}$ 上的 $\leq$）。
- **严格偏序** $<$：反自反 + 传递（如 $\mathbb{N}$ 上的 $<$），是偏序去掉自反性、去掉 $\leq$ 中的"等于"。

**包含关系**：良序 ⊂ 全序 ⊂ 偏序（良序必是全序，全序必是偏序，反之都不成立）。

**三个典型例子**：

- 集合的 $\subseteq$：偏序，但一般不是全序（$\{1\}$ 与 $\{2\}$ 不可比）
- 整数 $\mathbb{Z}$ 上的 $\leq$：全序，但不是良序（$\mathbb{Z}$ 本身没有最小元）
- **整除 $\mid$**：正整数上自反、反对称、传递 → **是偏序**但**不是**等价关系（见 6.4）

#### 6.4 等价关系 ⭐⭐⭐⭐（面试高频）

**等价关系** = 自反 + 对称 + 传递

**等价类** $[x]_R = \{y \in A \mid xRy\}$

**集合的划分**：把集合 $A$ 切成一族**非空子集**，要求：

1. 两两**不交**（任意两块交集为空）
2. **并起来恰好等于 $A$**（不重不漏）

划分中的每一块叫一个"块"，$A$ 中每个元素**恰好**属于一个块。

**核心定理**：集合 $A$ 上的等价关系 $R$ 与 $A$ 的划分**一一对应。**给定等价关系R，得到的等价类集合（商集 $A/R$）就是集合的一个划分；反过来，任何一个划分也对应一个等价关系（"在同一块"）。两者是同一事物的两个视角。

**商集** $A/R$ = 所有等价类构成的集合 = 一个划分

**典型例子**：整数模 $m$ 的同余关系 $\equiv_m$——把整数分成 $m$ 个等价类（余数相同的归一类），得到商集 $\mathbb{Z}/\equiv_m$。

**整除是等价关系吗？——不是**（面试爱考的反例）：

- 整除 $\mid$ **满足自反**（$a \mid a$）、**满足传递**（$a\mid b$ 且 $b\mid c$ ⟹ $a\mid c$）
- 但**不满足对称**：$2 \mid 4$ 成立，而 $4 \mid 2$ 不成立
- 所以整除**不是等价关系**，而是**偏序关系**（自反 + 反对称 + 传递）
- 想找与整除相关的等价关系，要用**同余** $\equiv_m$：$a \equiv b \pmod m \iff m \mid (a-b)$，同余满足对称性，是等价关系

> [!tip]+ 面试一句话  
> 记住三句：**等价 = 自反 + 对称 + 传递**（分堆，对应划分）；**偏序 = 自反 + 反对称 + 传递**（排队，对应哈斯图）；**整除是偏序不是等价**（卡在对称性上），**同余才是等价关系**。

### 第7章 函数

> [!note]+ 章节导引  
> **本章知识点之间的关系**：函数在离散数学里是关系的"特化"——关系允许一个 $x$ 对应多个 $y$，但函数要求**单值性**（每个 $x$ 唯一对应一个 $y$）。本章的逻辑是：先定义函数本身 → 再讨论函数的"质量"——满射（覆盖全）、单射（不重复）、双射（两者兼具）→ 然后研究函数的**复合**和**逆**。这里最重要的定理是"双射 ⟺ 可逆"，它把"双射"和"有逆函数"等同起来。本章最后还埋了个伏笔：**所有 $X \to X$ 的双射函数集合在复合运算下构成群**——这个结论是抽象代数（群环域）的入口！群的概念其实就是"双射复合"思想的抽象推广。
>
> **与上一章的关系**：函数就是满足单值性的关系。本章是第6章的特化与深化。
>
> **与学科的关系**：函数概念连接了集合论和抽象代数。同时，函数的"单射/满射/双射"思想会在后续所有 CS 课程中反复出现（如数据结构的哈希函数、数据库的函数依赖）。

#### 7.1 函数与特殊性质 ⭐⭐⭐

**函数** = 满足单值性的关系（每个 $x$ 唯一对应一个 $y$）

| 类型     | 定义                            | 几何直觉（$f:\mathbb{R}\to\mathbb{R}$） |
| ------ | ----------------------------- | --------------------------------- |
| **满射** | $ran(f) = Y$                  | 每条水平线至少1个交点                       |
| **单射** | $x \neq y \to f(x) \neq f(y)$ | 每条水平线至多1个交点                       |
| **双射** | 单射+满射                         | 每条水平线恰好1个交点                       |

#### 7.2 复合与逆 ⭐⭐⭐

**复合保持性质**：满射 ∘ 满射 = 满射；单射 ∘ 单射 = 单射；双射 ∘ 双射 = 双射

**逆函数存在条件**：$f$ 双射 ⟺ $f^{-1}$ 是函数

> [!tip]+ 关键定理  
> $f$ 单射 ⟹ $f^{-1}$ 单值；$f$ 满射 ⟹ $f^{-1}$ 处处有定义；**$f$ 双射 ⟹ $f^{-1}$ 也是双射**。

#### 7.3 双射集合构成群 ⭐⭐⭐

设 $F_X$ = 所有 $X \to X$ 的双射函数。则 $\langle F_X, \circ \rangle$ 构成群：

- 封闭性：双射复合仍是双射
- 结合律：函数复合可结合
- 单位元：恒等函数 $I_X$
- 逆元：每个双射有反函数

> [!tip]+ 抽象代数的入口  
> "群"的典型实例就是"所有双射构成的集合"。后续 群环域 都从这里推广。

### 第8章 自然数和基数

> [!note]+ 章节导引  
> **本章知识点之间的关系**：前几章研究具体的集合，本章换一个视角问"**集合有多大**"。逻辑链条：先把"一样大"翻译成精确的数学语言——**等势**（存在双射）→ 由此得到**基数（势）**这个概念 → 用"能否与自然数一一对应"把无穷集分成**可数集**与**不可数集** → 最后康托尔定理告诉我们幂集总比原集合大，于是**有无穷多个层级的"无穷"**（没有最大的基数）。
>
> 本章最反直觉的两个结论：① **自然数和有理数一样多**（都是可数集 $\aleph_0$）——有理数明明"稠密"，却能和自然数一一配对；② **实数和自然数不一样多**（$\mathbb{R}$ 不可数）——无穷也分大小。
>
> **与上一章的关系**：等势的定义直接用到第7章的**双射**概念；基数就是"等势"这个等价关系的等价类。
>
> **与学科的关系**：回答"无穷能不能比较大小"，是数学基础的重要成果，也是可计算性理论（可判定性、停机问题）的起点。

#### 8.1 基数与等势 ⭐⭐⭐⭐（面试高频）

**集合的大小称为基数**，也叫**势**（cardinality），记 $\#A$。

**等势**：$A$ 与 $B$ **等势** ⟺ 存在 $A \to B$ 的**双射**，记 $A \sim B$。等势的集合被认为"一样大"。

- **等势关系是等价关系**（自反：恒等映射；对称：逆映射；传递：复合映射），所以可按等势给集合分类——基数就是这个等价类（通常取代表集合，如自然数 $n$ 代表所有 $n$ 元集）。
- **有穷集 vs 无穷集**：与某个自然数等势的叫**有穷集**；**无穷集的本质特征是"与自己的某个真子集等势"**（如 $\mathbb{N} \sim \mathbb{E}$，$\mathbb{E}$ 为非负偶数集；整体"等于"部分，这正是无穷的标志）。
- **鸽巢原理**：$n+1$ 只鸽子进 $n$ 个笼，必有一笼至少 2 只；等价说法是"若 $\#A > \#B$，则不存在 $A \to B$ 的单射"。

#### 8.2 可数集：自然数和有理数一样多吗？⭐⭐⭐⭐（面试真题）

**先给答案：一样多。** 即 $\#\mathbb{N} = \#\mathbb{Z} = \#\mathbb{Q} = \aleph_0$（读作"阿列夫零"）。

**可数集**：能与自然数集 $\mathbb{N}$ 建立双射的集合——等价说法是"可以排成一个**不重不漏的无穷序列** $a_0, a_1, a_2, \dots$"，每个元素都有编号。

**怎么证明？** 核心动作就两个：**构造双射**，或等价地**给出一个不重不漏的枚举顺序**。

| 集合                  | 证明思路                                                            |
| ------------------- | --------------------------------------------------------------- |
| 整数 $\mathbb{Z}$     | 排成 $0,\ 1,\ -1,\ 2,\ -2,\ 3,\ -3, \dots$（正负交替，可写出通项）            |
| 正有理数 $\mathbb{Q}^+$ | 把分数按"分子 + 分母递增"摆成**方阵**，沿**对角线蛇形**读过去；遇到等值分数（$1/2 = 2/4$）**去重** |
| 有理数 $\mathbb{Q}$    | 在正有理数枚举中插入 $0$ 与负数：$q_0,\ 0,\ -q_0,\ q_1,\ -q_1, \dots$         |

**面试要说的三个关键点**：

1. 有理数虽然**稠密**（任意两个有理数之间还有有理数），但"稠密"不等于"更多"——可数性只看**能不能编号**。
2. 无穷集的标志是"**能与自己的真子集一样多**"，所以在无穷世界"部分小于整体"失效。
3. **可数个可数集的并仍可数**（这是 $\mathbb{Q}$ 可数的另一种证法：$\mathbb{Q} = \bigcup_{q} \{p/q\}$，可数多个可数集合的并仍可数）。

> [!tip]+ 面试一句话  
> **一样多**。$\mathbb{N}$、$\mathbb{Z}$、$\mathbb{Q}$ 都能与自然数一一对应，基数都是 $\aleph_0$（可数无穷）。证明方法：把元素排成**不重不漏的无穷序列**——整数正负交替；有理数按"分子分母之和递增"蛇形对角线枚举并去重，等价于构造 $\mathbb{N} \to \mathbb{Q}$ 的双射。

#### 8.3 不可数集与康托尔定理 ⭐⭐⭐

**实数不可数**（$\#\mathbb{R} = 2^{\aleph_0} > \aleph_0$），用**康托尔对角线法**证明：

1. 反证，假设 $(0,1)$ 内实数可枚举：$r_1, r_2, r_3, \dots$
2. 把每个 $r_i$ 写成小数 $0.d_{i1}d_{i2}d_{i3}\dots$
3. 构造新数 $r = 0.d_1d_2d_3\dots$，令第 $i$ 位 $d_i$ 与 $d_{ii}$ **不同**（对角线上"取反"，并避开 0/9 以免进位歧义）
4. 则 $r$ 与每个 $r_i$ 至少在第 $i$ 位不同，故 $r$ 不在列表中——矛盾。所以 $(0,1)$ 不可数，$\mathbb{R}$ 更不可数。

**康托尔定理**：$\#\rho(A) > \#A$——**幂集总比原集合"大"**（对无穷集也成立）。证法同为对角线：任意 $A \to \rho(A)$ 的映射都不是满射（构造 $B = \{x \mid x \notin f(x)\}$，则 $B \in \rho(A)$ 却不在值域内）。推论：**不存在最大的基数**，无穷有层级 $\aleph_0 < 2^{\aleph_0} < 2^{2^{\aleph_0}} < \cdots$

**常见基数速记**：$\#\mathbb{N} = \#\mathbb{Z} = \#\mathbb{Q} = \aleph_0$（可数）；$\#\mathbb{R} = \#(0,1) = \#\mathbb{R}^2 = 2^{\aleph_0}$（不可数，连续统）；$\#\rho(\mathbb{N}) = 2^{\aleph_0}$。

> [!tip]+ 面试一句话  
> 实数不可数，用**康托尔对角线法**：假设能列完，就构造一个"每一位都与对应实数不同"的新数，它必不在列表中。康托尔定理进一步指出 $\#\rho(A) > \#A$——**幂集严格更大，无穷也分等级**。

## 三、图论

### 第9章 基本概念

> [!note]+ 章节导引  
> **本章知识点之间的关系**：这一章是图论的"字母表"——它定义后续所有图论讨论所需的基础语言。知识点是这样铺开的：先定义**图本身**（有向/无向、顶点、边）→ 再定义点与点、点与边、边与边之间的三种关系（**邻接、关联、相邻**）→ 然后定义顶点的**次数**（度数），并得到图论最重要的定理——**握手定理**（所有次数之和等于 2 倍边数）→ 接着讨论图与图之间的关系（**子图、补图、同构**）→ 最后研究**连通性**——这是图论的核心性质，有向图分强/单向/弱连通，无向图通过割点和桥来衡量连通的"脆弱程度"。本章是后续所有图论章节的地基。
>
> **与上一章的关系**：图可以看作定义在顶点集合 $V$ 上的二元关系（有向图的弧集 $A \subseteq V \times V$）。所以本章和集合论通过"关系"自然衔接——这也是为什么很多教材把图论放在集合论之后讲。
>
> **与学科的关系**：本章提供图论的基础语言，后续章节（通路、矩阵、树、穿程、匹配）都建立在这些概念之上。

#### 9.1 握手定理 ⭐⭐⭐⭐（面试极高频）

$$\sum_{i=1}^{n} d(u_i) = 2m \quad \text{（无向图，m 条边）}$$

$$\sum_{i=1}^{n} od(u_i) = \sum_{i=1}^{n} id(u_i) = m \quad \text{（有向图）}$$

> [!tip]+ 推论与直觉  
> **推论**：奇顶点（次数为奇数）的个数必为偶数。
>
> **直觉**：每条边贡献 2 次到总次数中（两端各 1 次），所以总和必为偶数。奇顶点要"两两配对"才能凑齐偶数总和。

#### 9.2 连通性 ⭐⭐⭐

**有向图的三种连通**：

| 类型       | 条件         | 判定（充要） |
| -------- | ---------- | ------ |
| **强连通**  | 任意两点互相可达   | 有完备回路  |
| **单向连通** | 任意两点至少一方可达 | 有完备通路  |
| **弱连通**  | 忽略方向后连通    | 有完备半通路 |

**无向图**：只有"连通"概念，连通关系是等价关系 → 连通分支 = 等价类

**割点 / 桥**：删去后使图不连通的点/边

### 第10章 通路问题


> [!note]+ 章节导引  
> **本章知识点之间的关系**：上一章定义了"通路"这个概念，本章专门研究通路的两类应用问题：**最短通路**（带权图中求两点的最短路径，对应 Dijkstra/Floyd 算法）和**关键通路**（AOE 网中求工程的最短完成时间，对应项目管理）。两个问题一脉相承——都是"在有向带权图上求某种极值路径"。最短通路求"最短"，关键通路求"最长"。关键通路还会衍生出"最早完成时间 / 最迟完成时间 / 缓冲时间"三个概念，核心思想是"找出没有缓冲的事件，它们就是关键通路"。
>
> **与上一章的关系**：本章是第9章"通路"概念的应用深化。
>
> **与学科的关系**：这是图论联系实际工程的桥梁——最短路径对应导航、路由；关键路径对应工程调度。

#### 10.1 关键通路 ⭐⭐⭐

**工序流线图**（AOE 网）：无回路、有唯一发点和收点、每弧权非负的有向图。

- **最早完成时间 $TE(u_j)$**：发点到 $u_j$ 的**最长**通路长度
- **最迟完成时间 $TL(u_j)$**：不推迟收点最早完成时间的前提下，发点最迟到 $u_j$ 的时间
- **缓冲时间 $TS(v) = TL(v) - TE(v)$**：可以推迟的时间

**关键通路** = 发点到收点的最长通路，其上所有事件 $TE = TL$（缓冲为 0）。

#### 10.2 最短通路：Dijkstra 与 Floyd ⭐⭐⭐（面试高频）

**松弛（relax）**：所有最短通路算法的共同动作——若 $d(s,u) + w(u,v) < d(s,v)$，就用前者更新 $d(s,v)$。一句话就是"经由 $u$ 绕一下会不会更近"。

**Dijkstra：单源最短路，贪心**

- **思想**：把顶点分成"已确定"集合 $S$ 和"未确定"集合 $T$，每次从 $T$ 中取当前 $d$ 最小的顶点并入 $S$，再用它松弛所有邻居。重复 $n-1$ 次。
- **为什么对**：权**非负**时，当前 $d$ 最小的点不可能再被绕路改小——任何绕行都得先经过 $T$ 中 $d$ 比它更小的点，而权非负保证"绕一圈不会更短"。
- **复杂度**：朴素实现 $O(n^2)$（邻接矩阵，适合稠密图）；二叉堆 + 邻接表 $O(m \log n)$。
- ⚠️ **不能有负权边**：负权会让"最小点已确定"这个前提失效，此时要改用 Bellman-Ford（还能顺带判负圈）。

**Floyd：全源最短路，动态规划**

- **状态**：$d_k(i,j)$ = 只允许借前 $k$ 个顶点当中转时，$i$ 到 $j$ 的最短长度。
- **转移方程**（对中转点 $k$ 做决策：用还是不用）：

$$d_k(i,j) = \min\{d_{k-1}(i,j),\ d_{k-1}(i,k) + d_{k-1}(k,j)\}$$

- **实现要点**：三重循环，**最外层必须是中转点 $k$**。若把它写在内层，$d(i,k)$、$d(k,j)$ 会被本轮提前更新，结果错。
- **复杂度** $O(n^3)$；**可处理负权边，但不能有负圈**（有负圈则最短路无定义，检查 $d(i,i) < 0$ 即可发现）。
- **与第 11 章的联系**：这个转移和矩阵乘法同构，只是把"乘再求和"换成"加再取最小"（min-plus 代数），所以 Floyd 本质是在邻接矩阵上做了一次"广义矩阵幂"。

|      | Dijkstra                | Floyd          |
| ---- | ----------------------- | -------------- |
| 求解范围 | **单源**（一个起点到所有点）        | **全源**（所有点对）   |
| 算法策略 | 贪心：逐个"确定"最近的点           | 动态规划：逐个"放行"中转点 |
| 权值限制 | 必须非负                    | 可负权，不可有负圈      |
| 复杂度  | $O(n^2)$ / $O(m\log n)$ | $O(n^3)$       |
| 适合场景 | 单点查询、稀疏图用堆优化            | 顶点数少、要查所有点对    |

> [!tip]+ 面试一句话  
> Dijkstra 是"每次敲定一个最近的点，绝不反悔"——能反悔的底气来自非负权；Floyd 是"逐步放宽中转限制"，用 $n$ 轮 DP 换全景答案。

### 第11章 图的矩阵表示

> [!note]+ 章节导引  
> **本章知识点之间的关系**：本章是把图论"代数化"的工具章节。核心就两个矩阵：**邻接矩阵**（点对点）和**关联矩阵**（点对边）。邻接矩阵最重要的定理是 $M^k$ 的元素等于长度为 $k$ 的通路条数——这把"图上走 $k$ 步有几条路"变成了"矩阵乘 $k$ 次看元素"。关联矩阵则用于关联顶点和边，主要在电路分析等场景用。
>
> **与上一章的关系**：本章提供工具，让第10章的"通路计数"可以用矩阵运算机械地求解。
>
> **与学科的关系**：图论的"计算工具"。把图论问题变成矩阵代数问题，是后续 PageRank、图谱理论等方向的起点。

#### 11.1 邻接矩阵 ⭐⭐

**邻接矩阵** $M$：$m_{ij} = 1$ 当 $u_i$ 邻接 $u_j$

**关键定理**：$M^k$ 的第 $i$ 行 $j$ 列元素 = 从 $u_i$ 到 $u_j$ **长度为 $k$ 的通路条数**

> [!tip]+ 直觉  
> 矩阵乘法本质是"路径计数"——$(M^2)_{ij} = \sum_k m_{ik} m_{kj}$ 就是"经过中转点 $k$ 的两步路径数"。

### 第12章 树

> [!note]+ 章节导引  
> **本章知识点之间的关系**：树是图的"特例"——连通且无圈。本章先给出树的多种等价定义（每种定义从不同角度刻画"树"），然后讨论两类重要树：**生成树**（包含所有顶点的子树）和**最优树**（带权图的最小生成树）。最小生成树的两个经典算法（Prim、Kruskal）这里也会涉及，但在算法部分讲得更细。
>
> **与上一章的关系**：树建立在第9章的图概念之上，是图的特例。
>
> **与学科的关系**：树是图论和数据结构的交叉点——数据结构里的二叉树、B+ 树等都是树的特例。理解树的性质是理解数据结构的基础。

#### 12.1 树的等价定义 ⭐⭐⭐

**树** = 连通无圈无向图

**等价定义**（任一即可推出其他）：

- 连通且无圈
- 连通且 $n$ 个顶点有 $n-1$ 条边
- 无圈且 $n$ 个顶点有 $n-1$ 条边
- 任意两点间恰有一条基本链
- 连通，删去任一边即不连通
- 无圈，加任一边即产生圈

**生成树**：连通图的包含所有顶点的子树  
**最小生成树**：边权之和最小的生成树（Prim/Kruskal 算法）

#### 12.2 最小生成树：Prim 与 Kruskal ⭐⭐⭐（面试高频）

两者都是**贪心**，共用同一条定理作依据：**任取一个"切割"（把顶点分成两半），跨越切割的最小权边必属于某棵最小生成树**。区别只在贪心的对象——**Prim 贪点，Kruskal 贪边**。

**Prim：点扩展**

- 从任意顶点出发，每次把"**离当前这棵树最近**的树外顶点"和那条边一并收进树里，重复 $n-1$ 次，收满 $n$ 个点即得最小生成树。
- 维护的权值 $d[v]$ = 顶点 $v$ 到**树**的最小边权（**不是**到起点的路径长度——这是与 Dijkstra 最容易混的一点，两者只有"松弛比较的基准不同"这一处差别）。
- 复杂度：朴素 $O(n^2)$，**适合稠密图**。

**Kruskal：边扩展**

- 把所有边按权**升序**排列，依次考察：两端点**还不在同一连通块**就选入（否则这条边会成圈，丢弃）。选够 $n-1$ 条边即结束。
- 用**并查集**（union-find）判断两点是否已连通，近乎 $O(1)$。
- 复杂度 $O(m\log m)$，主要由排序决定，**适合稀疏图**。

|      | Prim           | Kruskal       |
| ---- | -------------- | ------------- |
| 贪心对象 | 顶点（把一棵树越滚越大）   | 边（把若干小树合并成一棵） |
| 关键操作 | 找"离树最近的点"      | 边排序 + 并查集判圈   |
| 复杂度  | $O(n^2)$       | $O(m\log m)$  |
| 适合   | **稠密图**（点数少边多） | **稀疏图**（边少）   |
| 中途状态 | 始终是一棵连通的树      | 一片森林，最后才连成一棵  |

> [!tip]+ 面试一句话  
> 最短通路（Dijkstra/Floyd）求"两点间最省的路"，是**路径**问题；最小生成树（Prim/Kruskal）求"把所有点连起来最省的边集"，是**连通**问题。前者结果是一条路，后者结果是一棵树。

### 第13章 穿程问题

> [!note]+ 章节导引  
> **本章知识点之间的关系**：本章研究图的两类"遍历"问题——**欧拉回路**（每条边走一次回到原点）和**哈密顿回路**（每个顶点走一次回到原点）。这两个问题看似相似（都是"遍历+回路"），实际难度天差地别：欧拉回路有完美的判定条件（连通+所有顶点次数为偶数），是多项式时间可解的；哈密顿回路没有简单的充要条件（只有 Dirac 等充分条件），是 NP 完全问题。这是面试最爱考的"对比辨析"。
>
> **与上一章的关系**：本章是第9章连通性概念的延伸——欧拉回路需要图连通，哈密顿回路也需要图连通。
>
> **与学科的关系**：图论的经典问题，也是算法复杂度理论的标志性案例（欧拉 vs 哈密顿 = P vs NP）。

#### 13.1 欧拉图与哈密顿图 ⭐⭐⭐⭐（面试必考辨析）

**四个定义（先分清对象）**：

- **欧拉通路/欧拉回路**：经过图中**每条边一次且仅一次**的通路/回路（顶点**可以**重复经过）。包含欧拉回路的图叫**欧拉图**（一笔画回到起点）。
- **哈密顿通路/哈密顿回路**：经过图中**每个顶点一次且仅一次**的通路/回路（边**不要求**用完）。包含哈密顿回路的图叫**哈密顿图**。

**对比表**：

|      | 欧拉回路       | 哈密顿回路                            |
| ---- | ---------- | -------------------------------- |
| 遍历对象 | **每条边**一次  | **每个顶点**一次                       |
| 充要条件 | ✅ 连通 + 偶顶点 | ❌ 无简单充要                          |
| 充分条件 | /          | Dirac：$\forall v, d(v) \geq n/2$ |
| 典型问题 | 七桥问题       | 旅行商问题                            |
| 复杂度  | 线性可判定      | NP-complete                      |

> [!tip]+ 面试一句话  
> 欧拉图 = 能"一笔画回到原点"走完**所有边**（判定：连通 + 所有顶点次数为偶数）；哈密顿图 = 能走遍**所有顶点**回到起点（无简单充要条件，只有充分条件，NP 完全）。一个是"边遍历"、一个是"点遍历"，难度天差地别。

**欧拉回路的判定**：

- **有欧拉回路** ⟺ 图连通 + 所有顶点次数为偶数
- **有欧拉通路（非回路）** ⟺ 图连通 + 恰有 2 个奇顶点（起点终点）

### 第14章 二分图匹配

> [!note]+ 章节导引  
> **本章知识点之间的关系**：本章是图论的应用专题——研究二分图（顶点二分、边只跨两部分）中的匹配问题。核心概念是"匹配"（无公共端点的边集），核心定理是 Hall 定理（相异性条件），它给出了二分图存在完备匹配的充要条件。这是图论里少数有完美判定条件的问题之一。
>
> **与上一章的关系**：本章是图论的应用深化，用到前面所有图论概念。
>
> **与学科的关系**：二分图匹配是图论的重要应用，对应现实中的"分配问题"（任务分配、学生选课、稳定婚姻等）。

#### 14.1 二分图与匹配 ⭐⭐

**二分图**：无向图的顶点可以拆成两个互不相交的顶点集合 $X,Y$。所有边**一定跨在 X 和 Y 之间**，同一集合内部**没有边**。一个**无向图是二分图**，**当且仅当图里不含奇数长度的圈（奇圈）**。

**匹配 **$M$：是图的边集的一个子集。要求**集合里任意两条边，不能共用顶点（没有公共端点）**。

**Hall 定理（相异性条件）**：$X$ 到 $Y$ 存在匹配 ⟺ 对 $X$ 任意子集 $U$，$\#\Gamma(U) \geq \#U$（邻域不小于子集大小）  
（X 中随便挑一组人，他们能做的任务总数，不能少于这组人的人数。）

## 四、抽象代数初步：群、环、域

> [!warning]+ 为什么单列一节  
> 你的集合论/图论笔记里没有代数系统部分，但**北航软院面试真题问过"群、环、域的定义"**，第 7.3 节的"所有双射构成群"也已经摸到了群的门口。下面按"群 → 环 → 域"逐级加条件整理。

> [!note]+ 章节导引  
> **本部分知识点之间的关系**：逻辑链条是"**条件层层加码**"——只要求"一个集合 + 一个运算"闭合并满足三条性质 → **群**；在群的基础上再加**第二个运算**、并用**分配律**把两个运算连起来 → **环**；环里再要求"**非零元都能除**" → **域**。所以三者是 域 ⊂ 环 ⊂ 群（在加法下看）的关系。
>
> **与前文的关系**：$\langle \rho(U), + \rangle$（对称差）是阿贝尔群、配上 $\cap$ 是布尔环（5.2）；所有双射在复合下成群（7.3）——抽象代数研究的"运算本身"，在这两处已经提前出现过。

#### 4.1 群的定义与例子 ⭐⭐⭐⭐（面试高频）

**代数系统**：一个集合 $S$ + 定义在 $S$ 上的运算，如 $\langle \mathbb{Z}, + \rangle$。

**群** $\langle G, \circ \rangle$ = 集合 $G$ 上有一个二元运算 $\circ$，满足四条：

1. **封闭性**：$\forall a,b \in G,\ a \circ b \in G$
2. **结合律**：$(a \circ b) \circ c = a \circ (b \circ c)$
3. **单位元**：存在 $e$，使 $e \circ a = a \circ e = a$
4. **逆元**：每个 $a$ 都有逆元 $a^{-1}$，使 $a \circ a^{-1} = a^{-1} \circ a = e$

（中间态：只满足前两条叫**半群**；再加单位元叫**含幺半群**——面试常拿这两个来对比"群少了什么"。）

**阿贝尔群（交换群）**：再满足**交换律** $a \circ b = b \circ a$。

**典型例子**：

| 例子                       | 是否成群     | 说明                                   |
| ------------------------ | -------- | ------------------------------------ |
| $\langle \mathbb{Z}, + \rangle$ | ✅ 阿贝尔群   | 单位元 $0$，逆元 $-a$                      |
| $\langle \mathbb{Z}, \times \rangle$ | ❌        | 只有 $\pm 1$ 有乘法逆元，$2$ 没有               |
| $\langle F_X, \circ \rangle$ | ✅        | $X$ 上全体**双射**，单位元 $I_X$、逆元 $f^{-1}$（7.3） |
| $\langle \rho(U), + \rangle$ | ✅ 阿贝尔群   | **对称差**为单位元，单位元 $\varnothing$、每元素逆元是自己（5.2） |
| $\langle \mathbb{Z}_m, +_m \rangle$ | ✅        | 模 $m$ 剩余类加法，单位元 $[0]$                 |

**阶**：群的元素个数 $|G|$ 叫群的阶；元素 $a$ 的阶 = 使 $a^k = e$ 成立的**最小正整数** $k$。

#### 4.2 环与域 ⭐⭐⭐（面试高频）

**环** $\langle R, +, \cdot \rangle$：集合上有**两个**运算，满足

1. $\langle R, + \rangle$ 是**阿贝尔群**
2. $\langle R, \cdot \rangle$ 满足**结合律**（乘法半群）
3. **分配律**：$a \cdot (b + c) = a\cdot b + a\cdot c$，$(b + c)\cdot a = b\cdot a + c\cdot a$

（附加叫法：乘法可交换 → **交换环**；有乘法单位元 → **含幺环**。如 $\langle \mathbb{Z}, +, \times \rangle$ 是含幺交换环。）

**域** $\langle F, +, \cdot \rangle$：**含幺交换环** + **每个非零元都有乘法逆元**（等价说法：$F - \{0\}$ 在乘法下构成群）。通俗说就是"域上可以做加、减、乘、除四则运算（除数非零）"。

**环 vs 域的一句话**：域里"**非零元都能除**"，环不保证。$\mathbb{Q}$、$\mathbb{R}$、$\mathbb{C}$ 是域；$\mathbb{Z}$ 只是环——$2$ 在整数里没有乘法逆元。

**三者关系**：条件层层加码——一个运算 → **群**；两个运算 + 分配律 → **环**；环里非零元可除 → **域**。第 5.2 节的 $\langle \rho(U), +, \cap \rangle$ 是**布尔环**，是"环"最经典的有限实例。

> [!tip]+ 面试一句话  
> **群** = 一个运算 + 封闭 + 结合 + 单位元 + 逆元；**环** = 加法成群 + 乘法半群 + 分配律；**域** = 含幺交换环 + 非零元都有逆元。答题时先给这三句，再各举一例（群：$\langle \mathbb{Z},+ \rangle$；环：$\langle \mathbb{Z},+,\times \rangle$；域：$\langle \mathbb{Q},+,\times \rangle$）。

## 附：离散数学面试速查表

| 问题                | 一句话回答                                                                           |
| ----------------- | ------------------------------------------------------------------------------- |
| 命题逻辑联结词           | 5 个：$\neg$、$\land$、$\lor$、$\to$、$\leftrightarrow$                               |
| 三段论               | 假言三段论：$P\to Q$、$Q\to R$ ⟹ $P\to R$（蕴含传递）；另一义是亚里士多德"大前提+小前提⟹结论"                  |
| 可靠性 vs 完备性        | 可靠性：可证的⇒重言式；完备性：重言式⇒可证（二者合起来：可证 ⟺ 重言式）                                          |
| 公理独立性             | 某公理不能由其余公理和规则推出，说明它删不得                                                          |
| 幂集基数              | $\#\rho(A) = 2^{\#A}$                                                           |
| 康托尔定理             | $\#\rho(A) > \#A$（幂集严格大于原集，无最大基数）                                               |
| 对称差               | $A + B = (A-B) \cup (B-A)$，即"恰好属于其一"的元素；等价于特征函数做模 2 加法（异或），满足 $A+A=\varnothing$ |
| 集合的划分             | 一族非空子集，两两不交、并集为 $A$；与等价关系一一对应                                                   |
| 整除是等价关系吗          | **不是**（不满足对称：$2 \mid 4$ 但 $4 \mid 2$ 不成立），它是偏序关系                                |
| 偏序 / 半序 / 全序 / 良序 | 偏序＝半序；全序＝任两元素可比；良序＝每个非空子集有最小元（良序 ⊂ 全序 ⊂ 偏序）                                     |
| 自然数 vs 有理数        | **一样多**，都可数（$\aleph_0$）：排成不重不漏的序列（对角线枚举 + 去重）                                   |
| 实数 vs 自然数         | **不一样多**，$\#\mathbb{R} = 2^{\aleph_0} > \aleph_0$（康托尔对角线法）                      |
| 集合的递归定义           | ＝归纳定义：基础语句 + 归纳语句（+ 极限语句限定范围）                                                   |
| 握手定理              | 所有顶点次数之和 = 2 × 边数                                                               |
| 奇顶点个数             | 必为偶数（握手定理推论）                                                                    |
| 偏序 = ?            | 自反 + 反对称 + 传递                                                                   |
| 等价 = ?            | 自反 + 对称 + 传递                                                                    |
| 等价关系 vs 划分        | 一一对应（商集 = 划分）                                                                   |
| 欧拉图               | 存在欧拉回路（每边一次）的图；判定：连通 + 所有顶点次数为偶数                                                |
| 哈密顿图              | 存在哈密顿回路（每点一次）的图；无简单充要条件，只有充分条件（Dirac）                                           |
| 树的边数              | $n$ 个顶点有 $n-1$ 条边                                                               |
| 邻接矩阵的幂            | $M^k$ 元素 = 长度为 $k$ 的通路条数                                                        |
| Dijkstra          | 单源最短路，贪心逐个"敲定"最近的顶点；要求**权非负**，$O(n^2)$（堆优化 $O(m\log n)$）                        |
| Floyd             | 全源最短路，DP 逐个"放行"中转点，**最外层循环必须是 $k$**；$O(n^3)$，可负权但不可有负圈                          |
| Prim vs Kruskal   | Prim 贪**点**（找离树最近的点，$O(n^2)$，稠密图）；Kruskal 贪**边**（排序+并查集判圈，$O(m\log m)$，稀疏图）     |
| 最短路 vs 最小生成树      | 前者求两点间最省的路（**路径**问题），后者求连通所有点最省的边集（**连通**问题）                                    |
| 群的定义              | 结合律 + 单位元 + 逆元                                                                  |
| 域 vs 环            | 域非零元有乘法逆元，环没有                                                                   |
