# 操作系统 - 面试背诵版（仅问题）

> [!tip]+ 使用方式
> 本文件**只列问题不列答案**，按 Q 重要度从高到低分组，专供背诵。
> 做题流程：
> 1. 默看问题，脑中尝试完整陈述答案（定义 + 条件 + 公式 + 对比 / 反例）。
> 2. 卡壳或答完后，去 [[面试知识点速览版]] 找对应 Q（用编号 `节.Q号` 定位，如 `1.1.Q1`）核对。
> 3. 带 **北航真题** 标记的是北航软院复试问过的题，务必能张口就来。
> 4. 每背出一题就打勾 ✅，没把握的保持空框，第二遍只看空框项。

> [!note] 评级与定位
> - **[⭐⭐⭐]** 高频 / 北航真题核心 → 第 1 轮必背
> - **[⭐⭐]** 中频 / 常用 → 第 2 轮复习
> - **[⭐]** 低频可救场 → 临考扫一遍
>
> 章节定位：`1.x = OS 概论`、`2.x = 进程管理`、`3.x = 同步与互斥`、`4.x = CPU 调度`、`5.x = 内存管理`、`6.x = I/O 与磁盘管理`、`7.x = 文件系统`、`8.x = 进程间通信`、`9.x = 实验与拓展`。编号与 [[面试知识点速览版]] 完全一致，可点对点互查。

## 自测方法建议

> [!example]+ 三轮背诵法
> 1. **第 1 轮（⭐⭐⭐）**：先把这 22 题连背 3 次；卡壳 ≥ 3 次的题加入"卡点清单"，次日重背。
> 2. **第 2 轮（⭐⭐）**：过完中频题；重点区分**容易混的对比类**（进程/线程、进程/程序、互斥/同步、抢占/非抢占、分页/分段、内碎片/外碎片、逻辑地址/物理地址、写直达/写回、DMA/通道、死锁/饥饿/活锁、共享内存/管道、用户级线程/内核级线程）。
> 3. **第 3 轮（⭐）**：考前最后 30 分钟扫一遍，能说出关键词即可。
>
> 自测时用三个角度各默想一遍：
> - **定义**：概念/术语的定义与公式（如PCB 与三态转换、临界区四原则、死锁四条件、FCFS/SJF/SRTF/HRRF/RR/MFQ、TLB 与多级页表、Belady 异常、HRRF 的响应比公式、RR 的等待时间与就绪进程数成正比）；
> - **对比**：凡是"XX vs YY"都要能说出 3 条以上区别，并点明**为什么**（如进程为什么比线程重、为什么共享内存最快、为什么 P 操作要先申请资源信号量再申请互斥信号量、为什么抢占式开销更大、为什么分页只有内碎片、为什么多级页表省空间、为什么要用时钟中断）；
> - **反例**：每个"不一定"都要能举反例（不安全 ≠ 死锁；阻塞→就绪不能直接到运行；时间片用完是就绪不是阻塞；多分物理块缺页率可能反升，即 FIFO 的 Belady 异常；主频高 ≠ 更快；银行家算法在通用 OS 里基本不用）。
