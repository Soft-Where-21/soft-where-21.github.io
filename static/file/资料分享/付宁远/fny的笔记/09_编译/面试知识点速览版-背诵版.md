# 编译原理 - 面试背诵版（仅问题）

> [!tip]+ 使用方式
> 本文件**只列问题不列答案**，按 Q 重要度从高到低分组，专供背诵。
> 做题流程：
> 1. 默看问题，脑中尝试完整陈述答案（定义 + 条件 + 公式 + 对比 / 反例）。
> 2. 卡壳或答完后，去 [[面试知识点速览版]] 找对应 Q（用编号 `节.Q号` 定位，如 `0.1.Q1`）核对。
> 3. 带 **北航真题** 标记的是北航软院复试问过的题，务必能张口就来。
> 4. 每背出一题就打勾 ✅，没把握的保持空框，第二遍只看空框项。

> [!note] 评级与定位
> - **[⭐⭐⭐]** 高频 / 北航真题核心 → 第 1 轮必背
> - **[⭐⭐]** 中频 / 常用 → 第 2 轮复习
> - **[⭐]** 低频可救场 → 临考扫一遍
>
> 章节定位：`0.x = 编译过程总览`、`1.x = 文法与语言`、`2.x = 词法分析`、`3.x = 语法分析`、`4.x = 语义分析与中间代码生成`、`5.x = 运行时存储组织`、`6.x = 代码优化与目标代码生成`。编号与 [[面试知识点速览版]] 完全一致，可点对点互查。

## 自测方法建议

> [!example]+ 三轮背诵法
> 1. **第 1 轮（⭐⭐⭐）**：先把这 13 题连背 3 次；卡壳 ≥ 3 次的题加入"卡点清单"，次日重背。
> 2. **第 2 轮（⭐⭐）**：过完中频题；重点区分**容易混的对比类**（NFA/DFA、编译执行/解释执行、自顶向下/自底向上、LL/LR、句柄/素短语、综合属性/继承属性、全局/局部变量、堆/栈、静态分配/动态分配、图着色/线性扫描）。
> 3. **第 3 轮（⭐）**：考前最后 30 分钟扫一遍，能说出关键词即可。
>
> 自测时用三个角度各默想一遍：
> - **定义**：概念/术语的定义与公式（如乔姆斯基四型文法与对应自动机、LL(1) 条件、活动记录的组成、寄存器分配的图着色）；
> - **对比**：凡是"XX vs YY"都要能说出 3 条以上区别，并点明**为什么**（如为什么编程语言选 CFG 而不选更复杂的文法、为什么局部优化只能在基本块内做、为什么要先把 NFA 确定化成 DFA 再写词法分析器、堆和栈为什么要分开）；
> - **反例**：每个"不一定"都要能举反例（NFA 允许 ε 转移而 DFA 不允许；句柄可以不含终结符但素短语必须含；"遇到错误处理几个字符"没有固定答案，由同步集决定，不是固定 3 个字符；`static` 局部变量属静态分配；`x / 2 → x >> 1` 只对无符号或已确定非负的数成立）。
