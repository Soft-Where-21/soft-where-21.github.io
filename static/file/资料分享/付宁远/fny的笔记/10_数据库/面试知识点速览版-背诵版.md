# 数据库 - 面试背诵版（仅问题）

> [!tip]+ 使用方式
> 本文件**只列问题不列答案**，按 Q 重要度从高到低分组，专供背诵。
> 做题流程：
> 1. 默看问题，脑中尝试完整陈述答案（定义 + 条件 + 公式 + 对比 / 反例）。
> 2. 卡壳或答完后，去 [[面试知识点速览版]] 找对应 Q（用编号 `节.Q号` 定位，如 `1.1.Q1`）核对。
> 3. 带 **北航真题** 标记的是北航软院复试问过的题，务必能张口就来。
> 4. 每背出一题就打勾 ✅，没把握的保持空框，第二遍只看空框项。

> [!note] 评级与定位
> - **[⭐⭐⭐]** 高频 / 北航真题核心 → 第 1 轮必背
> - **[⭐⭐]** 中频 / 常用 → 第 2 轮复习
> - **[⭐]** 低频可救场 → 临考扫一遍
>
> 章节定位：`1.x = 数据库基础与关系模型`、`2.x = SQL 与查询优化`、`3.x = 关系数据理论与范式`、`4.x = 存储与索引`、`5.x = 事务与并发控制`、`6.x = 数据库恢复`、`7.x = 关系型 vs 非关系型数据库`。编号与 [[面试知识点速览版]] 完全一致，可点对点互查。

## 自测方法建议

> [!example]+ 三轮背诵法
> 1. **第 1 轮（⭐⭐⭐）**：先把这 21 题连背 3 次；卡壳 ≥ 3 次的题加入"卡点清单"，次日重背。
> 2. **第 2 轮（⭐⭐）**：过完中频题；重点区分**容易混的对比类**（1NF/2NF/3NF/BCNF、关系型 vs NoSQL、聚簇 vs 非聚簇、不可重复读 vs 幻读、DDL vs DML、B+ 树/哈希/位图）。
> 3. **第 3 轮（⭐）**：考前最后 30 分钟扫一遍，能说出关键词即可。
>
> 自测时用三个角度各默想一遍：
> - **定义**：概念/术语的定义与公式（如三级模式、四类完整性约束、ACID、四个隔离级别、WAL、E-R 图三类冲突）；
> - **对比**：凡是"XX vs YY"都要能说出 3 条以上区别，并点明**为什么**（如为什么用 B+ 树而不用红黑树、为什么关系型难扩展而 NoSQL 易扩展、TRUNCATE 和 DELETE 差在哪）；
> - **反例**：每个"不一定"都要能举反例（外码可以为 NULL，但仅当它不属于主属性；RR 按教材仍允许幻读，MySQL 只是用 MVCC 缓解）。
