## 四、内存管理（2019北航961）

1. 2^32 = 4G 字节
2. 2^10 = 1K 页目录项，2^20 = 1M 页表项
3. * $PDbase = PTbase + (PTbase >> 10)$，一级页表起始地址：0x1FC7F000
	* 0x01234567 = 0b 0000_0001_00｜10_0011_0100 ｜0101_0110_0111，页目录号为4
	* 对应页目录项起始地址：0x1FC7F000 + 4 * 4（0x10） = 0x1FC7F010
4. $PDentry_{selfmapping} = PTbase + (PTbase >> 10) + (PTbase >> 20)$，一级页表对应页目录项地址：0x1FC7F1FC
5. * 0x12345678 = 0b 0001_0010_00 ｜11_0100_0101｜0110_0111_1000，页号为0x345
	* 页表项物理地址：0x00007000 + 0x345 * 4（0xD14）= 0x00007D14
	* 页目录项中的页框号：0x7

## 五、进程同步与互斥

```c
semaphore mutex = 1;	// 互斥访问零件暂存区
semaphore empty = 10;	// 不能超过10个零件
semaphore X_ready, Y_ready, Z_ready = 0;	// 分别表示零件X，Y，Z已经准备好的数量
semaphore X_clear, Y_clear = 1	// 表示零件X，Y已被取走

cobegin
{
  process R1() 
	{
    while (True) 
    {
      produceX();
      P(empty);			// 等待空位
      P(X_clear);		// 等待R3把X取走
      P(mutex);			// 等待缓冲区
      putX();
      V(mutex);			// 释放缓冲区
      V(X_ready);		// 告知R3，X已经好了
    }
	}
  
  process R2()			// 类似R1
  {
    while (True) 
    {
      produceY();
      P(empty);			
      P(Y_clear);
      P(mutex);
      putY();
      V(mutex);
      V(Y_ready);
    }
  }
  
  process R3()
  {
    while (True)
    {
      P(X_ready);		// 等待X生产好
      P(mutex);			// 等待缓冲区
      getX();
      V(mutex);			// 释放缓冲区
     	V(empty);			// 释放一个空位
      V(X_clear);		// 告知R1，X已经取走
      
      P(Y_ready);		// 取Y过程同上
      P(mutex);
      getY();
      V(mutex);
      V(empty);
      V(Y_clear);
      
      productZ();		
      P(empty);			// 等待空位
      P(mutex);			// 等待缓冲区
      putZ();
      V(mutex);			// 释放缓冲区
      V(Z_ready);		// 告知R4，Z已经好了
    }
  }
  
  process R4()
  {
		while (True)
    {
      P(Z_ready);		// 等待Z生产好
      P(mutex);			// 等待缓冲区
      getZ();
      V(mutex);			// 释放缓冲区
      V(empty);			// 释放一个空位
      produceP();
    }
  }
  
} coend
```

## 六、进程调度

优先级算法按照抢占式计算

| 时刻 | FCFS | SRTF |  RR   | Priority |
| :--: | :--: | :--: | :---: | :------: |
|  0   |  A   |  A   |   A   |    A     |
|  1   |  A   |  B   |   B   |    A     |
|  2   |  A   |  A   |   A   |    A     |
|  3   |  B   |  A   |   C   |    C     |
|  4   |  C   |  C   |   A   |    C     |
|  5   |  C   |  C   |   C   |    C     |
|  6   |  C   |  D   |   D   |    D     |
|  7   |  C   |  D   |   C   |    D     |
|  8   |  C   |  E   | **D** |    C     |
|  9   |  D   |  E   | **E** |    C     |
|  10  |  D   |  C   |   C   |    B     |
|  11  |  E   |  C   |   E   |    E     |
|  12  |  E   |  C   |   C   |    E     |

平均等待时间：

* **FCFS**：(0 + 2 + 1 + 3 + 3) / 5 = 1.8
* **SRTF**：(0 + 0 + 1 + 0 + 0) / 5 = 0.2
* **RR**：(0 + 0 + 0 + 0 + 1) / 5 = 0.2
* **Priority**：(0 + 9 + 0 + 0 + 3) / 5 = 2.4
