# E 最大子数组



## 题意

给一个数组，求其**和最大的连续非空子数组**



## 思路

数组元素为 $n$ 时，它的子数组个数为：
$$
\sum_{i=1}^{n}i=\frac{n\times(n+1)}{2}
$$
以数组 `1 2 3 4` 为例：

- 以 `1` 为最后一个元素的子数组有 $1$ 个，`1`
- 以 `2` 为最后一个元素的子数组有 $2$ 个，`1 2`、 `2`
- 以 `3` 为最后一个元素的子数组有 $3$ 个，`1 2 3`、`2 3`、`3`
- 以 `4` 为最后一个元素的子数组有 $4$ 个，`1 2 3 4`、`2 3 4`、`3 4`、`4`

一般情况：

- 以 `n - 1` 为最后一个元素的子数组有 $n-1$ 个
- 以 `n` 为最后一个元素的子数组包括：
  - 以 `n - 1` 为最后一个元素的子数组在末尾填上 `n` 构成的子数组
  - 由 `n` 构成的只含自身一个元素的数组

子数组的个数为 $n^2$ 数量级，暴力解法时间复杂度 $O(n^2)$，数据范围 $1\leq 𝑛\leq10^6$，会超时。

**考虑一些有共同特点的子数组——以 `i` 为最后一个元素的子数组。在这些有共同特点的子数组中，求出最大子数组和，再维护其中的最大值。**

求以 `i` 为最后一个元素的子数组中的最大子数组：

- 当 `i` 等于 $1$ 时，子数组只有一个，即为最大子数组
- 当 `i` 等于 $n$ 时
  - 若子数组为 “以 `n - 1` 为最后一个元素的子数组在末尾填上 `n` ” 构成的子数组，则在这种情况下的最大子数组和为 “以 `n - 1` 为最后一个元素的子数组中的最大子数组和”（**记为 `pre`**） 的值加上 “第 $n$ 个元素” 的值
  - 若子数组为只含自身一个元素的数组，则在这种情况下的最大子数组和为 “第 $n$ 个元素” 的值
  - 由上述两种情况，`pre + a[i]` 和 `a[i]` 中较大的值即为以 `i` 为最后一个元素的子数组中的最大子数组和（新的 `pre`）

维护一个 `max`，`pre` 每次更新时，与 `max` 做比较，判断 `max` 是否需要更新。



## 时间复杂度分析

数组只在读取时遍历一次，时间复杂度 $O(n)$；数组不需要存储，空间复杂度 $O(1)$。



## 代码

```c
#include <stdio.h>

int main()
{
    int n;
    scanf("%d", &n);
    long long x, pre, max = 0;
    scanf("%lld", &pre);					//令 pre 为数组第一个值
    for (int i = 1; i < n; i++)
    {
        scanf("%lld", &x);
        pre = (pre + x > x) ? pre + x : x;	//以 i 为最后一个元素的子数组中的最大子数组和
        max = (max > pre) ? max : pre;		//维护 max
    }
    printf("%lld\n", max);
    return 0;
}
```
