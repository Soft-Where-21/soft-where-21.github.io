## 题目描述

输入：n个白球，m个黑球，给出编号排列。

目的：在最少交换次数下让排列按顺序排列

规则：只有异色球可以互相交换

## 题意分析

##### 以下只是说明任何数字的任何排列情况都可以交换为顺序，实际统计时只需要根据乱序球个数直接求得

不考虑颜色如何交换最快：如题，5号要去3号所在位置，3号要去2号所在位置，2号要去5号所在位置。所以乱序其实就是一个球占了另一个球的位置的一个闭环链。这个链最快恢复顺序的交换次数就是边数，如2-5边交换后下，5去到位置3后5-3边交换。

考虑颜色：

1.球中有一个异色球：如下图，黑色箭头为球要去的位置，从图中可知有一个一色球按逆序进行交换，交换次数：球数减一

## 题解

1.从0到n-1位置遍历数组a

2.当位置与球号码不符合时，还是找环存在c数组，c[0]=2,c[1]=a[a[2]]=5,c[2]=a[a[5]]=3，球个数len=3

​	有两种颜色的球时总数+len-1，一种颜色的球：总数+len-1

​	tip：让a[2]=2,a[3]=3,a[5]=5,避免重复统计

## 算法分析

​	时间复杂度o(n),因为乱序的位置数<=n,而乱序的位置被统计后就恢复了，所以找乱序球次数<=n,再加上对n个球的n次判断，所以o(n)

## 代码

```C
#include<stdio.h>
int n,m,a[200005],w,b,c[200005],len_c=0;
long long sum=0;
int main(){
    int i=0;
    scanf("%d%d",&n,&m);
    for(i=1;i<=(n+m);i++){
        scanf("%d",&a[i]);
    }
    for(i=1;i<=(n+m);i++){
        if(a[i]!=i){
            len_c=0; 
            int b=i,white=0,black=0;
            do{
                if(b<=n){
                    white++;//统计黑白球个数 
                }else{
                    black++;
                }
                c[len_c]=b;//记录乱序环 
                b=a[b];
                len_c++;
            }while(b!=i);
            if(white>0&&black>0){//判断黑白球是否都有 
                sum+=len_c-1;//黑白球都有，球数-1 
            }else{
                sum+=len_c+1;//只有一种颜色，球数-1 
            }
            while(len_c>0){
            len_c--;
            a[c[len_c]]=c[len_c];//直接将统计球存入正确位置 
            }
        }
    }
    printf("%lld",sum);
}
```
