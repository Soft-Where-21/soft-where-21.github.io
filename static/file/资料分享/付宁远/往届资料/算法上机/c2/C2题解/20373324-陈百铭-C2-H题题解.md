# C2 — H题

## 题意

输入 n 个非负整数，每个整数表示一个宽度为1的方形柱子的高度，计算按此排列的 n 个柱子的高度图的凹槽数（接水量）

样例：假设输入的 n 个数为 [0,1,0,2,1,0,1,3,2,1,2,1][0,1,0,2,1,0,1,3,2,1,2,1]，代表如下图所示的柱子高度图，该图能接的总雨水量为6。

![5k33wV.png](https://z3.ax1x.com/2021/10/09/5k33wV.png)

## 题解

我们稍加思索，就会发现凹槽为0的柱状图一定是先递增再递减的（非严格），再一思索，就会想到把柱状图填成上述递增再递减的形状所用的最少格子数就是所求的凹槽数。

于是我们可以先遍历一遍数组找到最大的高度，再从两侧向最大高度处逐一修改凹槽处并计数，关键代码如下（从左到最高处为例）

```c
for(i=1;i<max_pos;i++)
    if(a[i]<a[i-1])
    {
    	cnt+=a[i-1]-a[i];
    	a[i]=a[i-1];
    }
```

注意，最终结果可能超出int范围

## 代码

```c
#include <stdio.h>
int a[1000000];
int main()
{
    int n,i,max=-1,max_pos;
    long long int cnt=0;
    scanf("%d",&n);
    for(i=0;i<n;i++)
    {
        scanf("%d",&a[i]);
        if(a[i]>max)
        {    
            max=a[i];
            max_pos=i;
        }
    }
    for(i=1;i<max_pos;i++)
        if(a[i]<a[i-1])
        {
            cnt+=a[i-1]-a[i];
            a[i]=a[i-1];
        }
    for(i=n-2;i>max_pos;i--)
        if(a[i]<a[i+1])
        {
            cnt+=a[i+1]-a[i];
            a[i]=a[i+1];
        }
    printf("%lld",cnt);
    return 0;
}
```
