# C2-H

## 题目分析：

蓄水量：红色线圈出的金字塔的面积-柱子（阴影部分面积）

![微信图片_20211013220540](C:\Users\25068\Desktop\微信图片_20211013220540.png)

## 题解：

1.在输入数组时把柱子所占面积s1统计了，并记录最高的柱子所在位置

2.统计最高柱子左边金字塔的面积

3.统计柱子右边金子塔面积

4.汇总得到面积S

5.蓄水量s-s1

## 算法分析：

时间复杂度o(n),输入数组时统计s1,时间复杂度<=cn,遍历一次数组统计S，时间复杂度<=cn,所以时间复杂度o(n)

## 代码

```c
#include<stdio.h>
int n,a[1000005];
long long sum=0,black=0,max=0;
int main(){
	scanf("%d",&n);
	int i,j,max=0;
	for(i=0;i<n;i++){
		scanf("%d",&a[i]);
		black+=a[i];//black柱子所占面积
		if(a[i]>a[max]) max=i;
	}
	int key=a[0];
	for(i=0;i<max;i++){//统计金字塔右边面积
		if(a[i]>key) key=a[i]; 
		sum+=key;
	}
	sum+=a[max];//最高柱子面积
	key=a[n-1];
	for(i=n-1;i>max;i--){//统计金字塔右边面积
		if(a[i]>key) key=a[i];
		sum+=key;
	}
	printf("%lld",sum-black);
} 
```
