# E题 最大子数组

## 题目

定义一个数组的和最大的连续非空子数组为该数组的最大子数组。

给你一个数组，求其最大子数组的和。

翻译：从数组挑出连续的一串来（非空），求和最大

## 题解

课本P38--42有相关讲解，用的是分治，这里说一个写起来很简单的方法



分析：

首先最大子数组的左右两端一定是负数（或到头了）

同时并不是有负数就不要，举两个栗子7,3，-5，6，和1,2，-5,6
7,3，-5，6中这-5和6还是可以要的（-5 + 6为正且之前的7+3>6）
所以从负数开始往后求和要为正，那么往前求和也要为正（类比一下）。

那么我们从左往右求和，为负的话就要考虑从下一个正数的地方重新开始

算法：从左向右依次累加，过程中记录最大值。加出来负的就不要了，往后找正数重新开始；

## 代码

```C
#include <stdio.h>
#include <stdlib.h>


int main()
{
    int n,i;
    long long int sum=0, tmp, max=0;
    scanf("%d", &n);
    for(i=1; i<=n; i++){
        scanf("%lld", &tmp);
        sum += tmp;
        if (sum<tmp) //加出来sum为负了就舍弃原sum，一直到正数出现赋给sum
            sum=tmp;
        if (sum>max) //累加过程中一直记录最大值
            max=sum;
    }
    printf("%lld", max);
    return 0;
}
```
