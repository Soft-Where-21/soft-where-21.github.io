# 题解

**分析：** 设这 $n$ 个柱子的高度分别表示为 $a_1,a_2,...,a_n$

考虑第 $i$ 个柱子能接多少水：

1. 如果这个柱子两边的柱子都没有它高，那它就接不到水（水会沿着两边流走）
2. 如果这个柱子两边的柱子有一边比它高，但另一边没有它高，那它还是接不到水（水会沿着另一边流走）
3. 如果两边都有柱子比它高，那么柱子 $i$ 上面就能有水保存，设左边最高的柱子高度为 $L$，右边最高柱子的高度为 $R$，那么保存的水量为 $min(L,R)-a_i$ （参考“水桶效应”）

由上面我们不难得出以下解法：

1. 首先输入 $n$ 和 $a_1,a_2,...,a_n$
2. 进行预处理，计算出 $L_1,L_2,...,L_n$ 和 $R_1,R_2,...,R_n$，其中 $L_i$ 表示 $a_1,a_2,...,a_i$ 中的最大值，$R_i$ 表示 $a_i,a_{i+1},...,a_n$ 中的最大值
3. 计算柱子$a_1,a_2,...,a_n$ 能装的水量，由分析可以得出第 $i$ 个柱子能装的水量为 $c_i=max(0,min(L_{i-1},R_{i+1})-a_i)$ （可以将 $a_0$ 和 $a_{n+1}$ 看作高度为 $0$ 的柱子，因此 $c_i$ 可以取 $c_1$ 和 $c_n$）
4. 对 $c_1,c_2,...,c_n$ 求和即可得到答案

**时间复杂度：** $O(n)$

# 代码

```c++
#include<bits/stdc++.h>
using namespace std;
#define N 1000005
int n,a[N],L[N],R[N];
long long ans,sum;
int main(){
	ios::sync_with_stdio(false);
	cin>>n;
	for(int i=1;i<=n;i++) cin>>a[i];
	for(int i=1;i<=n;i++) L[i]=max(a[i],L[i-1]);
	for(int i=n;i>=1;i--) R[i]=max(a[i],R[i+1]);
	for(int i=1;i<=n;i++)
	  ans+=max(0,min(L[i-1],R[i+1])-a[i]);
	cout<<ans;
	return 0;
}
```
