# C2-H题解

## 题目描述

打开了神秘的盒子之后，你看到里面放着一株绿藤，绿藤即将枯萎，需要神奇的雨水浇灌。

输入 nn 个非负整数，每个整数表示一个宽度为 11 的方形柱子的高度，计算按此排列的 nn 个柱子的高度图，下雨之后能接多少雨水？

样例：假设输入的 nn 个数为 [0,1,0,2,1,0,1,3,2,1,2,1][0,1,0,2,1,0,1,3,2,1,2,1]，代表如下图所示的柱子高度图，该图能接的总雨水量为 66。

[![5k33wV.png](https://z3.ax1x.com/2021/10/09/5k33wV.png)](https://imgtu.com/i/5k33wV)

## 输入格式

第一行一个整数 nn ( 1≤n≤1061≤n≤106 )，含义如上所示。

第二行 nn 个非负整数 a1,a2,...,ana1,a2,...,an（ 0≤ai≤1060≤ai≤106 ），代表柱子的高度。

## 输出格式

输出一行一个整数，表示接到的总雨水量。

## 样例输入

```
12
0 1 0 2 1 0 1 3 2 1 2 1
```

## 样例输出

```
6
```

## 题意解释

通过分析题目，不难得出在每一个坐标上的水位一定不能超过左侧最高的柱子的高度，同时也不能超过右边的最高的柱子的高度。

## 实现思路

我们需要知道每个位置对应的柱子高度、左侧最高柱子高度、右侧最高柱子高度。所以我们在按照顺序读入n个柱子的高度的时候，先不断更新左侧最高柱子的高度。然后从最后一个柱子开始反向遍历更新右侧最高柱子的高度。然后就是对每一个柱子分析可以加多少水位：

- 如果max_left和max_right均大于当前柱子，那么可以接的水就是min(max_left-max_right)-当前水位
- 否则无法接水

## C++代码

```c++
#include <bits/stdc++.h>
using namespace std;
int n;
int a[1000005];
int a_left[1000005];
int a_right[1000005];
long long cnt=0;
int main()
{
    scanf("%d",&n);
    for(int i=1;i<=n;i++)
    {
        scanf("%d",&a[i]);
        a_left[i]=max(a_left[i-1],a[i-1]);//在读入时顺便更新左侧的最高柱子
    }
    for(int i=n;i>=1;i--)//倒过来更新右侧最高柱子
    {
        a_right[i]=max(a[i+1],a_right[i+1]);
    }
    for(int i=2;i<n;i++)
    {
        if(a_left[i]>a[i]&&a_right[i]>a[i])//只有当右侧最高柱子和左侧最高柱子都比当前柱子高时才能接水
        {
            int hight=min(a_left[i],a_right[i]);
            cnt+=(hight-a[i]);
        }
    }
    printf("%lld",cnt);
    return 0;
}
```

int n;
