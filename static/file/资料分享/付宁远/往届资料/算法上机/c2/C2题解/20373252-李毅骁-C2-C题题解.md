# C2-C 公交排序

## 题意

一个n个元素的无序数列，交换相邻元素count次使得此数列变为非降序序列，求count的最小值。

## 数据范围

n ≤ 2 * 10<sup>5</sup>，

a<sub>i</sub> ≤ 2 * 10<sup>5</sup>，

(count不能用int)。

## 解题思路

首先，hint是排序(x，C题提示是归并排序(x，包括看完C题输入输出样例，应该能够自然联想到求数列的逆序对个数，用分治法把逆序对个数求出来这题就过了(x。

然后还是思考一下为什么最小的交换次数count<sub>min</sub>是数列的逆序对的个数。

观察子问题，假设这个数列为a<sub>1</sub>,a<sub>2</sub>...a<sub>n</sub>，取其中的子列a<sub>i</sub>...a<sub>j</sub>满足a<sub>i</sub> ≥ a<sub>k</sub> ≥ a<sub>j</sub>(i < k < j)，若没有这样的子列，那么这个序列为非降序序列(就是子列的头为子列最大值，子列尾为子列最小值)，对于这个子列来说，包含a<sub>i</sub>和a<sub>j</sub>的逆序对共有(j - i) * 2 - 1对，如果想要将a<sub>i</sub>和a<sub>j</sub>移动到正确的位置(尾和头)，那么同样需要交换相邻元素(j - i) * 2 - 1次，所以从最小的子列开始交换头和尾，将所有元素交换到正确的位置需要的最少的次数即为数列逆序对数，最少的次数是因为没有多余的步数。

## 代码

```C
#include<stdio.h>
#define INF 200005
#define HINF 100005
long long count;						  //0.4的原因可能是没用long long，数据范围count ≤ 4*10^10
int L[HINF],R[HINF];
int a[INF];
void Merge(int left, int mid, int right){ //合并左右
	int lenl = mid - left + 1;
	int lenr = right - mid;
	for(int i = 0;i < lenl;i++)
		L[i] = a[left + i];
	for(int i = 0;i < lenr;i++)
		R[i] = a[mid + 1 + i];
	L[lenl] = R[lenr] = INF;
	int l = 0,r = 0;
	for(int i = left;i <= right;i++)
		if(L[l] <= R[r])
			a[i] = L[l++];
		else{
			count += lenl - l;			  //将每一个包含右侧小元素的逆序对对数相加
			a[i] = R[r++];
		}
}
int mergeSort(int left, int right){ 	  //分治
	if(left < right){
		int mid = left + (right - left) / 2;
		mergeSort(left,mid);
		mergeSort(mid + 1,right);
		Merge(left,mid,right);
	}	
}
int main(){
	int n;
	scanf("%d",&n);
	for(int i = 0;i < n;i++)
		scanf("%d",&a[i]);
	mergeSort(0,n - 1);
	printf("%lld",count);
	return 0;
}
```
