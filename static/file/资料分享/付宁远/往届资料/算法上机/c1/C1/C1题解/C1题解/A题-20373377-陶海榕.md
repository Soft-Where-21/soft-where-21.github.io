# 题解



***



题目要求我们输出第6行和第8行的执行次数，我们可以声明两个全局变量cnt1、cnt2初始为0，分别用于记录第6行和第8行的运行次数，然后它们的自加一语句插入到代码中合适的部分，最后输出cnt1和cnt2即可。

首先当然是照着题目给的伪代码写一个插入排序函数了。

~~~c
void insert_sort(int n){//这里把待排序数组定义成了全局数组，传递数字个数即可
	int j = 0;
	for(j = 1; j < n; j++){
		int key = a[j];
		int  i = j-1;
		while(i >= 0 && a[i] > key){
			a[i+1] = a[i];
			i = i-1;
		}
		a[i+1] = key;
	}
}
~~~

然后考虑cnt1，cnt2应该插入哪里。  

观察第6行和第8行，可以发现第6行是应该循环的判断部分，无论条件是否成立都会执行，而第8行是普通的赋值语句。  

对于第8行，可以直接把cnt2的自加一语句直接跟在第8行后面。   

对于第6行，我们可以把它分为条件成立和条件不成立两种情况。条件成立的话，程序会进入循环体，顺序执行第7行，第8行，然后再跳回第6行进行判断；而条件不成立的话，就会直接从第9行开始执行。因此，我们只需要在循环体和第9行后面都插入cnt1的自加一语句即可。  

时间复杂度和插入排序一样，是 O(N<sub>2</sub>)。



# 代码



***



```C
#include <stdio.h>
int MAXN = 1005;
int a[MAXN];
int cnt1 = 0, cnt2 = 0;
void insert_sort(int n){
	int j = 0;
	for(j = 1; j < n; j++){
		int key = a[j];
		int  i = j-1;
		while(i >= 0 && a[i] > key){
			a[i+1] = a[i];
			i = i-1;
			cnt1++;
			cnt2++;
		}
		cnt1++;
		a[i+1] = key;
	}
}

int main(){
	int n = 0;
	while(scanf("%d", &a[n]) != EOF)n++;
	insert_sort(n);
	printf("%d %d", cnt1, cnt2);
	return 0;
}
```
