# F-黑子的训练

# 题意

目标得分为$n(2≤n≤70)$，可以投的两分球个数$max$\_$two$有限制$(2≤max$\_$two≤8)$，最后得分**恰好**达到。


# 题解
这道题直接可以以两分球的个数为变量进行一次for循环求解，也可以根据总的投球数来进行求解。因为在同样确定循环上下界和，后一种做法的数据更好处理，因此下面介绍后者的解题思路。

首先计算出总投球数的上下界(不一定能取到)：  

无论两分球限制投多少个，投球数下界都是$n/3$。  

当$max$\_$two$数值较大时，投球数上界为$n/2$;当$max$\_$two$较小，只投二分球不能满足得分时，估算投球数最多的情况是：二分球投满，其余的分数投三分球投满$(n-(max×2))/3+max$。  

在某固定投球数$t$下，采用鸡兔同笼的思考法，先把每个球得到的两分都减去，则三分球个数为$t3=n-2×t$，可能的情况用组合数计算$\tbinom{t3}{n}$   

对于下界来说，因为除法向下取余，所以$n/3$可能不够，在循环时作为下界不取等；对于上界来说，如果没除尽而向下取余，直接说明二分球尽可能多的极限情况下分数不能恰好取到，需要增加三分球而减少总次数，因此在循环时作为上界可取等。  

组合数公式： $\tbinom{m}{n}$ =$\tbinom{n-m}{n}$  

# 代码
	#include <stdio.h>
	#include <string.h>
	#include <stdlib.h>
	int C(int n,int t)//求组合数的函数
	{
		int i;
		if(t\*2>n)
		return C(n,n-t);//组合数公式，减小运算量并防止数据过大溢出
		long long result=1;
		if(t==0)
		return 1;
		for(i=0;i<t;i++)
			result\*=n-i;//本题数据量小，使用组合数公式后，最大的组合数的分子也不会超过long long
		for(i=0;i<t;i++)
			result/=i+1;
		return (int)result;
	}
	int main()
	{
		int n,max;
		scanf("%d%d",&n,&max);
		int t3;
		int i;
		int M=n/2;//上界初始化
		int m=n/3;//下界初始化
		int out=0;
		if(max<t2)
			M=(n-(max\*2))/3+max;//上界：二分球投满，其余的分数投三分球投满
		for(i=M;i>m;i--)
		{
			t3=n-i\*2;//三分球个数
			out+=C(i,t3);//求组合数
		}
		if(n%3==0)
			out++;//单独判断下界（全投三分）的情况
		printf("%d",out);
		return 0;
	}
