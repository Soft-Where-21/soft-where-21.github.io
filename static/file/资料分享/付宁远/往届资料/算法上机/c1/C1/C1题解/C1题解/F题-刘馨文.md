# C1 — F题

## 题意

`BUAA` 校级篮球联赛正如火如荼得进行着，教练在训练时对每个队员又提出了新的标准。

教练要求队员黑子在一次投篮训练中**得到 n 分**，黑子可以选择每次投两分球 **2** 分或三分球 **3** 分，但由于两分球比较容易投进，教练要求黑子投射的两分球数量**不超过** max_two 个。请输出黑子有多少种不同的投球顺序，使得**恰好**完成了教练要求的得分（假设投的球都能命中）。

**输入**一行，两个以空格分隔的正整数 n 、max_two（ 2≤n≤70 ，2≤max_two≤8）。

**输出**一行，b一个非负整数，表示有多少种不同的投球顺序。

## 题解

本题可以用**动态规划**处理：一个二维数组记录不同投球顺序的数量，**横坐标**表示**当前分数**，**纵坐标**表示投入**两分球的个数**。

可以知道得到当前得分有**两种方式**：

- 可以投**一个两分球**得到，前状态为**得分-2**，两分球**数量-1**；

- 可以投**一个三分球**得到，前状态为**得分-3**，两分球**数量不变**。

设当前得分为score，当前两分球的个数为num，则可以写出下式：
$$
dp[score][num] = dp[score-2][num-1] + dp[score-3][num]
$$
横坐标从初始值变化到n，纵坐标从0变化到max_two，依次计算，即可得到在不同得分及不同两分球的数量下，投球顺序的种数。

要求得分为n时有多少种不同的投球顺序，只需要将横坐标为n的所有数组元素累加即可。

## 代码

```c
#include<stdio.h>
int dp[100][10];
int main()
{
	int n, m, i, j, ans = 0;
	scanf("%d %d", &n, &m);
	dp[2][1] = 1, dp[3][0] = 1;
	for(i = 4; i <= n; i++)
	{		
		for(j = 0; j <= m; j++)
		{
			if(j != 0)
				dp[i][j] = dp[i-2][j-1] + dp[i-3][j];
			else
				dp[i][j] = dp[i-3][j];
		}
	}	
	for(i = 0; i <= m; i++)
		ans += dp[n][i];	
	printf("%d\n", ans);
	return 0;
}
```
