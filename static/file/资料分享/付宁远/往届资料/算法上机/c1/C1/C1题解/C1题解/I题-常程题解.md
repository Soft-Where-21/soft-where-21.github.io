# 题意

共有 $n$ 个同学，每轮比赛分成两个组，这样不同组的同学就产生了对抗关系；需要算出能使每对同学产生对抗关系的最少比赛轮数。

# 题解

## 解法

对编号为 $1$ 到 $n$ 的同学，第一轮比赛先分成编号区间 $[1,(n+1)/2]$ 和 $[(n+1)/2+1,n]$ 的两组；

第二轮比赛针对上面得到的这两个区间同样采取对半劈开的方式，得到四个区间，取第 $1$ 个和第 $3$ 个区间的并集作为一组，余下的作为另一组，进行比赛；

之后的每一轮都同理，针对前一轮比赛得到的区间（如第三轮就针对第二轮的四个区间），全都劈成两半，然后取这些两半中的所有的前一半的并集作为一组，余下的作为另一组，进行比赛；

劈区间时，若发现待劈区间长度只有 $1$ ，则可忽略。

比赛的次数为 $\lceil log_2 n\rceil$

## 证明

我们想要让同学们产生对抗关系，但只能采取一种操作——分成两组，设第一轮分的两组为 $A$ 和 $B$，因此赛后 $A$ 与 $B$ 中所有人都与另一组产生对抗，但 $A$ 组组内的所有人对彼此都没有对抗关系，$B$ 同理，因此接下来的任务就变成了让 $A$ 组组内的人互相对抗、$B$ 同理。

接下来，为了使 $A$ 组组内互相对抗，只能把 $A$ 拆成两块并且分别放于这轮比赛的两组中，$B$ 同理，**这是唯一能做、应该做的**——设 $A$ 拆成 $A_1$ 和 $A_2$，$B$ 拆成 $B_1$ 和$B_2$ ，则比赛的双方就是 $A_1$、$B_1$ 和  $A_2$、 $B_2$ （其他组合亦可，只要让 $A$ 的两块和 $B$ 的两块在不同组）；

再接下来，就是要让 $A_1$、$A_2$、$B_1$、$B_2$ 组内互相对抗，因此就如同上一步，拆成共 $8$ 块，合理地分在两组；

接下来同理，直到全分成大小为 $1$ 的小块，至此所有人互相产生了对抗。

每次必定把之前的块都拆成两块，因此比赛的轮数实际上就是最后一个长度为 $2$ 的块被拆成两块的比赛轮数，因此为使轮数最少就只能每次都是尽量对半分——减少分成的两块的最长的长度，因此比赛轮数最短是 $\lceil log_2 n\rceil$，每轮比赛两组的设置就如上面的过程一样即可。

## 复杂度分析

共  $\lceil log_2 n\rceil$ 轮比赛，第 $i$ 轮比赛大概要把 $2^{i-1}$ 个大块分成两半，而记录大块的前一半的过程的时间总和大概是 $n/2$；

因为 $i\le \lceil log_2 n\rceil$，所以 $2^{i-1}\le n$ ，因此每轮比赛用时 $O(n)$， $\lceil log_2 n\rceil$ 轮比赛用时 $O(nlogn)$；

空间上使用最多 $2^0+2^1+...+2^{\lceil n/2\rceil}\approx 2n$ 个结构用于队列存放，即 $O(n)$。

# 代码

```cpp
#include<cstdio>
#include<cmath>
#define N 1000
#define M 2000
using namespace std;
int n,ans[N+5];
//块的结构、队列
//dep表示在树形结构中与根的距离，本题中代表本块所在的比赛轮数
struct unit{
    int l,r,dep;
}que[M+5];
int main(){
    scanf("%d",&n);
    printf("%d\n",(int)ceil(log(n)/log(2)));
    //第一个块，即所有人
    que[0]=unit{1,n,1};
    int head=-1,tail=0,dep=1,numOfGroup1=0;
    while(head<tail){
        head++;
        //新一轮比赛的情况
        if(que[head].dep>dep){
            printf("%d ",numOfGroup1);
            for(int i=1;i<=numOfGroup1;i++)
                printf("%d ",ans[i]);
            printf("\n");
            dep=que[head].dep;
            numOfGroup1=0;
        }
        //块长度为1则忽略
        if(que[head].r<=que[head].l) continue;
        int mid=(que[head].l+que[head].r)>>1;
        //记下两半中的前一半
        for(int i=que[head].l;i<=mid;i++)
            ans[++numOfGroup1]=i;
        //下一轮比赛中的分块情况
        que[++tail]=unit{que[head].l,mid,dep+1};
        que[++tail]=unit{mid+1,que[head].r,dep+1};
    }
    return 0;
}
```
