# Problem H. 黑暗之魂

## 题意

判断一个年份是否同时满足以下条件：

+ 是一个质数：即除了 $1$ 和它本身以外不再有其他因数。
+ 是闰年： 四年一闰，百年不闰，四百年再闰。

## 解题思路

如果一个年份是闰年，那么 $4$ 一定是它的因数，因此它就不可能为质数，即不存在同时满足以上两个条件的年份。

## 备注

为了显得不那么摸鱼，或许我可以介绍一下快速判断素数的各种方法：

### 最直接的暴力判断

```c
bool isprime(int n){
    if(n==1) return 0;
    for(int i=2;i<n;i++)
        if(n%i==0) return 0;
    return 1;
}
```

时间复杂度是比较明显的$\Theta(n)$。

### 好那么一点的暴力判断

```c
bool isprime(int n){
    if(n==1) return 0;
    int h=sqrt(n+0.5);//预防浮点误差
    for(int i=2;i<=h;i++)
        if(n%i==0) return 0;
    return 1;
}
```

对于$n$的每一种因数分解$n=a\times b$，设$a\leq b$，则有$a\leq \sqrt n 且 b\geq \sqrt n$，因此若$n$为合数，$n$一定存在$\geq 2 $且$\leq \sqrt n$ 的因数，枚举这个区间中的数进行判断即可。

时间复杂度是也比较明显的$\Theta(\sqrt n)$。

### 线性筛素数

这种方法可以在$\Theta(n)$的时间复杂度内筛出所有$\leq n$ 的质数。

#### 算法思路

对于每一个数$x$，筛掉所有小于**最小质因子**小于 $x$ 的 $x$ 的倍数。

#### 算法实现

首先根据以上思路得出最简单的实现方法：

```c
void getprime(int n){
    for(int i=2,j=0;i<=n;i++)if(!flag[i]){
        prime[j++]=i;
        for(int k=i;k<=n;k+=i)
            flag[k]=1;
    }
}
```

时间复杂度大致分析如下：
$$
由于质数分布定理，\leq n的质数的个数约为\frac{n}{\ln n},第i个质数约为i\ln i\\
所以：T(n)\approx \Sigma_{i=1}^{\frac{n}{\ln n}} = n\Sigma_{i=1}^{\frac{n}{\ln n}} \frac{1}{i\ln i} = nO(\int_2^{\frac{n}{\ln n}}\frac{1}{i\ln i}di) = nO(\ln{\ln n})
$$
由于$\ln{\ln 10^6}\approx 2.63$，所以这种算法已经接近线性的时间复杂度。

但显然这样的实现方式仍然会带来一些重复，例如$2$和$3$都会同时对$6$进行访问，结合“好那么一点的暴力判断”方法，我们得知对于任意质数$x$，以$x$为**最小质因数**的数一定$\geq x^2$。因此 $k$ 的枚举可以从 $x^2$ 开始。

```c
void getprime(int n){
    for(int i=2,j=0;i<=n;i++)if(!flag[i]){
        prime[j++]=i;
        for(int k=i*i;k<=n;k+=i)
            flag[k]=1;
    }
}
```

这样的方法已经足够接近线性了（通常我偷懒都这么写的）。但这样也是会有重复的标记，例如 $36$ 会被 $2$ 和 $3$ 重复标记。

以下是严格的线性筛素数的实现方式：

```c
void getprime(int n){
    for(int i=2,j=0;i<=n;i++){
        if(flag[i]==0)
            prime[j++]=i;
        for(int k=0;k<j;k++){
            if(prime[k]*i>n) break;
            flag[prime[k]*i]=1;
            if(i%prime[k]==0) break;
        }
    }
}
```

#### 时间复杂度分析

因为```if(i%prime[k]==0) break;```的存在，可以保证每个合数都被标记且只被一个质数即其最小质因数标记一次。

证明如下：
$$
对于任意:n=p_1^{e_1}\times p_2^{e_2}\times \cdots \times p_m^{e_m}\\
当i=p_1^{e_1-1}\times p_2^{e_2}\times \cdots \times p_m^{e_m}, prime[k]=p_1 时n会被唯一标记一次。\\
当i<p_1^{e_1-1}\times p_2^{e_2}\times \cdots \times p_m^{e_m}时，可能筛到n的prime[k]>p_1\\
而对于<p_1^{e_1-1}\times p_2^{e_2}\times \cdots \times p_m^{e_m}的i:\\
当k枚举到prime[k]=p_1时由于i\%prime[k]==0,k的枚举结束，因此不会对n进行重复标记
$$
因此时间复杂度为$\Theta(n)$。



### miller-rabin质数判定法

线性筛素数的时间复杂度与空间复杂度均为$\Theta(n)$，当$n$的范围进一步扩大时便不再适用。

#### 算法思路

根据费马小定理：
$$
若n为质数，a不为n的倍数，则a^{(n-1)}\equiv 1　(mod　n)
$$
虽然**费马小定理的逆定理并不成立**，但其逆定理可以排除大多数合数的情况。
$$
对于奇质数n，令n-1=2^p\times m\\
a^{(n-1)}\equiv 1　(mod　n) \Leftrightarrow a^{2^p\times m}\equiv 1　(mod　n)
$$

$$
若x^2\equiv 1　(mod　p)　\Rightarrow 　(x^2-1)\equiv 0　(mod　p)\\
\Rightarrow 　(x-1)(x+1)\equiv 0　(mod　p)　\Rightarrow p|(x-1)(x+1)\\
由于p为质数，若x<p，则x_1=1，x_2=p-1
$$

$$
因此令a^{n-1}=a^{2^p\times m}=(((a^m)^2)^2\cdots)^2\\
即从x=a^m开始依次平方p次并mod　n根据上文推导，若结果为1则x一定是1或n-1，若不满足则为合数。
$$

对于随机生成的$a$，重复以上判断流程多次，若每次都满足，则认为这个数是素数。

随机选取 $k$个底数进行测试算法的失误率大概为 $4^{-k}$ （这我并不知道证明方法，也来不及找资料了QAQ）,以下代码我令$k=20$，失误率接近于$0$。

#### 算法实现

```c
typedef long long ll;
ll mul(ll a,ll b,ll m) { //乘法计算，防止两个longlong相乘产生溢出
    ll ret=0;
    a%=m,b%=m;
    while(b){
        if(b&1) ret=(ret+a)%m;
        a<<=1,a%=m,b>>=1;
    }
    return ret;
}
ll quick_pow(ll a,ll n,ll m){
    ll ret=1LL;
    while(n){
        if(n&1) ret=mul(ret,a,m);
        a=mul(a,a,m),n>>=1;
    }
    return ret;
}
bool check(ll n){
    if(n==2||n==3) return 1;
	if(!(n&1)) return 0;
	ll m=n-1,a,tmp,ans;
	int cnt=0;
	while(!(m&1)) m>>=1,cnt++;
	for(int i=0;i<20;i++){
		a=rand()%(n-1)+1;
		tmp=quick_pow(a,m,n);
		for(int j=0;j<cnt;j++){
			ans=mul(tmp,tmp,n);
			if(ans==1){
				if(tmp!=1&&tmp!=n-1) return 0;
				break ;
			}
			tmp=ans;
		}
		if(ans!=1)	return 0;
	}
	return 1;
}
```

#### 时间复杂度分析

时间复杂度为比较明显的$\Theta(Tp)=\Theta(T\ln{n})$，以上代码为了防止两个longlong乘法溢出，手写了倍增加法达到乘法的效果，时间复杂度会多乘上一个$\ln{n}$，为 $\Theta(T\ln{n}\ln{n})$。
