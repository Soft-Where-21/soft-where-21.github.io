# C1-20级算法第一次上机赛 第I题 对抗



## 题目描述
$$
注意，本题使用评测插件进行评测............................................................................................................\\

为了让大家对算法更深的理解，助教们决定以分组对抗的形式举办一场比赛。一共有n名同学。每个同学都有一个编号——从1到n的不同的整数。................\\

比赛分多轮，每轮全员参加比赛。同学们被分成两个组，各组可能有不同数量的同学，但每个组必须至少有一名同学。位于不同组的同学之间存在对抗关系。........\\

为了让大家在比赛中被充分调动，助教们希望每对同学都有过对抗关系。但是由于每轮比赛的安排耗费大量精力，助教们希望轮数越少越好。.....................\\

请你帮助教们安排分组方案................................................................................................................。
$$



### 输入

$$
输入仅一行。.............................................................................................................................\\

仅一个数为学生人数n(2≤n≤1000)。.....................................................................................................
$$



### 输出

$$

然后有m行输出。.........................................................................................................................\\
第i+1行中，先输出f_i——第i轮第一组的人数(1≤f_i<n) ，以及f_i个1到n之间的数字，对应第一组的同学编号。.......................................\\
在这轮中，其他同学将在第二组。数字间用空格分隔。同学编号顺序任意。...........................................................................\\

如果有多个最佳解决方案，请输出其中任何一个。...............................................................................................
$$

### 题目分析

$$
题目要求寻找最少的轮次能够使每队同学都对抗一次，首先可以想到这道题需要使用递归方法，寻找到一个比较好的逻辑来解题，暴力解题找到的一定不是最少的轮次。......\\
再往深层思考，能够分层并打散处理一块数据的，就是使用类似于归并排序的分治法。实际上用此方法是可以达到全覆盖的。.........................................\\
我们可以把同一层拆分出来的左半部分归为一个数组，右半部分归为一个数组，让两者对抗，这样做的最终效果就是，每一个左侧的数组元素都跟自己右侧的数组元素对抗过。
$$



### 所用方法举例

$$
假设输入为7，数组内有1-7七个数。........................................................................................................
$$



|  1   |  2   |  3   |  4   |  5   |  6   |  7   |
| :--: | :--: | :--: | :--: | :--: | :--: | :--: |

$$
利用分治法将其分开：......................................................................................................................
$$


**第一层：**

| 1 2 3 4 5 6 7 |
| :-----------: |

**第二层：**

| left : 1 2 3 4 | right : 5 6 7 |
| :------------: | :-----------: |

**第三层：**

| left : 1 2 | right : 3 4 | left : 5 6 | right : 7 |
| :--------: | :---------: | :--------: | :-------: |

**第四层：**

| left : 1 | right : 2 | left : 3 | right : 4 | left : 5 | right : 6 | individual : 7 |
| :------: | :-------: | :------: | :-------: | :------: | :-------: | :------------: |

$$
然后使用刚才的逻辑，将每层的左半部分归为第一组，右半部分归为第二组：.........................................................................
$$

**第一层：**

| 1 2 3 4 5 6 7 |
| :-----------: |

**第二层：**

| left : 1 2 3 4 | right : 5 6 7 |
| :------------: | :-----------: |

**第三层：**

| left : 1 2 5 6 | right : 3 4 7 |
| :------------: | :-----------: |

**第四层：**

| left : 1 3 5 | right : 2 4 6 | individual : 7 |
| :----------: | :-----------: | :------------: |

$$
因为使用的是归并排序的方法，所以当left == right的时候就不会再分了，.........................................................................
\\层数更高的时候就没有必要细化单独出来的元素了(如上例中的7，因为这些元素在之前的层已经与所有的元素对抗过一次了)。.................................
\\可见所用总轮次为\lceil log_2n\rceil，第二层及以上每一层的left可视为每轮的第一组。.........................................................................
$$



### 证明轮次最少

$$
首先假设第一轮分成1\cdots i和i+1\cdots n两组，显然当i=\frac{1}{2}时总对抗次数为\frac{n^2}{4}最大。..................................................................................................................\\
这时两边的编号都已经相互对抗过了。先看1\cdots i这组编号，若把它当作一个新的整体，显然取j=\frac{i}{2}可以使这一轮的总对抗次数最大，i+1\cdots n这组同理。........................................................\\
 这时我们就可以得到四等分的数组，但是题目要求只让每一轮有两个组，所以我们可以把第一组和第三组合起来，第二组和第四组合起来(因为一和三、二和四在第一轮时已经对抗过，合为一组是最高效的)。.................\\
 此时我们的第二轮已经分完组了，第二轮的总有效对抗次数为\frac{n}{4}*\frac{n}{4}+\frac{n}{4}*\frac{n}{4}=\frac{n^2}{8}。...............................................................................................................\\
 同理可算得第i轮最大有效对抗次数为\frac{n^2}{2^{i+1}}。所需的总对抗次数为\frac{n*(n-1)}{2}，而前t轮的有效对抗次数之和为\frac{n^2}{2}-\frac{n^2}{2^{t+1}}，当两者相等时t=log_2n，所以最少的轮次为\lceil log_2n\rceil(若n不是二的整数次幂就需要多一轮来处理)。
$$



### AC代码

```c
#include<stdio.h>
#define MAXN 1005

int a[MAXN]; // 全体学生的编号 
int stu[MAXN][MAXN]; // 所保存的第i轮中的第一组人数 
int times; // 一共需要比几轮
int nums[MAXN]; // 第i轮第一组有多少人 

void findLeft(int rank, int left, int mid){
	int lenl = mid - left + 1; // 左边部分的长度 
	int i;
	if(times < rank){
		times = rank; // 轮数等于层数的最大值 
	}
	for(i = 0;i < lenl;i++){
		stu[rank][nums[rank]++] = a[left + i]; // 将同层的左半数组划分为一组 
	}
}

int mergeSort(int rank, int left, int right){ // 递归将数组划分为小块 
	if(left < right){
		int mid = left + (right - left) / 2; // 将数组left到right的部分划成左右两半 
		mergeSort(rank + 1,left,mid); // 继续将左半部分划分 
		mergeSort(rank + 1,mid + 1,right); // 继续将右半部分划分 
		findLeft(rank,left,mid); // 找到左边的部分 
	}	
}

int main(){
	int i,j,n;
	scanf("%d",&n); // 输入学生数量 
	for(i = 0;i < n;i++){
		a[i] = i + 1; // 输入学生编号 
	}
	mergeSort(1,0,n - 1); // 分治 
	printf("%d\n",times); // 打印出轮数 
	for(i = 1;i <= times;i++){
		printf("%d ",nums[i]); // 打印出第i组的轮数 
		for(j = 0;j < nums[i];j++){
			printf("%d ",stu[i][j]); // 打印出第i组的学生 
		}
		printf("\n"); // 换行 
	}
	return 0;
}
```
