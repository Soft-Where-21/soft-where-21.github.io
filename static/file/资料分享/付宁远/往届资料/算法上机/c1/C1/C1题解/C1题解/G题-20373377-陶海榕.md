# 题意



***



读题可知，初始局面是树根，Matrix53先行棋，选择树根的各子节点中Matrix53胜率最大的子节点（设为M1），然后Alex行棋，选择M1中Matrix53胜率最小的子节点，依次重复直到叶子节点。因此我们要从树根开始，交替选择最大or最小胜率。

# 题解



***



**题目没有说明一个节点可以有多少个子节点**，我们不妨用**链表**构成的数组来保存各节点的子节点。    

观察这个交替选择的操作，我们其实可以把它分解成**若干个相似的子问题**，即寻找一个节点的各子节点的MAX或者MIN，因此我们可以想到用**递归**来解决这个问题。

于是我们创建一个BFS函数，传入节点和状态（1或0），根据状态返回MAX或者MIN，边界条件就是没有叶子节点了，此时直接返回输入的s即可。   

~~~C
int BFS(int m, int M){
	int max = 0, min = 1e9;
	Link p = x[m];
	if(p == NULL)return s[m];
	while(p != NULL){
		int tmp = BFS(p->son, M==1?0:1);
		if(tmp > max)max = tmp;
		if(tmp < min)min = tmp;
		p = p->next;
	}
	s[m] = M==1?max:min;
	return s[m];
}
~~~



最后我们只需要输出BFS（树根，1）即可。

时间复杂度取决于树的高度和子节点个数。

# 代码



***



```C
#include <stdio.h>
#include <stdlib.h>
typedef struct inode{
	int son;
	struct inode* next; 
}node, *Link;
int MAXN = 1000000+5
Link x[MAxN];
int s[MAXN];
int BFS(int m, int M){
	int max = 0, min = 1e9;
	Link p = x[m];
	if(p == NULL)return s[m];
	while(p != NULL){
		int tmp = BFS(p->son, M==1?0:1);
		if(tmp > max)max = tmp;
		if(tmp < min)min = tmp;
		p = p->next;
	}
	s[m] = M==1?max:min;
	return s[m];
}
int main(){
	int n;
	scanf("%d", &n);
	int i;
	for(i = 0; i < n-1; i++){
		int a, b;
		scanf("%d%d", &a, &b);
		Link p = (Link)malloc(sizeof(node));
		p->son = b;
		p->next = x[a];
		x[a] = p;
	}
	int p = 1;
	while(p <= n){ // x[p] == NULL的就是叶子节点了，按顺序赋值即可
		while(x[p] != NULL)p++;
		scanf("%d", &s[p]);
		p++; 
	}
	printf("%d", BFS(1, 1));
	return 0;
}
```
