# 考核内容

## 英语思政面试（15min）

- 思政：只有通过和不通过两种，只要回答的符合社会主义核心价值观即可，考核方式为从桌子上纸条随机抽一个，然后朗读出来，思考一段时间 ，然后开始作答。
- 英语：和 22 级面试不一样，改成了 8min 的英语自我介绍，结合个人专业背景、科研项目、工程实践、科技活动与获奖成果等，自我介绍完之后老师会提问一些关于你简历上的内容，简历上的细节（没有问我生活上的常识上的问题，都是专业知识的提问），提问方式有的考场是中文问英文回答，有的是英文问英文回答（我是中文提问）。

## 综合面试（15min）

也和去年不一样，不允许准备 ppt（但是可以打印出来发给评委老师），进去先进行 8min 自我介绍，然后老师根据简历提问关于简历的问题以及数学问题（有的人被问了，但是我没被问）。

# 个人见解

卓工选择一方面是为了一些在学保边缘的学生有一个更多的选择，另一方面也是为了想更早进入企业的学生，前两年在学校，后三年在企业，重点是要跟对导师，有的导师在企业话语权小，合作不密切，到最后就会出现三不管的状态（老师，学校，企业），甚至有可能同时做完全不同的方向。

跟对老师的话就可以做到，即享用企业的资源，且可以专注自己的学术任务，同时在前两年也可以去华为实习（带薪自习室，做自己的事情）
