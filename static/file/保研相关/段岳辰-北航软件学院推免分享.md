## 游记

北航软院基本属于强com，且机试占比非常高，因此只要机试发挥较好基本不用担心。

机试使用北航的accoding OJ，只能使用C语言，分值是20+20+15+15+10+10+5+5，前面的题目比较基础基本只要掌握C语言的常用语法。后面两个题目是一个单调队列优化dp和一个SA（或者SAM），没带后缀数组的板子于是只能打了个暴力倒闭（）。机试对于有XCPC或者OI经历的来说还是比较容易的，没有相关经历也没关系，可以提前在洛谷上做做大概黄题/橙题难度的题目就够用了。

面试大概就是四五个老师围在一起问你问题（bushi），首先是宣读诚信承诺书，之后会问你思政问题，一般只要不要回答太离谱就不会有事，问我的是关于新质生产力，我之前甚至没有听过这个词（）。然后是英语方面的提问，都是问一些很日常的问题，基本不需要特别准备。之后博士生会开始PPT展示，硕士生开始专业知识提问，数学上问我的是泰勒展开的应用，专业课问的是软件工程方面的问题，主要问的是如何将AI投入到软件工程开发中。总的来说面试官都很友好，基本没有给太大压力。

最后博士录取比例还是相当高的，录取了20多个。
