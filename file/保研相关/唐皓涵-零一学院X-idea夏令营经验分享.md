# 深圳零一学院 X-idea 夏令营经验分享（2026 年）

作者：唐皓涵  
参营年份：2026 年（2027 届毕业）  
分享范围：本人参加的导师选拔与黑客松考核，不披露导师姓名。

我参加的这次零一学院 X-idea 活动，主要用于一位老师筛选学生。按照我对当时申请流程的理解，这条路径比较接近大家常说的“弱 com”：导师的接收意向很重要，夏令营的主要目标是获得导师的口头 offer，后续仍需要参加清华的正式考核。

这次考核主要分为 **黑客松项目和面试** 两部分，更关注项目实践能力，以及简历中的科研、工程经历是否扎实。这里介绍的是我参加的具体导师选拔安排。

## 一、活动背景与整体流程

零一学院2026 年 X-Idea 交叉创新挑战问题共创营整体活动时间为 **7 月 4 日至 8 日**，地点为深圳南山总部，并强调跨学科探索和学生、导师的双向匹配。

官网记录的是整体活动；我实际参与的黑客松与导师考核，在不到三天内完成项目，并在第三天集中面试和答辩。下表按我的实际考核流程整理，不把整体活动的五天日程直接套用到个人考核上。

| 阶段 | 主要内容 |
| --- | --- |
| 选题与分配 | 发布多个选题，根据问卷填写情况进行分配 |
| 项目开发 | 在不到三天的时间内完成 demo，并准备答辩展示 |
| 第三天上午 | 个人面试 |
| 个人面试后 | 集体进行黑客松结项答辩 |
| 后续申请 | 获得导师接收意向后，继续准备清华预推免复试 |

第三天需要连续完成面试和项目答辩，因此前两天除了推进开发，也要为简历复盘和展示准备留出时间。

## 二、黑客松：短时间内完成可展示的项目

黑客松开始时会发布多个选题，大家填写问卷，再进行选题分配。我最终选择的是 **搭建带有 RAG（检索增强生成）的电商广告生成系统**，需要在不到三天的时间内完成 demo 和答辩展示。

这个环节的时间压力比较明显。拿到题目后，需要迅速理解任务、确定方案、完成开发，再把项目讲清楚。因此，除了技术能力，任务拆解和时间安排也很重要。

我的建议是，尽早确定能够交付的核心功能，优先跑通完整流程，再根据剩余时间完善效果。对于这类带有 RAG 的生成系统，准备答辩时可以重点解释检索信息如何参与生成、为什么采用这套方案，以及系统当前有哪些局限。

展示也需要提前准备：既要有能够运行的 demo，也要能够说明问题、方案和结果。不要把所有时间都投入开发，最后才开始整理答辩材料。

## 三、面试：重点核查项目经历与个人贡献

面试安排在第三天上午，基本流程是 **自我介绍，加上围绕简历项目的深入追问**。

老师很关注项目是不是自己真实、踏实地做过，也会通过具体问题判断你对工作的熟悉程度。例如，可能会要求现场背出论文摘要。这类问题要求你对自己写过的论文和做过的项目足够熟悉。

准备时，建议把简历中的每项工作都重新梳理一遍：

- 这项工作解决什么问题，为什么值得做？
- 核心方法是什么，为什么采用这个方法？
- 自己具体承担了哪些部分？
- 实验或系统是如何实现的？
- 得到了什么结果，有哪些不足？
- 如果继续做下去，下一步会如何改进？

论文摘要、主要贡献和关键实验结论尤其值得熟悉。面试中既要能够概括工作，也要能够进入细节，说明自己的贡献和判断。

**我参加的这次面试没有遇到单独的专业课问答、英语面或思政面。** 准备重点可以放在自我介绍、简历项目和科研经历上；这一点仅对应我参加的这次导师选拔，其他老师或其他批次的安排可能不同。

## 四、第三天：先面试，再集体答辩

第三天上午先进行个人面试，紧接着是集体黑客松答辩。两项考核放在同一天，要求提前把准备工作安排好。

个人面试主要围绕已有经历展开，黑客松答辩则需要展示这几天完成的项目。建议前两天就同步整理演示流程和答辩材料，提前检查 demo 是否稳定，并梳理项目中需要解释的技术选择。

## 五、口头 offer 与后续复试

按照我对当时流程的了解，获得导师口头 offer 后，进入清华预推免复试的机会比较大。这是对当时申请路径的个人理解，没有可据此给出的成功率；口头接收意向与正式录取之间仍有后续考核，需要继续认真准备。

我了解到的后续复试主要包括 **ACM 风格上机和面试**。清华部分会有其他同学详细介绍，这里就不展开。

对于这次夏令营，我最想强调的两点是：**黑客松要在有限时间内完成可运行、可展示的成果；简历中的项目和论文要足够熟悉，能够经得起细节追问。**
