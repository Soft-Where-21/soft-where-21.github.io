## 1. 提取函数调用及参数

**来源**：6 系 2020 年推免复试参考资料（2021 届）第 1 题 ｜ **题解文件名**：`findFunc.c`

### 题目

输入一行普通 C 语句（函数体内的一条可执行语句，非 `if`/`for`/`while`/`do` 等控制语句），识别其中的函数调用，分行输出函数名和实参。

- 实参可为变量、数字常量或表达式；**不含字符串/字符常量**，也**不含嵌套函数调用、不含带圆括号的表达式**
- 语句中可能有空白符；字符数 ≤ 100
- 输出：每行一个调用（按出现先后），函数名与实参、实参之间用一个空格分隔；**每行最后一个实参后（无实参时是函数名后）还要有一个空格**；实参是表达式时原样输出、中间无空格；没有函数调用则无任何输出

**样例**

```
输入1：area = areaOfTri ( a ,b,c) + areaOfRec(30, 50 ) ;
输出1：areaOfTri a b c
       areaOfRec 30 50

输入2：m = max(a + b, array [ a ] , structvar.a );
输出2：max a+b array[a] structvar.a
```

> 上面每个输出行的**末尾都有一个空格**。

### 思路

```
扫标识符（字母或 _ 开头）
  ├ 跳过空白后是 '(' → 是函数调用：输出「名字 + 空格」，再进参数
  │     循环：遇 ',' 结束一个实参；空白全丢；遇 ')' 结束
  │     每个实参后跟一个空格（含最后一个），结束后换行
  └ 否则不是调用，直接跳过
```

- **名字和 `(` 之间可能有空格**（样例 1 就是 `areaOfTri (`），必须先跳空白再判断，否则整个调用会漏掉。
- **每项后面补空格**（函数名一个、每个实参一个），别用"参数前补空格"的写法——题目要求行尾也有空格。
- 参数里的 `[` `]` `.` 都是普通字符，原样保留（`array [ a ]` → `array[a]`）。
- 题目保证实参里没有嵌套调用和括号 → **不用数括号深度**。
- 标识符要认 `_`：起头 `isalpha(c) || c == '_'`，后续 `isalnum(c) || c == '_'`。

复杂度 O(L)。

### 代码

```c
/* 北航机试「提取函数调用及参数」findFunc.c
 * 扫标识符 → 跳过空白后紧跟 '(' 即为函数调用
 * 实参按 ',' 断开、空白全部压掉，每项（含最后一项）后跟一个空格
 */
#include <stdio.h>
#include <ctype.h>
#include <string.h>

char s[128];
int n, p = 0;                                  /* p：当前扫描位置 */

/* 进入时 p 指向 '('；输出本行实参 + 换行，返回时 p 停在 ')' 之后 */
void args(void) {
    char buf[128];
    int k = 0;

    p++;                                       /* 跳过 '(' */
    while (p < n && s[p] != ')') {
        if (s[p] == ',') {                     /* 一个实参结束 */
            if (k) { buf[k] = '\0'; printf("%s ", buf); k = 0; }
        } else if (!isspace((unsigned char)s[p])) {
            buf[k++] = s[p];                   /* 空白全丢，其余原样保留 */
        }
        p++;
    }
    if (k) { buf[k] = '\0'; printf("%s ", buf); }   /* 最后一个实参 */
    if (p < n) p++;                            /* 跳过 ')' */
    putchar('\n');
}

int main(void) {
    if (fgets(s, sizeof s, stdin) == NULL) return 0;
    n = (int)strlen(s);

    while (p < n) {
        if (isalpha((unsigned char)s[p]) || s[p] == '_') {
            int start = p, j, i;
            while (p < n && (isalnum((unsigned char)s[p]) || s[p] == '_')) p++;
            j = p;
            while (j < n && isspace((unsigned char)s[j])) j++;   /* 跳过名字与 '(' 之间的空白 */
            if (j < n && s[j] == '(') {
                for (i = start; i < p; i++) putchar(s[i]);
                putchar(' ');                  /* 函数名后一个空格（无实参时它就是行尾空格） */
                p = j;
                args();
            }
        } else {
            p++;
        }
    }
    return 0;
}
```

## 2. 机场送站顺序

**来源**：6 系 2020 年推免复试参考资料（2021 届）第 2 题 ｜ **题解文件名**：`send.c`

### 题目

登机口呈树形排列，安检处是根（编号固定 100），登机口是叶子（编号 1~99），分叉节点编号 ≥ 100。

- 输入：① 节点个数 `T`，随后 `T` 行「节点 父节点」（根的父节点写 0；父节点信息先于子节点给出；每个分叉节点最多 4 个分叉子节点 + 4 个登机口子节点）；② 旅客数 `N`，随后 `N` 行「姓名 登机口 优先级」（优先级 0 最高，保证不并列）
- 送站规则：① 先送优先级最高的旅客；② 途中若某旅客的登机口**直接连在车经过的分叉节点上**，可顺路下车，同一分叉节点上优先级高的先下；③ 送完当前旅客后，从当前位置出发，再选剩下优先级最高的继续送，直到全部下车
- 输出：按下车顺序分行输出「姓名 登机口」

### 思路

**路线用 LCA 求，下车顺序按「经过顺序」排。**

- 每趟的目标 = 此刻**仍在车上**优先级最高的旅客；路线 = 从当前位置**上溯到 LCA**，再**下行到目标**。
- 题面说送站到「登机口**（实为登机口所属分叉节点）**」——车其实只开到**目标登机口的父分叉节点**，登机口自己不进路线（样例路线 `100→102→107→110` 到 110 就停）。用登机口当叶子算 LCA 只多最后一跳，而那一跳不产生下车动作，两者等价。
- **下车顺序 = 车经过分叉节点的先后顺序，不是优先级顺序**。样例第 1 趟就是铁证：`sunhui` 优先级 0（全场最高）最先上车，却第 4 个才下——`wuguo/songyu/huanglei` 的登机口 14、13 直接挂在 **107** 上，车路过 107 时他们先下。
- **只有同一个分叉节点内部**才按优先级排（0 先）：107 上是 4→5→8，105 上是 3→6→7。
- **必须逐趟模拟**：顺路下车会把别人提前送走，真正的「目标序列」只是「按优先级排序」的一个**子序列**，不能一次排完。一趟也可能送多人（样例第 1 趟送了 4 个）。
- **不用求深度/倍增**：分叉节点 ≤ 100，直接「从当前位置把整条祖先链打标记，再从目标节点上溯，撞到的第一个标记点就是 LCA」。
- 节点编号**不编码深度**（登机口 1~99 与分叉 ≥ 100 混编，父节点也可能是 100），只能靠 `par[]` 上溯；根的父亲是 0，上溯到 0 停。
- 边界：当前位置恰好等于目标节点（两人同一登机口）时，路径退化成单个节点，别越界。

**三趟路线**（对照样例）

1. 目标 `sunhui`（12 号口，优先级 0）：`100 → 102 → 107 → 110`，在 107 下 `wuguo 14、songyu 13、huanglei 14`，到 110 下 `sunhui 12`
2. 目标 `zhaomeng`（8 号口，优先级 1）：`110 → 107 → 102 → 105 → 109`，在 105 下 `zhoufei 6、qianliang 6、chenxiu 6`，到 109 下 `zhaomeng 8`
3. 目标 `lihong`（4 号口，优先级 2）：`109 → 105 → 102 → 101 → 104`，到 104 下 `lihong 4`

**复杂度**：版本一最坏 O(N² × 深度)，版本二降到 O(N log N + 趟数 × 深度)——两版对照见下面「代码」。

### 代码

两个版本**输出完全一致**，任选一个提交（科目目录里的 `send.c` 实体文件是版本一）。

**版本一：直观实现**（照模拟直接写，题面规模下最省事）

```c
/* ============================================================================
 * 北航机试第 2 题「机场送站顺序」     提交文件名：send.c / send.cpp
 * 来源：6 系 2020 年推免复试参考资料（2021 届）机试第 2 题
 * ----------------------------------------------------------------------------
 * 【题意转化】
 *   所有登机口呈树形挂在分叉节点下，安检处是树的根（编号固定为 100）。
 *   电瓶车一次载若干旅客，按下面三条规则决定下车顺序：
 *     1) 挑「当前车上优先级最高」的旅客作为本趟的送站目标（0 优先级最高）；
 *     2) 去目标的路上，凡「登机口直接挂在车所经过的分叉节点上」的旅客，
 *        可顺路下车；同一个分叉节点上有多人时，优先级高的先下；
 *     3) 送完本趟目标后回到第 1 步，从「车现在停的位置」重新出发，直到全部下车。
 *
 *   题面特别注明：送站目的地「实为登机口所属分叉节点」——
 *   即电瓶车只开到【目标登机口的父分叉节点】，登机口自己不进路线。
 *   （样例解说里 sunhui 的路径是 100->102->107->110，到 110 就停了，没开去 12 号口。）
 *
 * 【两个核心结论】
 *   A) 路线 = 树上两点间的唯一简单路径 = 从当前位置上溯到 LCA，再从 LCA 下行到目标。
 *      所以只要会求 LCA，路线就唯一确定了。
 *   B) 下车顺序 = 【车经过分叉节点的先后顺序】，不是优先级顺序！
 *      只有「同一个分叉节点内部」才按优先级排。
 *      铁证：样例里 sunhui 优先级 0（全场最高）最先上车，却第 4 个下车——
 *      因为 wuguo/songyu/huanglei 的登机口 14/13 直接挂在 107 上，车路过 107 时他们先下。
 *
 * 【必须逐趟模拟，不能一次排完】
 *   本趟目标固定是「车上优先级最高的人」，但顺路下车会把别人提前送走，
 *   所以真正的「目标序列」只是「按优先级排序」的一个【子序列】。
 *
 * 【复杂度】
 *   分叉节点 ≤ 100、登机口 ≤ 99，树很小。每趟 O(深度 × 人数)，趟数 ≤ 人数。
 * ============================================================================
 */

#include <stdio.h>
#include <string.h>

#define MAXN 256    /* 树节点总数上限（≤100 分叉 + ≤99 登机口 = 199，留余量） */
#define MAXP 256    /* 旅客数上限 */

/* ---------------------------- 树 ---------------------------- */
static int par[MAXN];   /* par[x] = 节点 x 的父节点；根（100）的父节点为 0 */
static int mark[MAXN];  /* 求 LCA 用：标记 cur 的整条祖先链 */
static int path[MAXN];  /* 本趟车的行驶路线，按「经过顺序」存分叉节点编号 */

/* --------------------------- 旅客 --------------------------- */
static char nm[MAXP][32]; /* 姓名（题面说不超过 20 个字母） */
static int  gate[MAXP];   /* 登机口编号 1~99 */
static int  prio[MAXP];   /* 优先级，数值越小越优先（0 最高） */
static int  used[MAXP];   /* 是否已经下车 */
static int  N;            /* 旅客总数 */

int main(void) {
    int T;                /* 树节点个数 */
    int i, x, y, k;
    int cnt;              /* 本趟路线的节点个数 */
    int cur;              /* 车当前所在节点（初始为安检处 100） */
    int served;           /* 已下车人数 */
    int seg[MAXN], sc;    /* LCA 下行段的临时缓冲，以及它的长度 */
    int best;             /* 在某个节点上挑出的「下一个该下车的人」 */

    /* ---- 1. 读入树：T 行，每行「子节点 父节点」；根的父亲写作 0 ---- */
    if (scanf("%d", &T) != 1) return 0;
    for (i = 0; i < T; i++) {
        int c, p;
        scanf("%d %d", &c, &p);
        par[c] = p;
    }

    /* ---- 2. 读入旅客：姓名 登机口 优先级 ---- */
    scanf("%d", &N);
    for (i = 0; i < N; i++)
        scanf("%s %d %d", nm[i], &gate[i], &prio[i]);

    cur = 100;            /* 电瓶车初始停在安检处（树的根） */
    served = 0;

    /* ---- 3. 逐趟模拟：每趟送一位「目标旅客」，外加沿途顺路的人 ---- */
    while (served < N) {
        int t = -1;
        int nodeT;        /* 本趟目标登机口所属的分叉节点 = 车真正的终点 */

        /* 3.1 选目标：还没下车的旅客里优先级最高的那一位（prio 最小） */
        for (i = 0; i < N; i++)
            if (!used[i] && (t < 0 || prio[i] < prio[t])) t = i;

        /* 登机口是叶子，它的父亲就是车要开到的那个分叉节点 */
        nodeT = par[gate[t]];

        /* 3.2 求路线第一步：把 cur 的整条祖先链打上标记
         *     （cur 自己、它的父亲、祖父…… 一直到根，全部标记）
         *     同时先按「自下而上」的顺序把上行段记进 path。
         *     终点条件 x != 0 是因为根的父亲是 0，遇到 0 说明已到顶。 */
        memset(mark, 0, sizeof mark);
        cnt = 0;
        for (x = cur; x != 0; x = par[x]) {
            mark[x] = 1;
            path[cnt++] = x;
        }

        /* 3.3 从目标节点往上走，撞到的第一个已被标记的节点就是 LCA
         *     （cur 的祖先链已全标记，所以两边祖先的第一次「相遇点」即最近公共祖先）
         *     循环结束后 y 就是 LCA。 */
        y = nodeT;
        while (!mark[y]) y = par[y];

        /* 3.4 补上「下行段」：目标节点向上到 LCA（不含 LCA）这一段。
         *     上溯时收集到的是自下而上，所以要倒着接到路线尾部，
         *     这样整条 path 恰好就是「车实际经过的顺序」。
         *     特例：nodeT 本身就是 LCA（或 nodeT == cur）时 sc == 0，
         *     路径退化成单个节点，代码依然正确，不会越界。 */
        sc = 0;
        for (x = nodeT; x != y; x = par[x]) seg[sc++] = x;
        while (sc > 0) path[cnt++] = seg[--sc];

        /* 3.5 沿路线「经过顺序」逐节点安排顺路旅客下车 */
        for (k = 0; k < cnt; k++) {
            /* 一个分叉节点最多挂 4 个登机口，可能有多人都顺路。
             * 反复挑「优先级最高」的那位输出，就实现了
             * 题面要求的「同一分叉结点上有多个顺路旅客时，优先级高的先下车」。 */
            for (;;) {
                best = -1;
                for (i = 0; i < N; i++)
                    if (!used[i] && par[gate[i]] == path[k]
                        && (best < 0 || prio[i] < prio[best]))
                        best = i;
                if (best < 0) break;            /* 这个节点上没人顺路了 */
                printf("%s %d\n", nm[best], gate[best]);
                used[best] = 1;
                served++;
            }
        }

        /* 3.6 本趟结束：车停在目标登机口所属的那个分叉节点上，作为下一趟的起点 */
        cur = nodeT;
    }
    return 0;
}

 * 【测试 & 递交提醒】
 * 1) 题面样例的输入里混着 PDF 的页码——"18 103" 后面孤立的 7、
 *    旅客列表中间的 8 和 9。真实数据是 29 条树边 + 9 名旅客，
 *    抄进测试文件时记得删掉那几个页码，否则读入全乱。
 * 2) 编译：gcc -std=c89 -Wall，无 warning（Dev-C++ 默认 gnu89 同样可过）。
 * 3) 输出即下车顺序，每行「姓名 登机口」。
 * ============================================================================
 */
```

**版本二：桶优化（通用化）**

先看版本一慢在哪——它有两处「在全部 N 名旅客里线性扫描」：

- 每趟选目标：`趟数 × O(N)`
- 车每经过一个分叉节点，又重扫一遍 N 人，挑「登机口挂在这个节点上、优先级最高」的人：`O(路径长 × N)`

合计最坏 **O(N² × 深度)**。题面只限定了「分叉节点 ≤100、登机口 ≤99」，**没有限定旅客人数**（同一个登机口可以站很多人），N 一大就退化。

于是做两处替换：

| 要解决的问题 | 版本一 | 版本二 |
| --- | --- | --- |
| 找「当前优先级最高的未下车旅客」 | 每趟扫一遍 N 人 | 按优先级排一次序，用**只往前走的指针**跳过已下车的人 → 摊还 O(1) |
| 找「挂在某分叉节点上、优先级最高的未下车旅客」 | 每个节点扫一遍 N 人 | 按 `(登机口所属分叉节点, 优先级)` 排一次序 + **链表建桶**，走到该节点 O(1) 弹出 |

- 选目标**用不上堆**：这里的「删除」是单调向后的，指针一路往前推就够，总共移动不超过 N 次。
- 建桶小技巧：排序后同一节点的人已经连续且升序，**倒着遍历做头插**，链表顺序仍是升序，不必另写插入排序。
- 复杂度：**O(N² × 深度) → O(N log N + 趟数 × 深度)**，`N log N` 全部来自两次 `qsort`。
- **主流程一字未改**：逐趟选目标 → 求 LCA → 补下行段 → 沿路径下车，骨架和版本一完全相同，只换了预处理和两处内层循环。

实测（深度 100 的链状树 + 99 个登机口；端到端耗时含约 4.4 ms 的进程启动开销）：

| 旅客数 N | 版本一 | 版本二 |
| --- | --- | --- |
| 99（题面规模） | 4.46 ms | 4.40 ms |
| 2000 | 6.32 ms（430 万次比较） | 4.68 ms |
| 20000 | 159.8 ms（4.07 亿次比较） | 9.0 ms |

```c
/* ============================================================================
 * 北航机试第 2 题「机场送站顺序」—— 桶优化版（通用化实现）
 * 提交文件名：send.c / send.cpp（与「版本一」二选一）
 * ----------------------------------------------------------------------------
 * 【与版本一的关系】
 *   主流程一模一样：逐趟选目标 -> 求 cur 到目标的 LCA -> 补下行段 -> 沿路径
 *   按「经过顺序」让顺路旅客下车 -> 车停在目标的父分叉节点，进下一趟。
 *   唯一差别是【怎么找目标】和【怎么找人下车】——这两处在版本一里都是
 *   「遍历全部 N 名旅客」的线性扫描，本版改成预处理 + 桶，降到摊还 O(1)。
 *
 * 【版本一慢在哪】
 *   1) 每趟选目标：在还没下车的人里线性挑优先级最高的  -> 趟数 x O(N)
 *   2) 车每经过一个分叉节点，又要在全部 N 人里重扫一遍，挑出「登机口挂在
 *      这个节点上」且优先级最高的人                    -> O(路径长 x N)
 *   最坏合计 O(N^2 x 深度)。题面只限制了「分叉节点 <= 100、登机口 <= 99」，
 *   【没有限制旅客人数 N】（同一个登机口可以站很多人），N 一大就退化：
 *   实测深度 100 的链状树 + 99 个登机口，N = 20000 时总比较 4.07 亿次。
 *
 * 【本版两处改动】
 *   改动 1（选目标）：把所有旅客按优先级升序排成 ord1[]，再用一个只往前走的
 *       指针 opos 指向「当前还没下车的最高优先级旅客」。有人下车只会让指针
 *       继续往前走，整个过程的指针移动总量不超过 N -> 摊还 O(1)。
 *       （不用堆：这里的「删除」是单调向后的，指针就够。）
 *   改动 2（下车）：把旅客按 (登机口所属分叉节点, 优先级) 排序，再用链表把
 *       同一个分叉节点的人串成【桶内优先级升序】的链表。车走到哪个节点，
 *       就从哪个桶的头上一路弹出 -> 弹出一个人 O(1)，且天然满足题面要求的
 *       「同一分叉节点上多个顺路旅客时，优先级高的先下车」。
 *       小技巧：排序后同一节点的人已经连续且升序，倒着遍历做头插，
 *               链表顺序仍然是升序，不必另写插入排序。
 *
 * 【复杂度】O(N log N + 趟数 x 深度)，其中 N log N 全部来自两次 qsort。
 *   版本一 O(N^2 x 深度)（深度 <= 100）；本版把 N^2 那一项彻底消掉。
 *
 * 【实测】（深度 100 链状树 + 99 个登机口；端到端含约 4.4 ms 进程启动开销）
 *   N = 99    （题面规模）：版本一 4.46 ms  / 本版 4.40 ms
 *   N = 2000            ：版本一 6.32 ms  / 本版 4.68 ms
 *   N = 20000           ：版本一 159.8 ms / 本版 9.0 ms
 *
 * 【编译】gcc -std=c89 -Wall -Wextra，零 warning；样例输出与版本一逐行相同。
 * ============================================================================
 */

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAXN 256      /* 分叉节点 <= 100 + 登机口 <= 99 = 199，留余量 */
#define MAXP 100005   /* 旅客数上限（题面未限制；N 更大就调大此值或改用 malloc） */

/* ---------------------------- 树 ---------------------------- */
static int par[MAXN];   /* par[x]：节点 x 的父节点，根（100）的父节点为 0 */
static int mark[MAXN];  /* 求 LCA 用：标记 cur 的整条祖先链 */
static int path[MAXN];  /* 本趟路线，按「经过顺序」存分叉节点编号 */

/* --------------------------- 旅客 --------------------------- */
static char nm[MAXP][24];  /* 姓名（题面 <= 20 个字母） */
static int  gate[MAXP];    /* 登机口编号 1~99 */
static int  prio[MAXP];    /* 优先级，数值越小越优先（0 最高） */
static int  used[MAXP];    /* 是否已下车：给「选目标指针」跳过用 */
static int  nxt[MAXP];     /* 桶内链表的后继，-1 表示链尾 */
static int  head[MAXN];    /* head[node]：挂在 node 下、还没下车的旅客链表头 */
static int  ord1[MAXP];    /* 按优先级升序的旅客下标（选目标用） */
static int  ord2[MAXP];    /* 按 (所属分叉节点, 优先级) 升序的下标（建桶用） */
static int  N;

/* qsort 比较函数：按优先级升序 */
static int cmpPrio(const void *A, const void *B) {
    int a = *(const int *)A, b = *(const int *)B;
    return prio[a] - prio[b];
}

/* qsort 比较函数：先按「登机口所属分叉节点」升序，同节点内再按优先级升序 */
static int cmpNode(const void *A, const void *B) {
    int a = *(const int *)A, b = *(const int *)B;
    int na = par[gate[a]], nb = par[gate[b]];
    if (na != nb) return na - nb;
    return prio[a] - prio[b];
}

int main(void) {
    int T;                        /* 树节点个数 */
    int i, j, x, y, k;
    int cnt;                      /* 本趟路线的节点个数 */
    int cur;                      /* 车当前位置（初始为根 100） */
    int served;                   /* 已下车人数 */
    int sc;                       /* LCA 下行段临时长度 */
    int nodeT;                    /* 本趟目标登机口所属的分叉节点 */
    int t;                        /* 本趟目标旅客下标 */
    int opos;                     /* 目标指针：指向 ord1 里第一个未下车的人 */
    int seg[MAXN];                /* 下行段缓冲 */

    /* ---- 1. 读入树：T 行「子节点 父节点」，根的父节点写 0 ---- */
    if (scanf("%d", &T) != 1) return 0;
    for (i = 0; i < T; i++) {
        int c, p;
        scanf("%d %d", &c, &p);
        par[c] = p;
    }

    /* ---- 2. 读入旅客：姓名 登机口 优先级 ---- */
    scanf("%d", &N);
    for (i = 0; i < N; i++) {
        scanf("%s %d %d", nm[i], &gate[i], &prio[i]);
        ord1[i] = i;
        ord2[i] = i;
    }

    /* ---- 3. 预处理 A：目标序列 ----
     * ord1 排成优先级升序后，opos 从 0 开始单向前移；跳过已下车的人，
     * 第一个没下车的 ord1[opos] 就是「当前优先级最高的旅客」。 */
    qsort(ord1, N, sizeof(int), cmpPrio);

    /* ---- 4. 预处理 B：下车桶 ----
     * 4.1 先按 (所属分叉节点, 优先级) 整体排序，同一节点的人就连续且升序；
     * 4.2 倒序遍历做头插 -> 链表顺序 = 正序 = 优先级升序。 */
    qsort(ord2, N, sizeof(int), cmpNode);
    memset(head, -1, sizeof head);
    for (i = N - 1; i >= 0; i--) {
        int who = ord2[i];
        int node = par[gate[who]];
        nxt[who] = head[node];
        head[node] = who;
    }

    cur = 100;      /* 车初始停在安检处（根） */
    served = 0;
    opos = 0;

    /* ---- 5. 逐趟模拟：骨架与版本一完全相同 ---- */
    while (served < N) {
        /* 5.1 选目标（摊还 O(1)）：指针只往后走，跳过已下车的人 */
        while (opos < N && used[ord1[opos]]) opos++;
        t = ord1[opos];

        /* 登机口是叶子，它的父亲就是车要开到的那个分叉节点 */
        nodeT = par[gate[t]];

        /* 5.2 把 cur 的整条祖先链打标记，同时按「自下而上」记下上行段 */
        memset(mark, 0, sizeof mark);
        cnt = 0;
        for (x = cur; x != 0; x = par[x]) {
            mark[x] = 1;
            path[cnt++] = x;
        }

        /* 5.3 从目标节点上溯，撞到的第一个已标记点就是 LCA */
        y = nodeT;
        while (!mark[y]) y = par[y];

        /* 5.4 下行段自下而上收集，再倒着接到路线尾部 */
        sc = 0;
        for (x = nodeT; x != y; x = par[x]) seg[sc++] = x;
        while (sc > 0) path[cnt++] = seg[--sc];

        /* 5.5 沿路径的经过顺序下车：走到哪个节点就把哪个桶清空。
         *     桶内已是优先级升序，边弹边输出即正确顺序；弹出时标 used，
         *     好让 5.1 的指针在下一趟跳过这些人。 */
        for (k = 0; k < cnt; k++) {
            while (head[path[k]] != -1) {
                j = head[path[k]];
                head[path[k]] = nxt[j];
                printf("%s %d\n", nm[j], gate[j]);
                used[j] = 1;
                served++;
            }
        }

        /* 5.6 本趟结束：车停在目标所属分叉节点上，作为下一趟的起点 */
        cur = nodeT;
    }
    return 0;
}
```

## 3. 二进制序列操作

**来源**：保研卷 ｜ **题解文件名**：见原卷

### 题目

给定一个二进制数（长度可能非常长），支持 4 种操作：`+` 加 1、`-` 减 1、`*` 乘 2、`/` 整除 2。给出初始二进制数和操作序列，求运算后的二进制数。

- 输入 3 行：第 1 行 `n m`（二进制数长度、操作个数）；第 2 行长度 `n` 的 01 串（无前导零）；第 3 行长度 `m` 的操作串
- 输出 1 行：结果二进制数（无前导零；结果为 0 则输出 `0`）
- 保证运算过程不会出现负数

**样例**

```
输入：3 4
      101
      +*-/
输出：101
```

### 思路

把二进制数按**低位在前**存进数组，用头尾指针 `start`（最低位）、`end`（最高位）标记。

不变式：`数值 = Σ a[i] · 2^(i - start)`。

- `*`：`start--`，新低位补 0（所有位权重翻倍，O(1)，不动任何位）
- `/`：`start++`（所有位权重减半，O(1)，不动任何位）
- `+`：从 `start` 向 `end` 进位——遇 1 变 0 继续，遇 0 变 1 停；越过 `end` 就新增最高位
- `-`：从 `start` 向 `end` 借位——遇 0 变 1 继续，遇 1 变 0 停；借到 `end` 则置 0 且 `end--`
- `end` 始终指向最高非零位 → 输出天然无前导零；`start > end` 表示结果为 0

**两个坑**

- 数组要**左右都预留**：`*` 让 `start` 左移最多 m 次，进位让 `end` 右移最多 m 次。开到 `n + 2m + O(1)`，初始数据放中间。若 `start` 从 0 起，第一次 `*` 就下标 −1。
- char 数组放**全局**：长度可能非常长，放栈上会爆栈。

复杂度 O(n + m)。

### 代码

```c
/* 北航机试「二进制序列操作」
 * 位数组 a[]：下标越小权重越低，不变式 数值 = Σ a[i] * 2^(i - start)
 * + 从 start 向 end 进位 / - 借位 / * start-- 补 0 / / start++
 * end 始终指向最高非零位 → 天然无前导零；start > end 表示结果为 0
 */
#include <stdio.h>

#define MAXN 4000005
#define GAP  5                    /* 左侧额外留白 */

static char a[MAXN];              /* 位数组（1 字节 1 位，省内存） */
static char buf[MAXN];            /* 二进制数字符串 */
static char op[MAXN];             /* 操作序列 */

int main(void) {
    int n, m, i, j, off, start, end;

    if (scanf("%d %d", &n, &m) != 2) return 0;
    if (scanf("%s", buf) != 1) return 0;
    if (scanf("%s", op) != 1) return 0;

    off = m + GAP;                                    /* 左边留 m 格给 '*' 左移 */
    for (i = 0; i < n; i++)                           /* 翻转 + -'0' */
        a[off + i] = (char)(buf[n - 1 - i] - '0');
    start = off;
    end = off + n - 1;

    for (i = 0; i < m; i++) {
        char c = op[i];

        if (c == '+') {                               /* 加 1 */
            j = start;
            for (;;) {
                if (j > end) { a[j] = 1; end = j; break; }   /* 全是 1：新增最高位 */
                if (a[j] == 0) { a[j] = 1; break; }          /* 0 -> 1，进位结束 */
                a[j] = 0; j++;                               /* 1 -> 0，继续进位 */
            }
        } else if (c == '-') {                        /* 减 1 */
            if (start > end) continue;                /* 值为 0（题目保证不出现负数） */
            j = start;
            for (;;) {
                if (j == end) { a[j] = 0; end--; break; }    /* 借到最高位，收缩 */
                if (a[j] == 1) { a[j] = 0; break; }          /* 1 -> 0，借位结束 */
                a[j] = 1; j++;                               /* 0 -> 1，继续借位 */
            }
        } else if (c == '*') {                        /* 乘 2：低位补 0 */
            a[--start] = 0;
        } else {                                      /* 整除 2：丢掉最低位 */
            start++;
        }
    }

    while (end >= start && a[end] == 0) end--;        /* 防御：收缩前导零 */
    if (end < start) { puts("0"); return 0; }         /* 结果为 0 */
    for (i = end; i >= start; i--) putchar('0' + a[i]);
    putchar('\n');
    return 0;
}
```

## 4. 图的连通性查询

**来源**：保研卷

### 题目

给定含 n 个顶点的图 G，两种操作：

1. 在两个顶点间加一条边（无向，**不保证两点间只有一条边**）
2. 询问两个顶点之间是否存在通路

- 输入第 1 行 `n m`（2 ≤ n ≤ 100000，1 ≤ m ≤ 1000000）；接下来 m 行每行 3 个整数：`op u v`（`op=1` 加边，`op=2` 询问；1 ≤ u, v ≤ n，u ≠ v）
- 每个询问输出一行：`YES` 互通 / `NO` 不互通

**样例**

```
输入：3 3
      2 1 2
      1 1 2
      2 1 2
输出：NO
      YES
```

### 思路

**裸并查集**。`op=2` 问的就是操作行里那两个点 `u`、`v` 是否互通：

```c
if (op == 1) { 合并 u、v 所在集合; }
else        { puts(find(u) == find(v) ? "YES" : "NO"); }
```

**不需要**邻接表、度数数组、边计数——查询只问"通不通"不问路径，存图纯属白费内存（m ≤ 10⁶ 时双向加边就是 2×10⁶ 条边）。

- 坑：别把"两点互通"误解成"整图连通"（样例第一次询问就会错输出 YES）。
- 输出必须**大写** `YES` / `NO`，每行都要换行。
- 允许重边，`ru == rv` 时跳过即可。
- 若真要判全图连通：维护连通块个数 `cnt`（初始 n，每次成功合并减 1，`cnt == 1` 即全连通），O(1) 且不受重边自环影响。

复杂度 O((n+m)·α)。

### 代码

```c
/* 北航「图的连通性查询」—— 并查集标准解
 * op=2 只问 u、v 两点是否互通 → 直接 find(u) == find(v)
 * 不需要邻接表 / 度数数组 / 边计数
 * n <= 100000, m <= 1000000 → 手写快读
 */
#include <stdio.h>

#define MAXN 100005

static int fa[MAXN], sz[MAXN];

static int readInt(void) {
    int c, x = 0, neg = 0;
    do { c = getchar(); } while (c != '-' && (c < '0' || c > '9'));
    if (c == '-') { neg = 1; c = getchar(); }
    while (c >= '0' && c <= '9') { x = x * 10 + (c - '0'); c = getchar(); }
    return neg ? -x : x;
}

static int find(int x) {
    int r = x, t;
    while (fa[r] != r) r = fa[r];                         /* 找根 */
    while (fa[x] != r) { t = fa[x]; fa[x] = r; x = t; }    /* 路径压缩 */
    return r;
}

int main(void) {
    int n, m, i, op, u, v, ru, rv, t;

    n = readInt();
    m = readInt();
    for (i = 1; i <= n; i++) { fa[i] = i; sz[i] = 1; }

    for (i = 0; i < m; i++) {
        op = readInt(); u = readInt(); v = readInt();
        if (op == 1) {
            ru = find(u); rv = find(v);
            if (ru != rv) {
                if (sz[ru] < sz[rv]) { t = ru; ru = rv; rv = t; }   /* 按大小合并 */
                fa[rv] = ru;
                sz[ru] += sz[rv];
            }
        } else {
            puts(find(u) == find(v) ? "YES" : "NO");
        }
    }
    return 0;
}
```

## 5. 学生身高分配问题

**来源**：保研卷（模型同 POJ 3263 Tallest Cow）

### 题目

N 名学生排队，编号 1…N，身高都是整数。当且仅当两人中间的学生都比他们矮时，两人才能互相看见。已知最高学生身高为 H，并给出 M 对"能互相看见"的关系，求每名学生身高的**最大可能值**。

- 输入第 1 行 `N H M`；接下来 M 行每行 `A B`，表示 A 和 B 能互相看见
- 输出 N 行，第 i 行为第 i 名学生可能的最大身高

**样例**

```
输入：9 185 5
      1 3
      5 3
      4 3
      3 7
      9 8
输出：185 184 185 183 184 184 185 185 185
```

### 思路

一对 `(A,B)` 能互相看见 ⇒ A、B 之间的每个人**严格矮于** `min(h[A], h[B])`。

要让身高最大 → 所有学生初值取 H，每对关系把中间区间 `[A+1, B-1]` **整体减 1**。这是标准**区间加**，差分 O(1) 处理，最后前缀和还原。

样例归一化后关系为 `(1,3)(3,5)(3,4)(3,7)(8,9)`，前四个分别把 `{2}`、`{4}`、`{}`、`{4,5,6}` 减 1，得到 `185 184 185 183 184 184 185 185 185`。

**三个必须处理的细节**

- **归一化**：题目给的 A 可能大于 B——**样例里就有 `5 3` 和 `4 3`**。不交换区间就算反，直接错。
- **去重**：同一对关系可能重复给出，不去重会被减两次、答案偏小。做法是 `qsort` 后相邻判重。
- **空区间跳过**：`B - A ≤ 1`（相邻或同一人）时中间没人，跳过。

差分数组要开到 `n + 2`：区间右端记的是 `diff[B]++`（不是 `B-1`），`B = n` 时会写到 `diff[n]`，而前缀和只扫到 n。

自检：如果输出里最大值不是 H，说明数据或逻辑有问题。

复杂度 O(N + M log M)。

### 代码

```c
/* 北航「学生身高分配问题」（= POJ 3263 Tallest Cow）
 * M 对 (A,B) 相互可见 → A、B 之间每个人都严格矮于 min(h[A], h[B])
 * 最大化 → 全取 H，每对关系把 [A+1, B-1] 整体减 1（差分 O(1)，最后前缀和还原）
 * 细节：① 关系对归一化 ② 去重 ③ 空区间跳过
 */
#include <stdio.h>
#include <stdlib.h>

typedef struct { int a, b; } Pair;

static Pair *r;
static int *diff;
static int n;

static int cmp(const void *x, const void *y) {
    const Pair *u = (const Pair *)x, *v = (const Pair *)y;
    if (u->a != v->a) return u->a - v->a;
    return u->b - v->b;
}

int main(void) {
    int h, m, i, a, b, t, s;

    if (scanf("%d %d %d", &n, &h, &m) != 3) return 0;
    r = (Pair *)malloc(sizeof(Pair) * (m > 0 ? m : 1));
    diff = (int *)calloc(n + 2, sizeof(int));

    for (i = 0; i < m; i++) {
        if (scanf("%d %d", &a, &b) != 2) break;
        if (a > b) { t = a; a = b; b = t; }        /* 归一化 */
        r[i].a = a;
        r[i].b = b;
    }

    qsort(r, m, sizeof(Pair), cmp);                 /* 排序 + 去重 */

    for (i = 0; i < m; i++) {
        if (i > 0 && r[i].a == r[i - 1].a && r[i].b == r[i - 1].b) continue;
        if (r[i].b - r[i].a <= 1) continue;         /* 中间没人 */
        diff[r[i].a + 1]--;                         /* [a+1, b-1] 整体减 1 */
        diff[r[i].b]++;
    }

    s = 0;
```
