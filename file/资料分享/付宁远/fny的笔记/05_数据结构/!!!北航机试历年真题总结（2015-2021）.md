### 六年规律（复习时怎么分配时间）

- **题型只有三族**：① **字符串处理**（2015-三 / 2016-一 / 2016-二 / 2017-二）② **树与图**（2017-三 / 2018-二 / 2019-二 / 2021-二）③ **模拟 + 排序 / 简单数据结构**（2015-一 / 2015-二 / 2017-一 / 2018-一 / 2019-一 / 2021-一）。
- **2017 年是分水岭**：从这一年起开始考树（17 年三题、18 年起两题，且 18 年起允许用 C++ 容器）。**2018 / 2019 稳定是「一道遍历/路径 + 一道统计/统计类数据结构」**，2021 回到「一题链表模拟 + 一题树 + 贪心」。
- **树题必定要解决「编号 → 结点」的映射**：编号不给规律时，要么「按行存 + 线性扫编号找行」（2021-二），要么「收集编号 → 排序去重 → 二分」（2018-二、2019-二）。参见「[[建树套路]]」那类整理。
- **两道求路径的题本质都是 LCA**（2017-三、2019-二）：先用父指针把深的对齐到同层，再一起上溯；2019-二还要把路径「上行段 + 倒序的下行段」拼出来。
- **格式细节年年有**，行尾空格尤其致命，见文末「附录 A」。
- **要背的不是题，是结构**：链表、树、编号映射、qsort 比较器、打表、记忆化表——这六年间反复就这六样，手搓写法见下一章**「手搓数据结构模板库（C89）」**（考场上改个 `MAXN` 直接抄）。

## 手搓数据结构模板库（C89）

> **建议动手写题之前先把这一章过一遍**（约 15 分钟）。机试考场上不能指望 STL（2018 年起才允许 C++ 容器，而且很多年份仍要求 C 语言），这里把六年间反复出现的"手搓"写法定型成模板，考场上改个 `MAXN` 直接抄。
> 每道题的「手搓要点」都注明了对应编号（如"模板 C-5"），看题时可以来回对照。
> 所有模板都用 **全局 `static` 数组 + 下标代替指针**：不用 `malloc/free`、不会内存泄漏、也不用担心指针判空。

### C-0 总则（先看这五条）

1. **大数组一律 `static`（放函数外）**：静态区自动零初始化。写成函数内的局部数组就落在**栈**上（macOS 默认 8 MB），`int a[1000000]` 一个就是 4 MB，几个就崩。
2. **"空"用 `-1`，不用 `0`**：编号 0 可能是合法结点。`static` 数组默认是 0，所以"空孩子 / 无父结点"必须在读入前**显式刷成 `-1`**。
3. **不写 `for (int i = …)`、不用 `bool`、不用 `//`**：`-std=c89` 只认 C89——变量声明在块首、注释用 `/* */`。本机 Dev-C++ 默认 gnu89 能容忍，但别赌考场编译器。
4. **"指针"就是下标**：`nxt[]`、`prv[]`、`par[]`、`kid[][3]` 里存的都是 `int` 下标，`-1` 表示空。这六年没有一道题需要真指针。
5. **要复用就把 `MAXN` 开大一点**：多开 5~10 个余量（下标 `-1`、循环里的 `i+2`、`j<i` 之类都靠它兜底）。

**这一章适用范围**

- 机试程序的典型形态：单文件、`main` + 几个函数、输入规模 10⁴~10⁶、不许用（或不想用）STL。本章所有模板都按这个前提写。
- 这五条不是风格洁癖，**每一条都对应一类真会崩的错误**：`static` 那条防的是栈溢出、`-1` 那条防的是"把合法编号 0 当空"、C89 那条防的是考场编译器拒绝编译。
- 用法：看题时如果发现"这题要建树 / 要编号映射"，直接翻到对应模板，改 `MAXN` 抄骨架，只写业务那几行。

### C-1 数组模拟双向循环链表

```c
#define MAXN 1005
static int val[MAXN];            /* 结点数据 */
static int nxt[MAXN], prv[MAXN]; /* “指针”：存下标 */

/* 建成环：0..n-1 首尾相接 */
for (i = 0; i < n; i++) { nxt[i] = (i + 1) % n; prv[i] = (i - 1 + n) % n; }

/* 从 cur 出发，恰好走一圈 */
x = cur;
do {
    /* 处理 x */
    x = nxt[x];
} while (x != cur);

/* 摘掉结点 b */
nxt[prv[b]] = nxt[b];
prv[nxt[b]] = prv[b];
/*  ⚠️ 右边用到的 prv[b] / nxt[b] 必须在被改写之前取完 */

/* 在 a 后面插入新结点 t */
nxt[t] = nxt[a];  prv[t] = a;  prv[nxt[a]] = t;  nxt[a] = t;
```

**应用场景**

- **什么时候该想到它**：题干出现「循环 / 环形 / 首尾相接 / 轮流 / 空闲块 / 内存块」，操作是"摘掉一个结点 + 插到别处"，而**结点自身的位置不能变**（位置就是它的地址或编号，业务数据挂在 `val[]` 上）。
- **这六年用在哪**：**2021-一**（空闲块 Best Fit）。那题把每块的长度存在 `val[]`，摘块 / 插块全靠 `nxt`/`prv`，分配时沿环走一圈找最合适的块——空闲块的**起始地址自始至终不变，只有长度在变**，这正是"位置不可变"的典型。
- **和 C-2 怎么选**：顺序表删一个 / 插一个要挪 O(n)，而这题每个请求都要沿空闲块表走一遍再摘块，结点上万时差距明显；"环状 + 频繁在中间摘插"是链表的主场。
- **别踩的坑**：① 走一圈必须 `do { … } while (x != cur)`，用 `while` 会漏掉起点；② 只剩一个结点时 `nxt[i] == prv[i] == i`，摘链等于把它自己接回去，遍历前先判；③ 摘结点的右侧值（`prv[b]`、`nxt[b]`）必须在改写之前取完。

### C-2 顺序表 / 静态单链表（"提到最前"这类操作）

```c
/* 写法一：顺序表（存下标，业务数据不搬） */
static int ord[MAXN];                    /* ord[0] 最靠前 */
for (i = 0; i < n; i++) ord[i] = i;

tmp = ord[k];                            /* 把 ord[k] 提到最前 */
for (j = k; j > 0; j--) ord[j] = ord[j - 1];
ord[0] = tmp;

/* 写法二：静态单链表（O(1) 摘接，但要维护前驱） */
static int nx[MAXN];
head = 0;
for (i = 0; i < n - 1; i++) nx[i] = i + 1;
nx[n - 1] = -1;

nx[pre] = nx[b];                         /* 摘出 b */
nx[b] = head; head = b;                  /* 接到表头 */
```

**应用场景**

- **什么时候该想到它**：题干出现「点击窗口 / 置顶 / 提到最前 / 最近使用 / 调整优先级」——本质是**维护一个顺序**，操作只有"把第 k 个元素挪到最前"和"按顺序输出"两种。
- **这六年用在哪**：**2015-二**（模拟鼠标点击窗口）。`ord[0]` 是最上层窗口，点中第 k 层就把它挪到 `ord[0]`，最后按 `ord[]` 顺序输出。
- **两种写法怎么挑**：结点数 ≤ 10³、只有"提到最前"这一种操作 → 顺序表（三行写完，和业务数据解耦）；结点数大、还要频繁在中间插删 → 静态单链表。这题的规模用顺序表更短。
- **别踩的坑**：① 顺序表"提到最前"要**从后往前挪**（`for (j = k; j > 0; j--)`），正着挪会把元素覆盖掉；② 单链表想摘掉一个结点必须知道它的**前驱**，所以要么额外维护 `pre[]`，要么直接上 C-1 的双向环；③ 输出顺序 = `ord[]` 的顺序，别按窗口编号输出。

### C-3 静态数组当树 · 孩子数组（度为 k）

```c
static int kid[MAXN][3];      /* kid[u][0..2] = 三个孩子的下标，-1 为空 */

for (i = 0; i < n; i++) kid[i][0] = kid[i][1] = kid[i][2] = -1;   /* 先刷 -1 */
/* 读入时：kid[u][k] = (c < 0) ? -1 : idx(c); */

/* 前序遍历：根 → 左 → 中 → 右（把判空放函数开头，调用处就能干净地调三次） */
void pre(int u, int d) {
    int k;
    if (u < 0) return;
    /* 处理 u（d 是深度，随递归带下去） */
    for (k = 0; k < 3; k++) pre(kid[u][k], d + 1);
}
```

**应用场景**

- **什么时候该想到它**：输入是「每行 父结点 孩子1 孩子2 孩子3」这种**父 → 子的边表**，问的是「前序遍历序 / 层次遍历序 / 深度 / 子结点个数 / 按层输出」——总之都是**往下走**的事。
- **这六年用在哪**：**2018-二**（前序统计，边遍历边比较 `(孩子数, 深度)`）、**2021-二**（层次遍历 + 排序贪心）、**2019-二**（BFS求 `dep[]`，随后交给 C-4 求路径）。
- **为什么不用指针树**：`kid[][3]` 的"空"是 `-1`，天然可判、不会被垃圾值坑；指针版要 `malloc`、要判空、要防泄漏，见 C-11。**六年里没有一道题值得用指针树。**
- **别踩的坑**：① 读入前**必须把 `kid[][]` 刷成 `-1`**（`static` 默认是 0，而 0 可能是合法结点）；② `-1` 不许喂给编号映射函数（C-5），否则会凭空多出一个假结点；③ 递归前序在**退化成链**的树上会吃掉与深度同阶的栈——深到 10⁵ 就改 BFS 或手工栈（C-6），本机 10⁴ 层没问题；④ 度不固定时别硬套 `[3]`，改成"孩子链表"（把 C-1 的 `nxt` 当兄弟链）或按最大度开够。

### C-4 静态数组当树 · 父指针 + 深度（LCA 专用）

```c
static int par[MAXN], dep[MAXN];

/* 读入一条边 (父 u, 子 v)：父一定先出现过，所以深度能直接算 */
par[v] = u;
dep[v] = dep[u] + 1;

/* 求 LCA —— 这六年间两道路径题的核心，就这三行 */
int a = u, b = v;
while (dep[a] > dep[b]) a = par[a];      /* 深的先上溯到同层 */
while (dep[b] > dep[a]) b = par[b];
while (a != b) { a = par[a]; b = par[b]; }   /* 同步上溯，相遇处 a == LCA */

/* 层次差：在最开始算 */
/* d = |dep[u] - dep[v]|; */
```

**应用场景**

- **什么时候该想到它**：题干出现「两点之间的路径 / 距离 / 隔着几代 / 最近的共同祖先 / 家谱 / 两人是什么关系」——这些全部只要求**从结点往上走**，不要求往下找孩子。
- **这六年用在哪**：**2017-三**（找家谱成员：问两人关系 + 层次差）、**2019-二**（送客户：要打印起点到目标之间**每段经过的结点**）。
- **为什么可以连树都不建**：只往上走的话，`par[]` + `dep[]` 两个数组就是全部所需，孩子数组（C-3）在这里纯属多余——这就是 2017-三 比 2018-二 简单一半的原因。
- **前提是 `dep[]` 必须是对的**，而填深度的时机取决于是谁保证行序：**2017-三** 题面保证父先出现，可以边读边算；**2019-二** 只保证"至多一个父节点"，行序不定，**必须先把整棵树建完、再从根 BFS 一遍**。
- **要"路径"而不只是"LCA"**：上行段（`u` 的父一路到 LCA）+ 下行段（`v` 上溯到 LCA，用栈倒序打印）。⚠️ **起点本身就是 LCA 时没有上行段**，不加 `if (u != a)` 守卫会一路往回打。层次差就是上溯之前算的 `dep[a]` 与 `dep[b]` 之差。
- **代价**：每次查询 O(路径长)。数据量大的比赛题会换倍增，机试这六年用不着。

### C-5 编号 → 下标映射（编号无规律时的标准解法）

```c
static int all[MAXN], na = 0;    /* 所有出现过的原始编号 */
static int vid[MAXN];            /* 下标 → 原始编号（输出时还原用） */
static int cmp(const void *A, const void *B) { return *(const int *)A - *(const int *)B; }

/* 1) 读入时顺手收集编号（每个出现过的都塞进 all[]） */

/* 2) 排序 + 原地去重 */
qsort(all, na, sizeof all[0], cmp);
for (i = 1, k = 1; i < na; i++)
    if (all[i] != all[i - 1]) all[k++] = all[i];
na = k;
for (i = 0; i < na; i++) vid[i] = all[i];

/* 3) 二分查下标 */
int idx(int v) {
    int lo = 0, hi = na - 1, mid;
    while (lo <= hi) {
        mid = (lo + hi) / 2;
        if (all[mid] == v) return mid;
        if (all[mid] < v) lo = mid + 1; else hi = mid - 1;
    }
    return -1;
}

/* 4) 之后一律用下标运算；打印时用 vid[] 换回编号 */
```

⚠️ **最常见的低级错误**：最后打印忘了 `vid[]`，输出一堆内部下标。
⚠️ **替代方案**：如果编号恰好是"行号 / 出现次序"，直接拿它当行下标 + 线性扫（**2021-二** 就是这种）。别为了省事假设"编号从 100 连续"——**2019-二** 就栽在这个假设上。

**应用场景**

- **什么时候该想到它**：结点 / 端点的**编号是任意整数**（100、707、100000 都可能），题面**没有**给出编号范围的保证，而你要拿编号当数组下标用。
- **这六年用在哪**：**2018-二**、**2019-二**（两题都要建树，且都只给了"编号与编号的关系"，没给编号范围）。
- **动手前先做一个判断**：**看题面有没有把编号空间封死**。有些版本会写「叶子编号 < 100、分叉编号 ≥ 100 且 < 300」——那样就可以直接用编号当下标，`all[]/qsort/去重/idx/vid` 整块省掉（本文 2019-二 就并列了这一版：`2019_2_deliver_byid.c`，比通用版少 40 多行）。**没有这句保证，就必须离散化。**
- **别踩的坑**：① **绝不要假设"编号从 100 连续"或"最大值不大"**——2019-二 最早就是这么写的，遇到六位数编号直接 ASan 报 `global-buffer-overflow`；② 最后打印忘了 `vid[]`，输出一堆内部下标；③ 它要求**先读完全部输入**才知道编号全集，所以必须暂存原始输入、走两遍（想省掉这一遍只有 C++ 的 `map` 这条路——**见下方「C++ 对照」**，注意 `operator[]` 会静默插入新键）。

**C++ 对照：用 `map` 免掉"必须先读完输入"这一遍**

> 本章以 C89 为准，这一段是**对照 / 选学**：考场科目若写明 C 语言、或不确定能不能用 STL，要练的仍是上面那版。它值得看的原因是——它让你看清"编号映射"到底在解决什么问题，平时也能当对拍工具。

```cpp
#include <map>
using namespace std;

static map<int, int> idm;        /* 编号 → 下标：键是原始编号，值是稠密下标 */
static int vid[MAXN], nid = 0;   /* 下标 → 编号（打印还原用）；nid 自己数 */

int idx(int v) {
    map<int, int>::iterator it = idm.find(v);
    if (it != idm.end()) return it->second;      /* ① 见过：直接返回旧下标 */
    int ni = nid++;                              /* ② 没见过：现场分配一个 */
    idm[v] = ni;
    vid[ni] = v;                                 /*    记下反向映射 */
    kid[ni][0] = kid[ni][1] = kid[ni][2] = -1;   /*    顺手把这个新结点刷空 */
    par[ni] = -1;
    return ni;
}

/* 主干：可以边读边建，不再需要暂存原始输入的 fid[] / ch[][] */
for (i = 0; i < n; i++) {
    scanf("%d %d %d %d", &f, &c0, &c1, &c2);     /* 先读到临时变量 */
    u = idx(f);                                  /* 下一行再翻译，别写成 &kid[f][0] */
    if (i == 0) root = u;
    kid[u][0] = (c0 < 0) ? -1 : idx(c0);         /* ⚠️ -1 不进 map */
    kid[u][1] = (c1 < 0) ? -1 : idx(c1);
    kid[u][2] = (c2 < 0) ? -1 : idx(c2);
    for (k = 0; k < 3; k++)
        if (kid[u][k] >= 0) par[kid[u][k]] = u;  /* 同一趟把父指针也建了 */
}
```

**它省了什么、没省什么**

| | 数组版（上面那版） | `map` 版 |
|---|---|---|
| 编号 → 下标 | `all[]` + `qsort` + 原地去重 + 二分 + `vid[]`（≈20 行） | 一个 `idx()`（9 行） |
| 能否边读边建 | **不能**：编号全集未知就定不了下标，必须先把原始输入暂存下来 | **能**，一趟读完就建完 |
| 额外数组 | `all[]`、`vid[]`、暂存用的 `fid[]` / `ch[][]` | 只剩 `vid[]` |
| 对编号值域的要求 | 只要"值域可压缩"（不同编号个数可控） | **无要求**，`int` 装得下就行 |
| 单次查找 | 二分 O(log n) | 红黑树 O(log n)，常数更大 |
| `kid[]` / `par[]` / `dep[]` 这套"树的形状" | 要 | **照样全要** |
| 打印时还原编号 | `vid[x]` | **照样要** `vid[x]`（映射是单向的） |

**还有两件 `map` 帮不了的**：① **深度仍要建完树之后单独 BFS 算**（输入行序不保证父在子之前，这条约束跟容器无关）；② 求路径仍要 `par[] + dep[]` 走 LCA——**指针版不会比数组下标版省半行**。

**三个坑**

1. 🔴 **别用 `if (idm[v] == 0)` 判"没出现过"。** `map::operator[]` 遇到不存在的键会**静默插入**一个值初始化为 0 的项，于是"编号映射到下标 0"的那个结点会被反复当成新编号——写成 `if (idm[v] == 0) idm[v] = nid++;` 就是这个错。实测 `idx(707)` 第一次给 `0`、**第二次给 `1`**：同一棵树被拆成两截，下标 0 还白漏了。判"在不在"只能用 `find()` 或 `count()`。
2. **`-1` 不要喂进 `idx()`。** 空孩子在外面判掉（`c < 0 ? -1 : idx(c)`），否则 map 里会凭空多出一个"编号 -1"的假结点，白占一个下标。
3. **`nid` 自己数，别写 `idm.size()`。** 它是 `size_t`，混进 `int` 比较会招 signed/unsigned 警告；语义上也不该拿容器大小当业务计数。

**想更快就换 `unordered_map`**：`#include <unordered_map>` + `unordered_map<int,int> idm;`，平均 O(1)。本题不需要"按编号有序遍历"，`map` 唯一的优势（有序）根本没兑现。

**行序无关这点它天生具备**：`idx()` 是"缺则新建"，所以某个分叉先作为别人的孩子出现、之后才有自己那一行，也不会崩（这是 2019-二 必须的性质；2018-二 题面另有保证，用哪版都行）。

### C-6 静态数组当队列 / 栈（不写 STL）

```c
/* 队列（BFS） */
static int q[MAXN];
int head = 0, tail = 0;
q[tail++] = root;                       /* 入队 */
while (head < tail) {
    int u = q[head++];                  /* 出队 */
    /* … q[tail++] = v; */
}

/* 栈（手工——比递归稳，不怕深链爆栈） */
static int st[MAXN];
int sp = 0;
st[sp++] = x;                           /* 压栈 */
while (sp > 0) { y = st[--sp]; }        /* 弹栈 */
```

⚠️ 写在**函数体里**的 `static` 数组只分配一次、跨调用保留上次内容 —— 每次用前自己 `sp = 0`（`2019_2_deliver.c` 的 `walk()` 就靠这个）。
⚠️ BFS 若数据可能异常（输入成环、重复边），加一张 `inq[]` 标记防重复入队（`gate.c` 加了）。

**应用场景**

- **什么时候该想到它**：只要需要「先进先出」或「后进先出」，而 STL 又不许用——几乎每道树 / 图题都会碰到。
- **这六年用在哪**：**队列**——2021-二（层次遍历）、2019-二（从根 BFS 算深度）、`gate.c`（层次遍历，另加 `inq[]` 防环）；**栈**——2019-二（下行段先收集再倒序打印）。
- **为什么值得单拎出来**：递归是"隐式栈"，深度上万就爆；把递归改成循环 + 手工栈（或 BFS）是**唯一**能让规模上去的办法。**2019-二** 的 `walk()` 就是靠手工栈同时实现了"倒序打印下行段"。
- **别踩的坑**：① 写在函数体里的 `static` 数组**只分配一次、跨调用保留上次内容**，每次用前自己 `sp = 0`（或 `head = tail = 0`）；② BFS 遇到"输入可能成环 / 有重复边"时加一张 `inq[]` 标记，否则会无限入队；③ 队列数组要按结点数开够，别跟别的用途共用一份。

### C-7 结构体 + qsort 比较器（单键 / 多键 / "稳定"）

```c
typedef struct { int v, t; } P;          /* v = 值，t = 输入次序 */
static P a[MAXN];

static int cmp(const void *A, const void *B) {
    const P *x = (const P *)A, *y = (const P *)B;
    if (x->v != y->v) return x->v < y->v ? -1 : 1;   /* 第一键：升序 */
    return x->t - y->t;                              /* 第二键：升序 → 等价“稳定排序” */
}
qsort(a, n, sizeof a[0], cmp);

/* 排“字符串的数组”时：元素是 char[L]，传进来正好是 const char * */
static int cmps(const void *A, const void *B) { return strcmp((const char *)A, (const char *)B); }
```

⚠️ **想要"稳定"就得自己带次序字段**：`qsort` 不稳定，`(值, 输入次序)` 双键是最省事的稳定化。
⚠️ 返回值别只写 `x->v - y->v`：整数溢出会翻符号。养成写"小于返回负、大于返回正"的三元习惯。
⚠️ 比较器必须是 `const void *` 签名，**参数里的星号一个都不能少**。

**应用场景**

- **什么时候该想到它**：要排序的对象**不止一个字段**（线段有两个端点、词语是字符串、中位数要带着"原始位置"），或者题目要求"值相同的按输入先后排"（也就是稳定排序）。
- **这六年用在哪**：**2017-一**（`(值, 输入次序)` 双键，输出中位数的**位置**）、**2018-一**（线段按起点排序，为 DP 铺出拓扑序）、**2015-三**（字符串数组按字典序 `strcmp`）。
- **怎么判断要不要带输入次序**：只要输出里出现"第几个 / 位置 / 原下标"，就得把输入次序当字段存进去一起排——`qsort` 本身不稳定，靠这个字段才能复现"值相同时按原顺序"。
- **别踩的坑**：① 比较器只写 `x->v - y->v` 有整数溢出翻符号的风险，养成"小于返回负、大于返回正"的三态写法；② 比较器签名必须是 `const void *`，**参数里的星号一个都不能少**；③ 排字符串数组时元素是 `char[L]`，传进来的正好是 `const char *`，直接 `strcmp` 即可，别再取地址。

### C-8 打表（素数筛 / 预处理）

```c
#define MAXV 100005
static char comp[MAXV];                  /* 标记数组用 char，省内存 */
static int  pr[10000], np = 0;

comp[1] = 1;                             /* 手动挡掉 1 */
for (i = 2; i < MAXV; i++)               /* 埃氏筛，O(N log log N) */
    if (!comp[i]) {
        pr[np++] = i;                    /* 顺手按序收表 */
        for (j = 2 * i; j < MAXV; j += i) comp[j] = 1;
    }
```

要点：**上界开到题目上界 + 5**；内层写 `j < MAXV`，写成 `<=` 就越界。要"第 k 个素数"就直接查 `pr[k-1]`。

**应用场景**

- **什么时候该想到它**：题目里出现「素数 / 质数 / 约数 / 1..N 中满足某性质的数」，而且要**反复查询**同一批数（不是只问一次）。
- **这六年用在哪**：**2019-一**（相邻素数组成的等差数列：先打表拿到"第 i 个素数"，再线性扫三个相邻项）。
- **为什么打表而不是每次判素数**：扫描过程会反复问"下一个素数是谁"，逐个判断会把线性扫退化成 O(范围 × √n)；一次筛到上界，之后全是数组访问。
- **别踩的坑**：① 上界开到题目上界 + 5（内层写 `j < MAXV`，写成 `<=` 就越界）；② `comp[1] = 1` 要手动挡掉 1；③ 标记数组用 `char` 省内存；④ 素数表的容量按上界内素数个数估，宁可开大。

### C-9 记忆化 DP（数组就是记忆表）

```c
static int f[MAXN];                      /* f[i] 本身就是记忆表，不需要额外结构 */

for (i = n - 1; i >= 0; i--) {           /* 倒序填，保证后继已经算好 */
    best = 0;
    for (j = i + 1; j < n; j++)
        if (能接上(i, j) && f[j] > best) best = f[j];
    f[i] = best + 1;
}
```

要点：**先给状态找"拓扑序"**（本题按起点横坐标 `qsort` 后，后继必然排在后面），再决定正序还是倒序填。能写成循环就别写递归——不用防爆栈、也不用担心重复计算。树形 DP 同理（在后序位置累加孩子）。

**应用场景**

- **什么时候该想到它**：题干出现「最长 / 最多 / 最少 / 能否接下去 / 有几种方案」，且状态之间的依赖是**单向**的（能用"谁接在谁后面"描述，天然无环）。
- **这六年用在哪**：**2018-一**（首尾相接的最长线段链：`f[i]` = 以第 i 条线段开头最远能接多长，倒序填表）。
- **正确的使用顺序**：先找**拓扑序**（这题是"按起点横坐标排序后，后继必然排在后面"），再决定正序还是倒序填。做不到这一点就只能退回递归 + 记忆化，容易写错。
- **为什么数组就够**：`f[i]` 本身就同时回答了"算过没有"和"结果是多少"，不需要额外的访问标记；`static` 的零初始化也不会被误用（每一步读到的 `f[j]` 都已显式赋过值）。
- **方向怎么定**：`f[i]` 定义成"从 i 出发"（倒序填）时**起点是白拿的**；定义成"到 i 结束"（正序填）就必须额外带 `px/py` 或 `prev[]` 才能回答"链的起点是谁"。**照题目问哪个端点来选方向。**

### C-10 字符串扫描（整行 / 字符流 / 数字串↔整数）

```c
/* 整行读：行长可能到 10^5~10^6，缓冲必须 static */
static char line[1000005];
while (fgets(line, sizeof line, stdin) != NULL) { ... }   /* NULL == EOF（终端 Ctrl+D） */
/* ⚠️ fgets 会把 '\n' 一起读进来（行尾换行符会保留）；扫到行尾用 strlen 或判 '\0' */

/* 字符流：一次读完整个输入（含换行） */
static char s[1000005];
int c, len = 0;
while ((c = getchar()) != EOF && len < 1000000) s[len++] = (char)c;
s[len] = '\0';

/* 判定函数 + “合法取反”：只认合法字符，其余一律当分隔符 */
static int isId(int c)  { return (c>='a'&&c<='z') || (c>='A'&&c<='Z') || c=='_'; }
static int isIdc(int c) { return isId(c) || (c>='0'&&c<='9'); }

/* 取一个 token（标识符） */
k = 0;
while (i < len && isIdc((unsigned char)s[i]) && k < L - 1) tok[k++] = s[i++];
tok[k] = '\0';

/* 数字串 ↔ 整数：前导 0 想丢就转整数，想留就按串打 */
for (i = 0; i < len; i++) n = n * 10 + (s[i] - '0');   /* "00232" → 232 */
printf("%s", r);                                        /* 想保住前导 0 就打印字符串 */
```

要点：
- `(unsigned char)` 强转是习惯（防高位字符变负）。
- 判"**以数字开头就是常数**"时把数字和 `.` **整块吃掉** → `a[30]`、`456.78`、`y=1` 里的 `1` 全部自动免疫。
- 字符串表用 `static char tab[MAXT][MAXL];`，不用 `malloc`；尾随空格写进格式串。

**应用场景**

- **什么时候该想到它**：输入是"整行文本"而不是整齐的数字列——要统计单词、找变量名、按字符处理、按行读到 EOF；或者输入里带空格、带标点、长度不定。
- **这六年用在哪**：**2016-一**（逆序数：数字串 ↔ 整数，前导 0 要靠字符串保住）、**2016-二**（enum 解析：按 `,` 切、遇 `=` 赋值）、**2017-二**（未定义变量：只认合法字符，数字开头整块当常数跳过）、**2015-三**（统计词语：`fgets` 到 EOF + 词表 + 排序）。
- **三种读法怎么选**：`scanf("%s")` —— 单个不含空格的 token（2016-二）；`fgets(line, …)` —— **整行**，可以含空格（2015-三、2017-二）；`getchar()` 读到 `EOF` —— 一次拿全部字符含换行，适合整块扫描（2016-二）。
- **别踩的坑**：① `fgets` **会把行尾换行符也读进来**，扫到行尾要用 `strlen` 或判 `'\0'`；② 行长可能到 10⁵~10⁶，缓冲**必须 `static`**，否则爆栈；③ 字符判定统一 `(unsigned char)` 强转，防止高位字符变负数；④ "以数字开头就跳过"时要把数字和 `.` **整块吃掉**，这样 `a[30]`、`456.78`、`y=1` 里的数字自动免疫；⑤ 多组 / 多点输入要判到 EOF 为止，别只读一组。

### C-11 真要用 `struct` + 指针链表的样子（知道即可）

```c
struct node {
    int data;
    struct node *nxt, *prv;      /* ⚠️ 星号必须写在每个名字前面 */
};
static struct node pool[MAXN];   /* 静态结点池：零初始化、不用 free */
static int pcnt = 0;

struct node *newnode(int v) {
    struct node *p = &pool[pcnt++];
    p->data = v;
    p->nxt = p->prv = NULL;      /* ⚠️ 显式置空，别省 */
    return p;
}
```

⚠️ **语法坑**：`struct node *fa, son[3];` 里的 `*` 只修饰 `fa`，`son` 会变成**结构体数组**，编译直接报 `array has incomplete element type`。必须写 `*fa, *son[3]`。
⚠️ **不初始化就是垃圾值**：局部指针没置 `NULL` 时 `p->nxt != NULL` 判空失效 → 段错误；下标数组版（`-1` 为空）天然没这个问题。
👉 所以这六年所有题都用**下标数组**；`struct` + 指针只在"结点数不定且很大、还要频繁在中间插删"时才值得上。

**应用场景**

- **这六年用在哪**：**没有一道题必须用它**。2018 年起虽然允许 C++ 容器，但用数组 + 下标做题只会更短、更稳。
- **什么情况下它才真划算**：结点数不定且很大、要频繁在中间插删、还要按"值"直接找到某个结点（这时配合 `map<int, node*>`）。反过来，只要结点总数能估出来（大致 4n 量级），数组就是更优解。
- **真要写时的坑**：① `struct node *fa, son[3];` 里的 `*` 只修饰 `fa`，`son` 会变成结构体数组 → 编译报 `array has incomplete element type`（必须写 `*fa, *son[3]`）；② 局部指针不初始化就是垃圾值，`p->nxt != NULL` 的判空会失效 → 段错误；③ 即使用指针也建议配"静态结点池"（`static struct node pool[MAXN]`）而不是每个都 `malloc`，免得泄漏和碎片。
- **顺带一句**：C++ 的 `map<int, node*>` 建树在"编号无规律"时确实方便（省掉离散化），但 `m[x]` 会**静默插入**空指针——必须用 `find` / `count` 判存在，否则遇到行序不定的输入会直接段错误。

### C-12 枚举 / 数论小套路

```c
/* 因子枚举（含 1、不含自身）：扫到 n/2 足够 */
for (i = 2; i <= n / 2; i++) if (n % i == 0) { sum += i; printf("+%d", i); }
/* 1 一定是因子，先手工铺路：printf("%d, 1", n); sum = 1;  循环从 2 开始 */

/* 相邻三项等差判定（比两边相减更短，也不会写出除零） */
if (pr[i] + pr[i + 2] == 2 * pr[i + 1]) { ... }
```

补充：`n` 上限到 10⁶ 时扫 `n/2` 秒过；上限到 10⁹ 就要改成**试除到 `√n` 再配对累加**（`i` 与 `n/i` 成对）。

**应用场景**

- **什么时候该想到它**：题目在问"约数 / 因子 / 整除 / 等差 / 质因数"这类**数论小性质**，而规模又不足以让你上高级算法。
- **这六年用在哪**：**2015-一**（相亲数：枚举因子求和）、**2019-一**（相邻三项等差判定 `pr[i] + pr[i + 2] == 2 * pr[i + 1]`）。
- **写法按 n 的上界选**：`n` 到 10⁶ → 直接扫到 `n/2`（实测秒过）；`n` 到 10⁹ → 改成试除到 `√n`，把 `i` 与 `n/i` **成对累加**，否则必超时。
- **等差判定为什么用这个式子**：比"两边相减再比"短，而且**不会写出除以 2 的表达式**，省掉一个取整 / 除零的坑。

## 2021 年

### 题目一 · 空闲块链表的 Best Fit

**考查**：双向循环链表模拟（用数组 + `next`/`prev` 下标最省事） ｜ **代码**：`2021_1_freeblock.c`

**手搓要点（C89）**

- **结构**：不写 `struct`，用四张平行数组当结点池 —— `static int st[MAXN], ln[MAXN], nxt[MAXN], prv[MAXN];`，`nxt/prv` 存**下标**当指针（模板 C-1）。
- **建成环**：`nxt[i] = (i+1) % n; prv[i] = (i-1+n) % n;` —— 取模天然成环，不用头结点、不用哨兵。
- **走一圈**：`do { … x = nxt[x]; } while (x != cur);` —— 必须是 `do/while`，用 `while` 会漏掉对起点自己的判断。
- **摘结点**：`nxt[prv[b]] = nxt[b]; prv[nxt[b]] = prv[b];` ⚠️ 右边的 `nxt[b]/prv[b]` 要在被改写前用完，顺序反了就把结点指成自己。

**题目**

空闲块按地址升序组成**循环链表**，每块记「起始位置、长度」。对每个申请量 `q`：

1. 从**当前位置**开始沿链表遍历**一圈**，找**长度 ≥ q 的最小块**（并列时取**先遇到**的那个，即 Best Fit）；
2. 恰好相等 → 把该块**从链表中摘掉**，当前位置变为**被摘块的下一块**；
3. 大于 → 该块长度减 `q`，**起始位置不变**，当前位置仍为该块；
4. 找不到 → 忽略本次申请，**当前位置不变**。

输入：先一个整数 `n`（空闲块个数），再 `n` 行「起始位置 长度」（地址升序），最后一行若干个申请量、以 `-1` 结束。
输出：从当前位置开始沿链表输出每个剩余空闲块的「起始位置 长度」。

**样例**（12 个空闲块，申请序列 `1024 2560 10240 512 1024 6400 512`）

```
输入：
12
1024 2048
8192 512
16384 1024
32768 8192
65536 8192
77824 1024
80896 3072
86016 1024
91136 5120
99328 512
104448 1024
112640 3072
1024 2560 10240 512 1024 6400 512 -1

输出（当前位置已走到 104448，共剩 8 块）：
104448 1024
112640 3072
1024 2048
8192 512
32768 1792
65536 8192
77824 1024
91136 5120
```

**思路**

- 用数组存块，`nxt[]`/`prv[]` 做双向循环链表，`cur` 记当前位置，初始为第 0 块。
- **找块**：从 `cur` 出发 `do { … } while (x != cur);` 恰好走一圈；更新条件写 **严格小于**（`len[x] < len[best]`），并列就自动保留先遇到的。
- **摘块**：`nxt[prv[b]] = nxt[b]; prv[nxt[b]] = prv[b]; cur = nxt[b];`。⚠️ 先把 `nxt[b]` 用掉再改指针，顺序不能反。
- ⚠️ **最大的坑：剩余块的起始位置不变**。题面说「大小合适的空闲块返回给用户，剩下的部分留在链表中」，直觉上应把剩余块起点后移 `q`（`start += q`）；但样例明确是 **`32768 1792`**（原 `32768 8192` 减 6400）——起点没动，**只有长度变小**。按直觉写样例就对不上。
- 请求值一次读一个、读到 `-1` 为止即可（样例是把 7 个请求写在同一行，`scanf` 天然跨行跨空格，不用按行解析）。

**伪代码**

```
cur = 0；建双向循环链表
while 读到请求 q 且 q != -1:
    best = 空；x = cur
    do:
        if len[x] >= q 且 (best 空 或 len[x] < len[best]): best = x
        x = nxt[x]
    while x != cur
    if best 存在:
        len[best] -= q
        if len[best] == 0:
            nxt[prv[best]] = nxt[best]
            prv[nxt[best]] = prv[best]
            cur = nxt[best]；n--
        else:
            cur = best
从 cur 出发沿 nxt 打印 n 个块
```

**代码**

```c
/* 2021 年北航复试上机 题目一：空闲块链表的 Best Fit 分配
 * 考点：双向循环链表模拟（用数组 + next/prev 下标即可）
 * 规则：从当前位置开始沿循环链表走一圈，找「长度 >= 请求」的最小块（并列取先遇到的）；
 *       恰好相等 → 删除该块，当前位置 = 被删块的下一块；
 *       大于 → 长度减去请求值，起点不变，当前位置 = 该块；
 *       找不到 → 忽略本次请求，当前位置不变。
 * 输出：从当前位置开始沿链表打印每个空闲块的「起始位置 长度」
 */
#include <stdio.h>

#define MAXN 1005

static int st[MAXN], ln[MAXN], nxt[MAXN], prv[MAXN];

int main(void) {
    int n, i, q, best, x, cur;

    if (scanf("%d", &n) != 1) return 0;
    for (i = 0; i < n; i++) scanf("%d %d", &st[i], &ln[i]);
    for (i = 0; i < n; i++) {                      /* 建成循环双向链表 */
        nxt[i] = (i + 1) % n;
        prv[i] = (i - 1 + n) % n;
    }
    cur = 0;                                       /* 初始位置：地址最小的第一块 */

    while (scanf("%d", &q) == 1 && q != -1) {
        best = -1;
        x = cur;                                   /* 从当前位置开始，恰好走一圈 */
        do {
            if (ln[x] >= q && (best < 0 || ln[x] < ln[best])) best = x;
            x = nxt[x];
        } while (x != cur);

        if (best >= 0) {
            ln[best] -= q;                         /* 剩余部分留在原位置（起点不变） */
            if (ln[best] == 0) {                   /* 恰好用完 → 从链表中摘掉 */
                nxt[prv[best]] = nxt[best];
                prv[nxt[best]] = prv[best];
                cur = nxt[best];
                n--;
            } else {
                cur = best;
            }
        }
    }

    x = cur;
    for (i = 0; i < n; i++) {                      /* 从当前位置开始打印 */
        printf("%d %d\n", st[x], ln[x]);
        x = nxt[x];
    }
    return 0;
}
```

### 题目二 · 登机口调整

**考查**：三叉树建树 + 层次遍历 + 排序贪心 ｜ **代码**：`gate.c`（长注释版）

**手搓要点（C89）**

- **树的结构**：度是 3 就用二维数组 `static int son[MAXL][3];`，`-1` 表示空位（模板 C-3）。真写 `struct node { int id; struct node *son[3]; }` 反而要额外操心"局部指针是垃圾值"（`son[i] != NULL` 判空失效），不划算。
- **编号不能当下标**：分叉编号（100、101、103…）不连续，开 `kid[编号]` 会浪费巨大空间。这题的取巧点是**用「行」当结点**：`fid[]` 记"第 i 行描述的是哪个分叉"，要按编号找行就线性扫 `T` 行（`T ≤ 100`），完全不依赖编号范围。
- **BFS 队列**：`static int q[MAXL]; int head = 0, tail = 0;`，`q[tail++] = x` 入队、`q[head++]` 出队（模板 C-6）；`inq[]` 是防异常数据成环的保险。
- **层次遍历的顺序天然等于题面要求**：孩子按 S1→S2→S3 入队，出队顺序就是「从上到下、同层从左到右」，不用自己算坐标。

**题目**

登机口呈**度为 3 的树**：根是安检处（编号固定 **100**），分叉结点编号 ≥ 100，登机口编号 1~99 且**一定是叶结点**。已知每个登机口的日均流量。要求在**不改变树形**（航班相对关系不变）的前提下重新分配登机口，使所有旅客从安检口到登机口经过的分叉路口总数最少。

调整规则：① 登机口按**流量由大到小、流量相同按编号由小到大**排序；② 从根开始按**从上到下、同层从左到右**的顺序依次摆放。
输出：按排序后的顺序分行输出「调整前登机口编号 调整后所在位置的登机口编号」。

输入：先树结点关系条目数 `T`，接 `T` 行「`R S1 S2 S3`」（空位写 `-1`，**每行固定 3 列**；分叉结点输入顺序不确定，但**父结点信息一定先输入**）；再输入各登机口流量（行数 = 登机口个数，题面**没给**这个数）。

**样例**

```
输入：
12
100 101 102 103
103 14 108 13
101 5 104 6
104 7 8 -1
102 105 106 107
106 1 110 2
108 16 15 -1
107 18 111 17
110 3 4 -1
105 9 109 10
111 20 19 -1
109 11 12 -1
17 865
5 668
（…… 共 20 个登机口的流量 ……）
4 576

输出（前 6 行）：
12 5
20 6
8 14
19 13
7 7
15 8
```

**思路**

- **树形不变 ⇒ 位置固定**：每个登机口位就是一个固定的「位置」，同一层的位置到根的分叉数相同，越靠上的层越近。
- 于是「总代价最小」= **把流量大的放到靠上的位置**——贪心，本质是排序不等式（两个序列同序配对代价最小）。
- **位置序列** = 把树中所有登机口按**层次遍历**列出来（孩子按 S1→S2→S3 入队，天然满足「从上到下、同层左到右」）；**登机口序列** = 按流量排序。两者一一对应：第 `i` 名放进第 `i` 个位置，输出 `A[i] B[i]`。
- **没给登机口个数**：建树时顺手数叶结点（编号 1~99），这个数正好等于后面要读的流量行数。
- **分叉编号没有规律**：别拿编号当数组下标；用「行」存关系（每行 = 某分叉的 3 个孩子），要按编号找行就在 `T` 行里线性扫（`T ≤ 100`），完全不用假设编号范围。

**伪代码**

```
读 T 行「R S1 S2 S3」→ son[行][0..2]
root = 编号 100 所在的行
BFS(root)：孩子按 S1→S2→S3
    if 孩子是登机口(1..99)：按遇到顺序追加到 slot[]（位置序列）
    else：找到它的行，入队
读入 (登机口, 流量)，行数 = slot 的长度
按 (流量降序, 编号升序) 排序
for i = 0..G-1: 输出 第 i 名登机口编号, slot[i]
```

**代码**（与 `gate.c` 同一份代码，此处略去文件头的长注释，完整版见 `gate.c`）

```c
#include <stdio.h>

#define MAXL 256   /* 树结点关系条目（分叉结点）≤ 100，留余量 */
#define MAXG 105   /* 登机口 ≤ 99 */

static int fid[MAXL];      /* fid[i]：第 i 行描述的分叉结点编号 */
static int son[MAXL][3];   /* son[i][j]：该分叉结点的第 j 个子结点，-1 表示该位置为空 */

static int slot[MAXG];     /* 层次遍历遇到的登机口序列，即「位置序列」 */
static int ngate;          /* 位置个数（= 树中登机口的个数） */

static int gid[MAXG];      /* 读入的登机口编号 */
static int gflw[MAXG];     /* 对应的日均流量 */

/* 登机口：编号 1~99（分叉结点编号 ≥ 100；-1 表示空位置） */
static int is_gate(int x) { return (x > 0 && x < 100); }

/* 在前 t 行里找「分叉结点编号 == id」的行号，找不到返回 -1 */
static int line_of(int t, int id) {
    int i;
    for (i = 0; i < t; i++)
        if (fid[i] == id) return i;
    return -1;
}

int main(void) {
    int T, i, j, root, head, tail, q[MAXL], inq[MAXL], cur, c, idx, tmp;

    /* 逐组处理：单点测试只跑一组；若文件里有多组也能连续吃下来 */
    while (scanf("%d", &T) == 1) {
        /* ---- 1. 读入树：T 行「R S1 S2 S3」 ---- */
        for (i = 0; i < T; i++)
            scanf("%d %d %d %d", &fid[i], &son[i][0], &son[i][1], &son[i][2]);

        /* ---- 2. 层次遍历：从根（编号 100 所在的那一行）出发 ---- */
        ngate = 0;
        head = tail = 0;
        for (i = 0; i < T; i++) inq[i] = 0;        /* 防重复入队（正常一棵树不会重） */
        root = line_of(T, 100);
        if (root >= 0) { inq[root] = 1; q[tail++] = root; }
        while (head < tail) {
            cur = q[head++];
            for (j = 0; j < 3; j++) {              /* 从左到右：S1、S2、S3 */
                c = son[cur][j];
                if (c < 0) continue;               /* 空位置，跳过 */
                if (is_gate(c)) {
                    slot[ngate++] = c;             /* 登机口：按遇到顺序记下位置 */
                } else {
                    idx = line_of(T, c);           /* 分叉结点：找到它的行，入队继续往下 */
                    if (idx >= 0 && !inq[idx]) { inq[idx] = 1; q[tail++] = idx; }
                }
            }
        }

        /* ---- 3. 读入各登机口的流量（行数 = 树中登机口个数） ---- */
        for (i = 0; i < ngate; i++) scanf("%d %d", &gid[i], &gflw[i]);

        /* ---- 4. 排序：流量由大到小；流量相同按登机口编号由小到大 ---- */
        for (i = 0; i < ngate; i++)
            for (j = i + 1; j < ngate; j++)
                if (gflw[j] > gflw[i] || (gflw[j] == gflw[i] && gid[j] < gid[i])) {
                    tmp = gid[i];  gid[i] = gid[j];  gid[j] = tmp;
                    tmp = gflw[i]; gflw[i] = gflw[j]; gflw[j] = tmp;
                }

        /* ---- 5. 一一对应：第 i 名（流量第 i 大）放进第 i 个位置 ---- */
        for (i = 0; i < ngate; i++)
            printf("%d %d\n", gid[i], slot[i]);
    }
    return 0;
}
```

### 题目一 · 相邻素数组成的等差数列

**考查**：埃氏筛打表 + 线性扫描 ｜ **代码**：`2019_1_primeap.c`

**手搓要点（C89）**

- **结构**：一张标记数组 `static char comp[MAXV];`（`comp[i] = 1` 表示 i 不是素数）+ 一张素数表 `static int pr[10000];` —— 这就是"打表"最朴素的样子（模板 C-8）。
- **筛法骨架**：`for (i=2;i<MAXV;i++) if (!comp[i]) { pr[np++] = i; for (j=2*i;j<MAXV;j+=i) comp[j] = 1; }` —— 顺手把素数**按序收进表**，后面直接按下标取三项。
- **上界**：数组开 `100005`（题面上界 10⁵ + 余量）；内层筛选写 `j < MAXV`，写成 `<=` 就越界。
- `comp[1] = 1;` 手动挡掉 1，比在循环逻辑里特判省事（也顺带免疫 `1 3 5 7` 这种错误序列）。

**题目**

输入 `a b`（`1 ≤ a, b < 100000`），输出闭区间 `[a, b]` 内**由相邻素数组成**的等差数列；**三个以上才算序列**，且对多于三个的序列**不必再输出其子序列**（即只输出最长的那一段）。每行一个序列，**每个数之间有空格、一行最后一个数后也有空格**。

**样例**

```
输入：100 200
输出：151 157 163
      167 173 179

输入：200 500
输出：251 257 263 269
      367 373 379

输入：1 100
输出：3 5 7
      47 53 59
```

> 「相邻素数」= 素数表里**挨着的**三个素数（比如 5、11、17 虽是等差但中间夹着 7、13，不算）。
> 上面输出每行的**末尾还有一个空格**（题面明确要求，md 里保留不了行尾空格）。

**思路**

- **筛法打表**：`1` 标记为非素数（`comp[1] = 1`，这样 `1 3 5 7` 这类错误输出天然不会出现），埃氏筛到 100000，把素数顺序存进 `pr[]`。
- 定位区间内第一个素数后，**只看相邻三项**：`pr[i] + pr[i+2] == 2 * pr[i+1]` 即成等差。
- 命中后**继续往后吃**：只要下一项还满足等差就 `i++` 并打印，一次输出最长的序列；循环结束时 `i` 停在最后一个已输出的位置上，外层 `i++` 自然跳过子序列。
- 边界：**尾巴必须卡 `b`**（`pr[i+2] <= b`、延长时也要判 `<= b`），否则会把区间外的素数打出来。

**伪代码**

```
筛出 2..100000 的素数表 pr[]
i = 第一个 >= a 的素数下标
while i+2 在表内 且 pr[i+2] <= b:
    if pr[i] + pr[i+2] == 2*pr[i+1]:
        输出 pr[i], pr[i+1], pr[i+2]
        while i+3 在表内 且 pr[i+3] <= b 且 pr[i+1]+pr[i+3] == 2*pr[i+2]:
            i++；输出 pr[i+2]        // 延长成更长的等差
        换行
    i++
```

**代码**

```c
/* 2019 年北航复试上机 题目一：相邻素数组成的等差数列
 * 考点：素数筛（埃氏筛打表）+ 线性扫描
 * 输入 a b（1 <= a,b < 100000）
 * 输出所有「由相邻素数组成、长度 >= 3」的等差数列，一行一个，
 *       每个数后跟一个空格；长度超过 3 的只输出最长的那一个（不输出其子序列）
 * 坑：1 不是素数（筛法里天然满足）；尾巴要卡住 b 这个上界
 */
#include <stdio.h>

#define MAXV 100005

static char comp[MAXV];        /* comp[i]=1 表示 i 不是素数 */
static int  pr[10000], np = 0; /* 素数表 */

int main(void) {
    int a, b, i, j;

    comp[1] = 1;                                  /* 特判 1 */
    for (i = 2; i < MAXV; i++)                    /* 埃氏筛 */
        if (!comp[i]) {
            pr[np++] = i;
            for (j = 2 * i; j < MAXV; j += i) comp[j] = 1;
        }

    if (scanf("%d %d", &a, &b) != 2) return 0;

    i = 0;
    while (i < np && pr[i] < a) i++;              /* 定位到区间内的第一个素数 */

    while (i + 2 < np && pr[i + 2] <= b) {
        if (pr[i] + pr[i + 2] == 2 * pr[i + 1]) { /* 相邻三个素数成等差 */
            printf("%d %d %d ", pr[i], pr[i + 1], pr[i + 2]);
            while (i + 3 < np && pr[i + 3] <= b && pr[i + 1] + pr[i + 3] == 2 * pr[i + 2]) {
                i++;                              /* 还能延长，就接着往后吃 */
                printf("%d ", pr[i + 2]);
            }
            printf("\n");                         /* i 停在最后一个已输出的素数上 */
        }
        i++;                                      /* 跳到下一个没输出过的素数 */
    }
    return 0;
}
```

### 题目二 · 按优先级送客户并输出每段路径

**考查**：树的唯一路径（LCA 上溯 + 下行）+ 编号映射 + 排序 ｜ **代码**：简化版 `2019_2_deliver_byid.c`（题面已声明编号范围）· 通用版 `2019_2_deliver.c`（题面未声明编号范围）

**手搓要点（C89）**

- **两张表分工**：`fid[]/ch[][3]` 存**原始输入行**，`kid[][3]/par[]/dep[]` 存**映射后的树**（模板 C-3 + C-4），中间靠编号映射连起来。
- **手搓 map**：收集所有出现过的编号 → `qsort` → 原地去重（`for (i=1,k=1;i<na;i++) if (all[i]!=all[i-1]) all[k++] = all[i];`）→ 二分 `idx(编号)`；`vid[]` 存「下标 → 原始编号」，**打印时必须靠它还原**（模板 C-5）。
- **父指针 LCA（这六年间最值钱的三行）**：`while (dep[a]>dep[b]) a=par[a]; while (dep[b]>dep[a]) b=par[b]; while (a!=b) { a=par[a]; b=par[b]; }` —— 结束后 `a` 就是 LCA，不用最短路、不用邻接表。
- **手工栈**：下行段用 `static int st[]; int sp = 0;` 收集再倒着打（模板 C-6）。⚠️ 写在函数里的 `static` 数组只分配一次、跨调用保留，每次用前自己 `sp = 0`。
- ⚠️ `scanf("%d %d %d %d", &f, &kid[f][0], &kid[f][1], &kid[f][2])` —— **同一个 `scanf` 里既读 `f` 又拿 `f` 当下标是未定义行为**（参数求值顺序不定），必须先读到临时变量再写入。
- **什么时候能省掉「编号映射」这一整块？** 判据是「**题面有没有把编号空间封死**」，不是「编号最大值有多小」。只有像 2021 年题目二那样明写两段互不重叠的区间（分叉 `100..300`、登机口 `< 100`）才成立；单说「分叉编号 ≤ 300」**不够**——**孩子里的叶结点编号不受这句约束，照样越界**。本题 PDF 原文没有这类句子，所以通用版才是标准答案（见下面两版对照）。

**题目**

输入 `n`（`n < 10000`）和 `n` 行「**分叉结点 孩子1 孩子2 孩子3**」（`-1` 表示无；**第一行第一个结点是根**；保证每个结点至多一个父结点）；再输入 `m`（`m < n`）和 `m` 行「**目标叶结点 优先级**」（数值越小越优先，不并列）。

从根出发，按优先级依次把客户送到目标叶结点，**每次从上一次的目标位置继续出发**，全部送完后**返回起点**，记录并输出**每段经过的路径**。

**样例**

```
输入：
6
100 101 102 103
101 1 104 2
102 3 105 4
103 5 6 -1
104 7 8 -1
105 9 10 -1
5
7 7
9 3
6 2
8 1
4 5

输出：
100 101 104 8
104 101 100 103 6
103 100 102 105 9
105 102 4
102 100 101 104 7
104 101 100
```

**思路**

- 这输出是**一条连续行车路线的展开**：**起点（100）单独打印**，之后**每段一行**，内容是「从上一个位置到目标」经过的结点序列——**不含起点、含目标**；最后一段是从最后一个目标**回到根**。
- 优先级排序后：`8(1) → 6(2) → 9(3) → 4(5) → 7(7)`，路线串起来正好是 `100 → 101 → 104 → 8 → 101 → 100 → 103 → 6 → …`。
- 树上的路径唯一，所以**不用最短路算法**：求两点 LCA，路径 = `u` 上溯到 LCA，再从 LCA 下行到 `v`。下行方向只需把 `v` 到 LCA 的链**收集到栈里再倒着打**。
- **编号无规律**（题面没限定范围）：先收集所有出现过的编号 → `qsort` 去重 → 二分查下标，之后一律用下标运算，最后打印时再 `vid[]` 换回编号。这样完全不依赖编号大小。
- **但本题存在一个分支**：如果题面**另外声明了编号范围**（如「叶结点编号 < 100、全树编号 < 300」），那么「收集 → 排序去重 → 二分 → `vid[]` 还原」这整块都可以删掉——编号本身就是合法下标，直接写 `kid[编号][k]`、`par[编号]`，打印时也直接打编号。**LCA 那三行一个字都不用改**，变的只是「数据怎么表示」。下面两版代码就是这两种情况。
- ⚠️ 两个易错点：① **起点本身就是 LCA 时没有上行段**，不加判断会导致往回一直打印；② 打印时**别忘了 `vid[]` 还原编号**（否则输出的是内部下标）——这条只对通用版成立，简化版编号即下标，反而不会有这个坑。

**伪代码**

```
【简化版 · 题面已声明编号范围（如叶 < 100、全树 < 300）】编号就是下标，边读边建：
    读入 n
    for 每行: 读 f, c0, c1, c2
        第一行: root = f
        kid[f][0..2] = c0, c1, c2        // -1 原样存着，遍历时用 >= 0 判
        非 -1 的孩子: par[c] = f          // 题面保证至多一个父，可直接赋值
    读入 m 和 m 组（目标叶, 优先级）       // 不需要暂存原始输入
    BFS(root) 求 dep[]                    // 不需要 all[]/qsort/去重/idx/vid

【通用版 · 题面未声明编号范围】多一层「编号 → 下标」的翻译：
    读入 n 行，同时把出现过的编号全收进 all[]
    收集所有编号 → 排序去重 → 二分查下标 idx(编号)
    重新遍历原始输入建树：kid[u][0..2] = idx(孩子)，par[孩子] = u；root = idx(第一行的第一个)
    BFS 从 root 求 dep[]

【两版共用的后半段】
按优先级升序排序客户（数值小优先）

输出 root
for 每个客户 t:
    输出 walk(cur → t)          // 不含 cur、含 t
    换行
    cur = t
输出 walk(cur → root)；换行

walk(u, v):                     // 打印路径，数字间一个空格、行末不加空格
    a = u; b = v
    while dep[a] > dep[b]: a = par[a]
    while dep[b] > dep[a]: b = par[b]
    while a != b: a = par[a]; b = par[b]        // a = LCA
    if u != a:                                  // 上行段（不含 LCA）
        for x = par[u] while x != a: 输出 x；x = par[x]
        输出 a                                   // LCA 本身
    for x = v while x != a: 入栈 x；x = par[x]   // 下行段自下而上收集
    while 栈不空: 输出 出栈元素                   // 倒着打就是下行顺序
```

**代码**

> **两版并列**：简化版在「题面封死了编号空间」时用，通用版在题面没说时用。算法（LCA 那三行）**两版完全相同**，差别只在「编号要不要翻译成下标」。考场先看题面——只要明写了编号范围，就用简化版，少写一半代码、少一半出错点。

**① 简化版 · 编号直接当下标（题面已声明：叶结点编号 < 100，全树结点编号 < 300）** → `2019_2_deliver_byid.c`

```c
/* 2019 年北航复试上机 题目二：按优先级送客户并输出每段路径
 * ★ 本版前提（题面已声明）：叶结点编号 < 100，全树结点编号 < 300
 *   → 编号可以直接当数组下标，不需要「收集编号 → 排序去重 → 二分翻译」那整套离散化。
 *
 * 求路径仍是父指针 + 深度做 LCA（与 2019_2_deliver.c 的算法完全一致），
 * 区别只在于：kid 的第一维、par/dep 的下标、输出时打印的东西，
 * 这里全都是「编号本身」，所以连 vid[] 还原都不需要。
 *
 * 编译：cc -std=c89 -Wall -Wextra -o 2019_2_deliver_byid 2019_2_deliver_byid.c
 */
#include <stdio.h>

#define MAXV 305                    /* 题面保证编号 < 300，开 305 留余量 */

/* ==================== 树：编号即下标，不做任何翻译 ==================== */
static int kid[MAXV][3];            /* kid[u][k] = 孩子编号；-1 表示该位为空 */
static int par[MAXV];               /* par[v] = 父亲的编号 */
static int dep[MAXV];               /* dep[v] = 深度，根记 0 */

/* ==================== 运行时用的表 ==================== */
static int q[MAXV];                 /* BFS 队列 */
static int stk[MAXV];               /* 打印下行段时用的栈 */
static int cid[MAXV], cpri[MAXV];   /* 客户：目标叶结点编号 + 优先级 */

/* 打印从 u 到 v 的路径：跳过 u、包含 v。
 * sep=1 表示本行前面已有内容（每个数前补空格）。 */
static void walk(int u, int v, int sep) {
    int x, a = u, b = v, sp = 0;

    while (dep[a] > dep[b]) a = par[a];                 /* ① 对齐深度 */
    while (dep[b] > dep[a]) b = par[b];
    while (a != b) { a = par[a]; b = par[b]; }          /* ② 同步上溯，相遇点 a 就是 LCA */

    if (u != a) {                                       /* 起点本身就是 LCA 时没有上行段 */
        for (x = par[u]; x != a; x = par[x]) {          /* 上行段：从起点的父走到 LCA 的父 */
            if (sep) putchar(' ');
            printf("%d", x);                            /* ★ 编号即下标，直接打印，无 vid[] */
            sep = 1;
        }
        if (sep) putchar(' ');
        printf("%d", a);                                /* LCA 本身 */
        sep = 1;
    }
    for (x = v; x != a; x = par[x]) stk[sp++] = x;      /* 下行段：自下而上收集 */
    while (sp > 0) {                                    /* 倒着弹出就是下行顺序 */
        if (sep) putchar(' ');
        printf("%d", stk[--sp]);
        sep = 1;
    }
}

int main(void) {
    int n, m, i, j, k, u, root = 0, head, tail, t, bi;

    if (scanf("%d", &n) != 1) return 0;

    /* ⚠️ static 数组是零初始化的，而「空孩子」要的是 -1 而不是 0，必须显式刷一遍 */
    for (i = 0; i < MAXV; i++) kid[i][0] = kid[i][1] = kid[i][2] = -1;

    /* ---------- 读入即建树：编号就是下标，一次遍历搞定 ----------
     * 对比原版：原版要先把 fid[]/ch[][] 存下来 → 收集 all[] → qsort → 去重
     *           → 再遍历一遍用 idx() 翻译；这里全部省掉。 */
    for (i = 0; i < n; i++) {
        int f, c0, c1, c2;
        scanf("%d %d %d %d", &f, &c0, &c1, &c2);
        if (i == 0) root = f;                           /* 题面：第一行第一个结点是根 */
        kid[f][0] = c0; kid[f][1] = c1; kid[f][2] = c2; /* -1 原样存着，遍历时用 >= 0 判 */
        if (c0 >= 0) par[c0] = f;                       /* 题面保证至多一个父，可直接赋值 */
        if (c1 >= 0) par[c1] = f;
        if (c2 >= 0) par[c2] = f;
    }

    scanf("%d", &m);
    for (i = 0; i < m; i++) scanf("%d %d", &cid[i], &cpri[i]);

    /* ---------- 从根 BFS 一遍算出深度 ----------
     * 必须等树建完再算：输入行的顺序不保证父在子之前。 */
    head = tail = 0;
    dep[root] = 0;
    q[tail++] = root;
    while (head < tail) {
        u = q[head++];
        for (k = 0; k < 3; k++)
            if (kid[u][k] >= 0) {
                dep[kid[u][k]] = dep[u] + 1;
                q[tail++] = kid[u][k];
            }
    }

    /* ---------- 客户按优先级升序（m 很小，选择排序够用） ---------- */
    for (i = 0; i < m; i++) {
        bi = i;
        for (j = i + 1; j < m; j++) if (cpri[j] < cpri[bi]) bi = j;
        if (bi != i) {
            t = cpri[i]; cpri[i] = cpri[bi]; cpri[bi] = t;
            t = cid[i];  cid[i]  = cid[bi];  cid[bi]  = t;
        }
    }

    /* ---------- 逐段输出 ---------- */
    u = root;
    printf("%d", u);                                    /* 起点先单独打一次 */
    for (i = 0; i < m; i++) {
        walk(u, cid[i], i == 0);                        /* 第 1 段接在起点那一行往后写 */
        putchar('\n');
        u = cid[i];                                     /* 本段终点变成下一段起点 */
    }
    walk(u, root, 0); putchar('\n');                    /* 最后把车送回起点 */
    return 0;
}
```

**② 通用版 · 编号离散化（题面未声明编号范围——本题 PDF 原文即属此类，考场按这个写）** → `2019_2_deliver.c`

```c
/* 2019 年北航复试上机 题目二：按优先级送客户并输出每段路径
 * 考点：树上的唯一路径 = 两点的 LCA 上溯 + 下行；优先级排序
 * 输入 n（< 10000）和 n 行「分叉结点 孩子1 孩子2 孩子3」（-1 表示无；第一行第一个是根）
 *      再输入 m 和 m 行「目标叶结点 优先级」（数值越小越优先，不并列）
 * 输出：把整条行车路线按“一段一行”展开：起点先单独打印，之后每段打印
 *       「从上一个位置到目标」经过的结点（不含起点、含目标）；最后一段是「从最后一个目标回起点」
 *
 * ★ 建树四步（本题最麻烦的地方，和 2018 年题目二同一套路）
 *   ① 读入时把「分叉结点编号」和「孩子编号」全部收集进 all[]——只是攒编号，还没建树；
 *   ② all[] 排序 + 原地去重，得到全树的编号集合；vid[i] = 第 i 个编号（输出时要靠它还原）；
 *   ③ 二分 idx(编号) 把每条边翻译成「下标」：kid[u][k] 存孩子下标，同时 par[孩子] = u；
 *   ④ 从根 BFS 一遍算出 dep[]（有了 par[] 和 dep[]，后面 LCA 才能用）。
 * 为什么要这么绕：题面没限定结点编号范围，既可能从 1 开始也可能从 100 开始、还可能不连续，
 *   所以不能拿编号直接当数组下标（那样会开出一个巨大的空洞数组）。
 *   一律翻译成 0..nid-1 的下标再做事，输出时用 vid[] 换回编号。
 */
#include <stdio.h>
#include <stdlib.h>

#define MAXN 40005                      /* n < 10000：节点池 3n+1；all[] 要装 4n 个编号（每行 1 父 + 至多 3 子） */

/* ================= 第 ① ② 步用到的表（原始输入与编号集合） ================= */
static int fid[MAXN], ch[MAXN][3];      /* ① 原始输入：fid[i] = 第 i 行的分叉结点，ch[i][0..2] = 它三个孩子（-1 为空） */
static int all[MAXN], na = 0;           /* ① 所有出现过的编号（父和子都塞进来），后面排序去重 */
static int vid[MAXN];                   /* ② 下标 → 编号：vid[下标] = 原始编号，输出时用它换回来 */
static int nid = 0;                     /* ② 去重后的编号个数 = 树的实际结点数 */

/* ================= 第 ③ ④ 步真正要用的树（全部用下标表达，不用指针） ================= */
static int kid[MAXN][3];                /* ③ 孩子表：kid[u][k] = 孩子下标，-1 表示该位为空 */
static int par[MAXN];                   /* ③ 父指针：par[v] = v 的父亲下标（LCA 上溯全靠它） */
static int dep[MAXN];                   /* ④ 深度：dep[根] = 0，BFS 一层层算出来 */

static int cid[MAXN], cpri[MAXN];       /* 客户：目标叶子（原始编号）+ 优先级 */
static int q[MAXN];                     /* BFS 用的队列（静态数组，不写 STL） */

static int cmp(const void *A, const void *B) { return *(const int *)A - *(const int *)B; }

static int idx(int v) {                 /* ③ 编号 → 下标：在去重后的 all[] 里二分查找 */
    int lo = 0, hi = na - 1, mid;
    while (lo <= hi) {
        mid = (lo + hi) / 2;
        if (all[mid] == v) return mid;
        if (all[mid] < v) lo = mid + 1; else hi = mid - 1;
    }
    return -1;                          /* 理论上查不到（编号都收集过了），留个返回值防身 */
}

/* 打印从 u 到 v 的路径：跳过 u、包含 v。
 * sep=1 表示本行前面已有内容（每个数前面补空格）；sep=0 表示本行从空开始。 */
static void walk(int u, int v, int sep) {
    static int st[MAXN];
    int x, a = u, b = v, sp = 0;

    while (dep[a] > dep[b]) a = par[a];                 /* 先对齐深度 */
    while (dep[b] > dep[a]) b = par[b];
    while (a != b) { a = par[a]; b = par[b]; }          /* a = LCA */

    if (u != a) {                                       /* 起点就是 LCA 时没有上行段 */
        for (x = par[u]; x != a; x = par[x]) {
            if (sep) putchar(' ');
            printf("%d", vid[x]);
            sep = 1;                                    /* 上行段（不含 LCA） */
        }
        if (sep) putchar(' ');
        printf("%d", vid[a]);                           /* LCA 本身 */
        sep = 1;
    }
    for (x = v; x != a; x = par[x]) st[sp++] = x;       /* 下行段自下而上收集 */
    while (sp > 0) {
        if (sep) putchar(' ');
        printf("%d", vid[st[--sp]]);                    /* 倒着打就是下行顺序 */
        sep = 1;
    }
}

int main(void) {
    int n, m, i, j, k, root, head, tail, cur, t;

    /* ---------- 第 ① 步：读入 + 把编号全部收集起来 ---------- */
    if (scanf("%d", &n) != 1) return 0;
    for (i = 0; i < n; i++) {
        scanf("%d %d %d %d", &fid[i], &ch[i][0], &ch[i][1], &ch[i][2]);
        all[na++] = fid[i];                                 /* 分叉结点编号 */
        for (k = 0; k < 3; k++)
            if (ch[i][k] >= 0) all[na++] = ch[i][k];        /* -1 不是编号，不收进来 */
    }
    scanf("%d", &m);
    for (i = 0; i < m; i++) scanf("%d %d", &cid[i], &cpri[i]);
    /* 客户的目标是叶结点，它一定已作为某行的孩子被收进 all[] 了，所以这里不必再收一次 */

    /* ---------- 第 ② 步：编号排序 + 原地去重 → 得到下标的取值范围 ---------- */
    qsort(all, na, sizeof all[0], cmp);                     /* 排序 */
    for (i = 1, k = 1; i < na; i++)                         /* 原地去重：只留不相邻重复的 */
        if (all[i] != all[i - 1]) all[k++] = all[i];
    na = k;
    nid = na;                                               /* nid = 树的结点数，0..nid-1 就是合法下标 */

    /* 顺手准备 vid[]（下标 → 编号）和 kid[]（先全刷 -1）。
     * ⚠️ static 数组是零初始化的，而「空孩子」要的是 -1 而不是 0，
     *    所以必须在这里显式刷一遍，不能指望默认值。 */
    for (i = 0; i < nid; i++) {
        vid[i] = all[i];
        kid[i][0] = kid[i][1] = kid[i][2] = -1;
    }

    /* ---------- 第 ③ 步：把每条边的「编号」翻译成「下标」，同时建孩子表和父指针 ---------- */
    for (i = 0; i < n; i++) {
        int u = idx(fid[i]);                                /* 本行分叉结点对应的下标 */
        for (k = 0; k < 3; k++) {
            kid[u][k] = (ch[i][k] < 0) ? -1 : idx(ch[i][k]);/* -1 留空，否则翻译成下标 */
            if (kid[u][k] >= 0) par[kid[u][k]] = u;         /* 孩子的父亲就是这个下标 u */
        }
    }
    root = idx(fid[0]);                                     /* 题面：第一行第一个结点是根 */
    /* 这一步只依赖「编号 → 下标」的映射，和输入行的先后顺序无关：
     * 某个分叉可能先作为别人的孩子出现、之后才有自己那一行，也可能反过来，都不影响结果。
     * 父指针直接赋值（而不是「判断是否已有父亲再挂」）的依据是题面保证「输入的结点至多有一个父节点」。 */

    /* ---------- 第 ④ 步：从根 BFS 一遍，算出每个结点的深度 ---------- */
    /* 为什么必须「建完树再 BFS」，而不能边读边算 dep：
     *   输入行的顺序不保证父在子之前（题面只保证了「至多一个父亲」），
     *   读到某个子结点时，它的父可能还没被翻译成下标、深度自然也推不出来。
     *   先建完树，再从根出发，就一定是父先于子，深度就对了。
     * 用 BFS 而不是递归的原因：树可能退化成一条长链，BFS 不占调用栈。 */
    head = tail = 0;
    dep[root] = 0;                                          /* 根深度记 0（记 1 也行，LCA 只用到差值） */
    q[tail++] = root;
    while (head < tail) {
        int u = q[head++];
        for (k = 0; k < 3; k++)
            if (kid[u][k] >= 0) {
                dep[kid[u][k]] = dep[u] + 1;
                q[tail++] = kid[u][k];
            }
    }
    /* 孩子按 0→2 的顺序入队，所以出队顺序天然就是「从上到下、同层从左到右」的层次遍历序。 */

    for (i = 0; i < m; i++) {                           /* 按优先级升序（m 很小，选择排序够用） */
        int bi = i;
        for (j = i + 1; j < m; j++) if (cpri[j] < cpri[bi]) bi = j;
        if (bi != i) {
            t = cpri[i]; cpri[i] = cpri[bi]; cpri[bi] = t;
            t = cid[i];  cid[i]  = cid[bi];  cid[bi]  = t;
        }
    }

    cur = root;
    printf("%d", vid[cur]);                             /* 起点先单独打一次 */
    for (i = 0; i < m; i++) {
        walk(cur, idx(cid[i]), i == 0);                 /* 第 1 段接着起点那一行往后写 */
        putchar('\n');
        cur = idx(cid[i]);                              /* 本段终点变下一段起点（下标形式） */
    }
    walk(cur, root, 0); putchar('\n');                  /* 最后把车送回起点 */
    return 0;
}
```

### 题目一 · 首尾相接的最长线段链

**考查**：排序 + DP（记忆化，别写纯暴搜） ｜ **代码**：`2018_1_lines.c`

**手搓要点（C89）**

- **结构**：`typedef struct { int sx, sy, tx, ty; } S;` + `static S seg[MAXN];`，再单开一张记忆表 `static int f[MAXN];`（模板 C-7 + C-9）。
- **比较器**：双键就写成"第一键不等先返回，否则返回第二键"：`if (x->sx != y->sx) return x->sx - y->sx; return x->sy - y->sy;`。
- **记忆化不需要额外结构**：`f[]` 数组本身就是记忆表，**从右往左一遍填完** —— 不用递归、不用标记"算过没有"、不用担心爆栈。
- **排序是 DP 的前提**：按起点横坐标排完，"能接上的后继"必然排在后面，才敢倒着扫；这个"先给状态找拓扑序"的思路在树形 DP 里也一样用。

**题目**

`n` 条线段（`n < 10000`），每行「左端点 x y，右端点 x y」，**保证右端点横坐标 > 左端点横坐标**。两条线段能连在一起的条件是：**一条的左端点与另一条的右端点坐标完全相同**。求连在一起的大线段最多包含多少条线段，以及**最长链起点的坐标**。

**样例**

```
输入：
4
1 2 2 3
2 3 3 4
3 4 4 1
2 3 5 6
输出：3 1 2          （链：(1,2)→(2,3)→(3,4)）

输入：
6
1 3 2 4
2 4 3 3
3 3 7 2
2 4 4 1
4 1 5 6
5 6 6 5
输出：4 1 3
```

**思路**

- 题面只约束**横坐标**（右 > 左），纵坐标随意——这说明**横坐标可以用来定序**：把所有线段按**起点横坐标排序**，那么「能接在本段后面的线段」起点横坐标必然**严格更大**，必然排在后面。
- 于是可以倒着做 DP：`f[i] = 1 + max{ f[j] : (sx_j, sy_j) == (tx_i, ty_i) }`，**从右往左算**，保证后继的 `f` 已经算好；答案就是 `max f[i]`。
- 这比指南的参考实现（纯递归枚举所有分支）稳得多：那个在「一个端点接很多条线段」时会指数级爆炸。本做法最坏 O(n²)（n=10⁴ 实测 15 ms，够用）；若想更快，可把线段按 `(sx, sy)` 分组后用二分定位后继，降到 O(n log n)。
- 并列时**没有明确规则**，本实现取排序后（起点横坐标、纵坐标升序）**最先**的那条作为起点的坐标。

**伪代码**

```
读入 n 条线段 (sx, sy, tx, ty)
按 (sx, sy) 升序排序
for i = n-1 downto 0:                     // 从右往左，后继一定在后面
    best = 0
    for j = i+1 to n-1:
        if (sx[j], sy[j]) == (tx[i], ty[i]) and f[j] > best: best = f[j]
    f[i] = best + 1
取最大的 f[i]（并列取最靠前的），输出 f[i], sx[i], sy[i]
```

**代码**

```c
/* 2018 年北航复试上机 题目一：首尾相接的最长线段链
 * 考点：排序 + DP（按终点接起点做记忆化，别写纯暴搜）
 * 连接规则：只能「某条线段的左端点」接「另一条线段的右端点」，且两个端点坐标完全相同
 * 输入 n（< 10000）和 n 行「左x 左y 右x 右y」（保证 右x > 左x）
 * 输出「最长链的线段条数 链起点x 链起点y」
 */
#include <stdio.h>
#include <stdlib.h>

#define MAXN 10005

typedef struct { int sx, sy, tx, ty; } S;

static S seg[MAXN];
static int f[MAXN];                     /* f[i]：以第 i 条线段开头的最长链长度 */

static int cmp(const void *A, const void *B) {
    const S *x = (const S *)A, *y = (const S *)B;
    if (x->sx != y->sx) return x->sx - y->sx;
    return x->sy - y->sy;
}

int main(void) {
    int n, i, j, best, mx = -1, mi = 0;

    if (scanf("%d", &n) != 1) return 0;
    for (i = 0; i < n; i++)
        scanf("%d %d %d %d", &seg[i].sx, &seg[i].sy, &seg[i].tx, &seg[i].ty);

    qsort(seg, n, sizeof seg[0], cmp);   /* 按起点横坐标排序：后继的起点 > 本段起点 → 必在后面 */

    for (i = n - 1; i >= 0; i--) {       /* 从右往左算，后继的 f 一定已经算好 */
        best = 0;
        for (j = i + 1; j < n; j++)
            if (seg[j].sx == seg[i].tx && seg[j].sy == seg[i].ty && f[j] > best)
                best = f[j];
        f[i] = best + 1;
    }

    for (i = 0; i < n; i++)              /* 取最长链；长度并列取排序后靠前的起点 */
        if (f[i] > mx) { mx = f[i]; mi = i; }

    printf("%d %d %d\n", mx, seg[mi].sx, seg[mi].sy);
    return 0;
}
```

### 题目二 · 三叉树前序遍历统计

**考查**：多叉树建树（编号 → 下标映射）+ 前序遍历 ｜ **代码**：`2018_2_pretree.c`

**手搓要点（C89）**

- **结构**：`static int kid[MAXN][3];`（-1 为空）+ `vid[]`（下标 → 编号）+ `all[]`/`idx()` 二分映射（模板 C-3 + C-5）。
- **递归前序**：`void pre(int u, int d) { if (u < 0) return; … for (k=0;k<3;k++) pre(kid[u][k], d+1); }` —— **把判空放在函数开头**，调用处就能干净地调三次，不用各套一个 `if`。
- **深度靠参数传**：`d + 1` 随递归带下去，不需要另存 `dep[]` 再遍历第二遍。
- ⚠️ `kid` 用 `static` 只保证**零初始化**，而"空孩子"要的是 `-1` 不是 `0`，所以读入前必须显式刷满 `-1`。
- 结点数 10⁴ 的链状树递归深度也就 10⁴，默认 8 MB 栈够用；真到 10⁶ 级再改手工栈（模板 C-6）。

**题目**

`n` 行，每行「**根 左孩子 中孩子 右孩子**」（`-1` 表示不存在；**保证每个根在之前出现过**）。求**前序遍历**（根、左、中、右）中「**子分支最多**」的结点编号，以及它**第几次**被遍历到；并列时取**深度更深**者，再并列取**先遍历到**的。

**样例**

```
输入：              输出：
2                   7 3
20 2 -1 7
7 6 4 -1

输入：              输出：
4                   9 2
10 9 -1 7
9 6 5 -1
7 -1 3 11
11 -1 14 -1
```

**思路**

- **规则**（两个官方样例 + 指南自测用例 2 共同印证）：先比**非空孩子个数**，多者胜；并列比**深度**，深者胜；再并列取**前序最先访问到**的。样例 1 里 20 和 7 都挂两个孩子，7 更深，取 7；样例 2 里 10、9、7 都挂两个孩子，9 和 7 同深度，取先访问的 9（2 号）。
- ⚠️ 指南参考代码的条件写成 `cnt >= cntmax && d > dmax`，在「**先遇到孩子少但很深、后遇到孩子多但较浅**」时会漏选后者（例如先访问到 cnt=1/d=5，后访问到 cnt=2/d=1，后者会被拒绝）。按上面的字典序规则写成 `cnt > bc || (cnt == bc && d > bd)` 才对。
- **建树**：输入按「父已出现过」给，但仍然**不能假设编号范围**。做法是先把所有编号（每行 4 个）收集起来 → 排序去重 → 二分查下标；然后 `kid[下标]` 挂孩子。第一行的第一个结点是根。
- 深度在前序遍历时顺手递推（根深度记 1），访问序号用全局计数器。

**伪代码**

```
读 n 行 (f, c1, c2, c3)，把所有编号收进 all[]（含 -1 之外的全部）
all[] 排序去重 → vid[]（下标 → 编号），idx(编号) 二分查下标
建树：kid[idx(f)][0..2] = idx(c*)，-1 保持 -1
pre(u, d):                                  // 前序：根、左、中、右
    cnt = u 的非空孩子个数
    if cnt > best_cnt 或 (cnt == best_cnt 且 d > best_dep):
        记下 u、d、以及当前访问序号
    for k = 0..2: pre(kid[u][k], d+1)
pre(idx(第一行第一个), 1)
输出 vid[最优结点], 它的访问序号
```

**代码**

```c
/* 2018 年北航复试上机 题目二：三叉树前序遍历统计
 * 考点：多叉树建树（编号 → 下标映射，用“编号排序 + 二分”代替 map）+ 前序遍历
 * 输入 n（< 10000）和 n 行「根 左孩子 中孩子 右孩子」（-1 表示无；根一定在之前出现过）
 * 输出：前序遍历里「子分支（非空孩子）最多」的结点编号，以及它第几次被遍历到
 *       并列时取深度更深者，再并列取先遍历到的
 */
#include <stdio.h>
#include <stdlib.h>

#define MAXN 10005

static int kid[MAXN][3];        /* 三个孩子的下标，-1 表示空 */
static int vid[MAXN];           /* 下标 → 结点编号 */
static int all[MAXN], na = 0;   /* 所有出现过的编号（排序后二分查找） */
static int nid = 0;
static int dep[MAXN], cnt[MAXN];
static int order = 0;
static int bc = -1, bd = -1, bn = -1, bo = 0;   /* 目前最好的：孩子数 / 深度 / 编号 / 遍历序号 */

static int fid[MAXN], ch[MAXN][3];              /* 原始输入 */

static int cmp(const void *A, const void *B) { return *(const int *)A - *(const int *)B; }

static int idx(int v) {                         /* 编号 → 下标 */
    int lo = 0, hi = na - 1, mid;
    while (lo <= hi) {
        mid = (lo + hi) / 2;
        if (all[mid] == v) return mid;
        if (all[mid] < v) lo = mid + 1; else hi = mid - 1;
    }
    return -1;
}

static void pre(int u, int d) {                 /* 前序：根、左、中、右 */
    int k;
    if (u < 0) return;
    dep[u] = d;
    order++;
    cnt[u] = 0;
    for (k = 0; k < 3; k++) if (kid[u][k] >= 0) cnt[u]++;

    /* 先比孩子数，再比深度（更深者优先）；先遍历到的自然先占位，并列时不替换 */
    if (cnt[u] > bc || (cnt[u] == bc && d > bd)) { bc = cnt[u]; bd = d; bn = u; bo = order; }

    for (k = 0; k < 3; k++) pre(kid[u][k], d + 1);
}

int main(void) {
    int n, i, k, root;

    if (scanf("%d", &n) != 1) return 0;
    for (i = 0; i < n; i++) {
        scanf("%d %d %d %d", &fid[i], &ch[i][0], &ch[i][1], &ch[i][2]);
        all[na++] = fid[i];
        for (k = 0; k < 3; k++) if (ch[i][k] >= 0) all[na++] = ch[i][k];
    }
    root = fid[0];                              /* 第一行第一个是树根 */

    qsort(all, na, sizeof all[0], cmp);         /* 编号排序去重，之后用二分映射 */
    for (i = 1, k = 1; i < na; i++) if (all[i] != all[i - 1]) all[k++] = all[i];
    na = k;
    nid = na;
    for (i = 0; i < nid; i++) {
        vid[i] = all[i];
        kid[i][0] = kid[i][1] = kid[i][2] = -1;
    }
    for (i = 0; i < n; i++) {
        int u = idx(fid[i]);
        for (k = 0; k < 3; k++) kid[u][k] = (ch[i][k] < 0) ? -1 : idx(ch[i][k]);
    }

    pre(idx(root), 1);                          /* 深度从 1 开始数 */

    printf("%d %d\n", vid[bn], bo);
    return 0;
}
```

## 2017 年（三题，字符串 + 树的第一年）

### 题目一 · 中位数的位置

**考查**：结构体排序（值 + 原始输入次序） ｜ **代码**：`2017_1_median.c`

**手搓要点（C89）**

- **结构**：`typedef struct { int v, t; } P;` —— **把"输入次序"当字段一起存**，这是"输出中位数的位置"能成立的前提（模板 C-7）。
- **数组规模**：`N < 10⁶` → `static P a[1000005]` 约 8 MB，**必须放静态区**；写成 `main` 里的局部数组直接爆栈（模板 C-11 的总则）。
- **稳定化**：`qsort` 本身**不稳定**，比较器第二键写 `x->t - y->t` 就等于手工做了稳定排序。
- ⚠️ 别"先 `qsort` 再回头找原始位置"—— 那时同值元素之间的相对次序已经乱了。

**题目**

输入 `N`（`1 ≤ N < 1000000`）和 `N` 个无序整数，输出**非递减排序后**的中位数**及其在输入中的次序**：`N` 为奇数输出一行（最中间那个），`N` 为偶数输出两行（中间两个，先小后大）。数值相同时**先输入的排前面**。

**样例**

```
输入：5 / 9 2 7 1 6            输出：6 5
输入：6 / 9 6 7 1 2 3          输出：3 6
                                     6 2
输入：6 / 9 3 7 1 3 3          输出：3 5
                                     3 6
```

**思路**

- 经典「结构体 + 排序」：结构体存 `{值, 输入次序}`，按「值升序、次序升序」排序，直接取 `a[n/2]`（偶数再取 `a[n/2-1]`）。
- `N < 10⁶`：数组开 `1000005` 放**静态区**（约 8 MB），别放栈上。
- 坑：**不能先排序再记位置**（会在同值处打乱原次序），必须把次序当字段一起排。

**伪代码**

```
读 N 个数：a[i].v = 值；a[i].t = i+1
按 (v 升序, t 升序) 排序
if N 是奇数: 输出 a[N/2].v, a[N/2].t
else:        输出 a[N/2-1].v, a[N/2-1].t；再输出 a[N/2].v, a[N/2].t
```

**代码**

```c
/* 2017 年北航复试上机 题目一：中位数的位置
 * 考点：结构体排序（值 + 原始输入次序）
 * 输入 N（1 <= N < 10^6）和 N 个无序数
 * 输出非递减序的中位数，以及它在输入里的次序：
 *   N 为奇数 → 一行（最中间那个）；N 为偶数 → 两行（中间两个，先小后大）
 *   数值相同时，先输入的排前面
 */
#include <stdio.h>
#include <stdlib.h>

#define MAXN 1000005

typedef struct { int v, t; } P;        /* v：数值；t：输入次序（从 1 开始） */

static P a[MAXN];

static int cmp(const void *A, const void *B) {
    const P *x = (const P *)A, *y = (const P *)B;
    if (x->v != y->v) return x->v < y->v ? -1 : 1;
    return x->t - y->t;                /* 同值时按输入次序，稳定 */
}

int main(void) {
    int n, i;

    if (scanf("%d", &n) != 1) return 0;
    for (i = 0; i < n; i++) { scanf("%d", &a[i].v); a[i].t = i + 1; }
    qsort(a, n, sizeof a[0], cmp);

    if (n % 2 == 1) {
        printf("%d %d\n", a[n / 2].v, a[n / 2].t);
    } else {
        printf("%d %d\n", a[n / 2 - 1].v, a[n / 2 - 1].t);
        printf("%d %d\n", a[n / 2].v, a[n / 2].t);
    }
    return 0;
}
```

### 题目二 · 查找未定义的变量

**考查**：字符串扫描（**只认「合法字符」**，把「不合法」当分隔符） ｜ **代码**：`2017_2_undef.c`

**手搓要点（C89）**

- **结构**：只需要一张字符串表 `static char tab[MAXT][MAXL];`（二维 `char` 数组当"字符串列表"），不用 `malloc`（模板 C-10）。
- **两个判定函数撑起全题**：`isId(c)`（字母 / 下划线）与 `isIdc(c)`（再加数字）；其余符号（`= + - * ( ) [ ] ;`）**一律默认是分隔符** —— "合法取反"永远不会漏字符。
- **整行读**：`fgets(line, sizeof line, stdin)`，`line` 开 `static char line[1000005]`（行长 10⁶，栈放不下）。
- **常数整块吃掉**：以数字开头就 `while (数字或 '.') i++;` 跳过整块 → `a[30]`、`456.78`、`y=1` 里的 `1` 全部自动免疫，**不用特判数组和浮点**。
- 尾随空格写进格式串：`printf("%s ", nm)`。

**题目**

输入两行：第一行是合法的 C 变量定义语句（可含数组、指针，变量间可有多个空格），第二行是基本运算语句（不含强制转换）。输出第二行中**未定义**的变量，**每个变量后面跟一个空格**，最后换行；没有未定义变量时只输出一个换行。定义的变量数 ≤ 1000，单个变量长度 ≤ 1000。

**样例**

```
输入：
double x12, y=1, num_stu=89,a[30],*p;
Sum=num+x12*y
输出：Sum num␣

输入：
int int123  =456;
in = ab_ * (int123++)
输出：in ab_␣
```

> 输出里 `Sum num` 后面**还有一个空格**（题面明确要求，md 里保留不了行尾空格）。

**思路**

- 全题只有一条核心规则：**标识符 = 字母/下划线开头，后接字母/数字/下划线**；其余字符（`= , + - * ( ) [ ] ; & .` 等）全当分隔符。**反过来用「合法取反」比枚举非法字符稳得多**。
- 关键判别：**以数字开头的整块是常数，直接跳过**。这一步同时解决了 `a[30]`、`456.78`、`y=1` 里的 `1`、`c[1][2][3]` 这些坑——不用特判数组和浮点。
- 第一行**跳过开头的类型名**（`while (isIdc) i++`），其余标识符全部登记为「已定义」；第二行扫描出的每个标识符查表。
- 坑：① 第二行**不一定有分号**（用 `i < len` 判断结尾，别用分号）；② 名字后可能跟空格再跟 `=`；③ 输出是**每个未定义变量各跟一个空格**（出现的每一处都输出，不合并重复）。

**伪代码**

```
collect(行, 跳过类型名?):
    if 跳过类型名: 先跳过开头的标识符
    while 未到行尾:
        if 是标识符首字符(字母/_):
            连续读取 [字母/数字/_] → 存进表
        elif 是数字: 把 [数字/.] 整块吃掉     // 常数，不记录
        else: i++                            // 其它符号一律跳过

主流程:
    collect(第一行, 跳过类型名 = 真)
    while 扫第二行:
        同样规则取出标识符 → 若不在表里，输出它 + 一个空格
    输出换行
```

**代码**

```c
/* 2017 年北航复试上机 题目二：查找未定义的变量
 * 考点：字符串扫描。只认“合法字符”（字母/数字/下划线），其余全当分隔符；
 *       只要一个 token 以数字开头，就整块当常数跳过（这样 a[30]、456.78 自动免疫）。
 * 输入：第 1 行变量定义语句（跳过开头的类型名，其余标识符都是已定义变量）
 *       第 2 行运算语句
 * 输出：第 2 行里出现、但第 1 行没定义的变量，每个后面跟一个空格，最后换行
 *       （一个都没有时只输出一个换行）
 */
#include <stdio.h>
#include <string.h>

#define MAXT 1005
#define MAXL 1005

static char tab[MAXT][MAXL];          /* 第 1 行定义出的变量名 */
static int  nt = 0;
static char line[1000005];            /* 变量可以很多，行缓冲开大一点 */

static int isId(int c)  { return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') || c == '_'; }
static int isIdc(int c) { return isId(c) || (c >= '0' && c <= '9'); }

/* 把一行里的标识符收进 tab[]；skipType=1 时先跳过开头的类型名 */
static void collect(const char *s, int skipType) {
    int i = 0, len = (int)strlen(s), k;

    if (skipType) {
        while (i < len && s[i] == ' ') i++;
        while (i < len && isIdc((unsigned char)s[i])) i++;       /* 类型名（int/double/...） */
    }
    while (i < len) {
        if (isId((unsigned char)s[i])) {                          /* 标识符：不能数字开头 */
            k = 0;
            while (i < len && isIdc((unsigned char)s[i]) && k < MAXL - 1) tab[nt][k++] = s[i++];
            tab[nt][k] = '\0';
            nt++;
        } else if (s[i] >= '0' && s[i] <= '9') {                  /* 常数：整块吃掉 */
            while (i < len && ((s[i] >= '0' && s[i] <= '9') || s[i] == '.')) i++;
        } else {
            i++;                                                  /* = + - * ( ) [ ] ; & 等一律跳过 */
        }
    }
}

static int defined(const char *s) {
    int i;
    for (i = 0; i < nt; i++) if (strcmp(tab[i], s) == 0) return 1;
    return 0;
}

int main(void) {
    int i, len, k;
    char nm[MAXL];

    if (fgets(line, sizeof line, stdin) == NULL) return 0;
    collect(line, 1);                       /* 第 1 行：跳过类型，其余都是已定义变量 */

    if (fgets(line, sizeof line, stdin) == NULL) { putchar('\n'); return 0; }  /* 第 2 行可能没有分号 */
    len = (int)strlen(line);
    for (i = 0; i < len; ) {
        if (isId((unsigned char)line[i])) {
            k = 0;
            while (i < len && isIdc((unsigned char)line[i]) && k < MAXL - 1) nm[k++] = line[i++];
            nm[k] = '\0';
            if (!defined(nm)) printf("%s ", nm);      /* 未定义就打印，后面跟空格 */
        } else if (line[i] >= '0' && line[i] <= '9') {
            while (i < len && ((line[i] >= '0' && line[i] <= '9') || line[i] == '.')) i++;
        } else {
            i++;
        }
    }
    putchar('\n');
    return 0;
}
```

### 题目三 · 找家谱成员

**考查**：二叉树 + 父指针 + LCA（先对齐深度再同步上溯） ｜ **代码**：`2017_3_family.c`

**手搓要点（C89）**

- **结构**：姓名表 `static char nm[MAXN][MAXL];` + `par[]` + `dep[]` —— **不需要孩子指针**（这题全程只往上走），比 2018-二 那种建树简单一半（模板 C-4）。
- **手搓 map**：`find(s)` 线性 `strcmp` 扫表、`get(s)` 找不到就新建；`n` 只有几千，`O(n²)` 秒过。
- **父指针 LCA**：对齐深度 → 同步上溯，就那三行（模板 C-4）；**层次差**就是上溯之前算的 `|dep[a] - dep[b]|`。
- **怎么认查询行**：数这一行有几个 token（**3 个 = 谱系行，2 个 = 查询行**），比靠换行 / 关键字判断都稳。
- ⚠️ 被查的两人可能是**同一个成员**（层次差 0，输出他本人），也可能**同层**（不用上溯，直接同步走）。

**题目**

输入若干行家谱：**每行「某成员 他的两个孩子」**（除第一行的第一个成员外，每行第一个成员都在之前输入过；**第一行第一个成员是祖先**）。最后一行输入**两个成员**（只有两个名字），求他们的**最近共同祖先**和**层次差**。

**样例**

```
输入：
Ye Shu Ba
Shu Ge Mei1
Ba Self Mei2
Ge Son1 Son2
Son2 Mei1
输出：Shu 1

（末尾换成 Son2 Son1 → Ge 0；Son2 Self → Ye 1；Son2 Son2 → Son2 0）
```

**思路**

- **怎么判断哪一行是查询行**：谱系行固定「3 个名字」，查询行只有「2 个名字」——按这一行的名字个数分流，简单可靠（不需要靠"有没有换行"之类的技巧）。
- 求 LCA 只需 `par[]` + `dep[]`：把**深的那个先上溯到同层**，然后**两个一起上溯**，第一次相等就是 LCA；层次差就是上溯前的 `|dep[a]-dep[b]|`。**不用建孩子指针**，这题全程只往上走。
- 建结点用「按名字线性查表，没有就新建」；父结点一定先出现过 ⇒ 建孩子时父的深度已经确定，`dep = dep[父] + 1` 直接可算。
- 坑：查询的两个人**可能是同一个成员**（层次差 0，输出他本人）；也可能同层（不用上溯，直接同步走）。

**伪代码**

```
循环读每一行:
    拆出这一行的名字（最多 3 个）
    if 只有 2 个名字:                    // 查询行
        a = 查表(名字1); b = 查表(名字2)
        d = |dep[a] - dep[b]|
        while dep[a] > dep[b]: a = par[a]
        while dep[b] > dep[a]: b = par[b]
        while a != b: a = par[a]; b = par[b]
        输出 名字[a], d；结束
    else:                                 // 谱系行：父 + 2 个孩子
        v = 查表或新建(名字1)
        u = 查表或新建(名字2)；par[u] = v；dep[u] = dep[v] + 1
        u = 查表或新建(名字3)；par[u] = v；dep[u] = dep[v] + 1
```

**代码**

```c
/* 2017 年北航复试上机 题目三：找家谱成员
 * 考点：二叉树 + LCA（只要父指针 + 深度：先把深的那个提到同一层，再一起往上走）
 * 输入：若干行「成员 孩子1 孩子2」（第一行第一个成员是根；父成员一定先出现过）
 *       最后一行为查询，且这行只有两个名字
 * 输出：最近共同祖先的名字 + 两人的层次差
 */
#include <stdio.h>
#include <string.h>

#define MAXN 10005
#define MAXL 64

static char nm[MAXN][MAXL];
static int  par[MAXN], dep[MAXN];
static int  n = 0;

static int find(const char *s) {
    int i;
    for (i = 0; i < n; i++) if (strcmp(nm[i], s) == 0) return i;
    return -1;
}

static int get(const char *s) {              /* 按名字取结点，不存在就新建 */
    int i = find(s);
    if (i >= 0) return i;
    strcpy(nm[n], s);
    par[n] = -1;
    dep[n] = 1;                              /* 根那一行先建，随后会被 father 覆盖为正确深度 */
    return n++;
}

int main(void) {
    static char line[4096];
    char tok[3][MAXL];
    int  a, b, d, u, v;

    while (fgets(line, sizeof line, stdin) != NULL) {
        int i = 0, nt = 0, k;

        while (line[i] != '\0' && nt < 3) {                 /* 拆出这一行的名字（最多 3 个） */
            while (line[i] == ' ' || line[i] == '\t'
                   || line[i] == '\n' || line[i] == '\r') i++;
            if (line[i] == '\0') break;
            k = 0;
            while (line[i] != '\0' && line[i] != ' ' && line[i] != '\t'
                   && line[i] != '\n' && line[i] != '\r' && k < MAXL - 1)
                tok[nt][k++] = line[i++];
            tok[nt][k] = '\0';
            nt++;
        }
        if (nt < 2) continue;                               /* 空行 */

        if (nt == 2) {                                      /* 只有两个名字 → 查询行 */
            a = find(tok[0]);
            b = find(tok[1]);
            if (a < 0 || b < 0) continue;
            d = dep[a] - dep[b];
            if (d < 0) d = -d;                              /* 层次差（取正） */
            u = a; v = b;
            while (dep[u] > dep[v]) u = par[u];             /* 深的先上溯到同层 */
            while (dep[v] > dep[u]) v = par[v];
            while (u != v) { u = par[u]; v = par[v]; }      /* 同步上溯，相遇处即 LCA */
            printf("%s %d\n", nm[u], d);
            break;                                          /* 查询只有一次 */
        }

        v = get(tok[0]);                                    /* 建树：父 + 两个孩子 */
        u = get(tok[1]); par[u] = v; dep[u] = dep[v] + 1;
        if (nt == 3) { u = get(tok[2]); par[u] = v; dep[u] = dep[v] + 1; }
    }
    return 0;
}
```

### 题目一 · 逆序数

**考查**：字符串 ↔ 整数（关键在于**前导 0**） ｜ **代码**：`2016_1_revnum.c`

**手搓要点（C89）**

- **结构**：两个小 `static char` 数组就够：`s[32]` 原串、`r[32]` 倒序串（模板 C-10）。
- **手写"串 → 整数"**：`for (i=0;i<len;i++) n = n*10 + (s[i]-'0');` —— 比 `atoi` 更可控（能中途停），也避开 `00232` 被当八进制读的坑。
- **同一个串两个身份**：`r`（字符串）用来打印、**保住前导 0**；`m`（整数）用来 `% n` 判倍数。`printf("%d %s", n, r)` 混着用正是本题考点。
- **读入**：`scanf("%s", s)` 天然跳过前导空白、读满整个数字串，比逐字符 `getchar` 短。

**题目**

输入 `n`（`0 < n < 1000000`），把它各位倒过来得到 `m`。若 `m` 是 `n` 的整数倍（`k` 倍）输出 `n*k=m`，否则输出 `n` 和 `n` 的逆序数（**按数字串原样输出，保留前导 0**）。已知输入开头不含多余的 0。

**样例**

```
1089  → 1089*9=9801
1234  → 1234 4321
23200 → 23200 00232
9801  → 9801 1089       （反着来不成倍数）
1     → 1*1=1
```

**思路**

- 用 `scanf("%s")` 读成字符串最省事：**倒序后的数字串**（保留前导 0）和**当作整数**解释（前导 0 自动消失）一次都能拿到。
- 判是否存在整数倍：`m % n == 0`（题目保证不成负数）。
- 坑：输出逆序数时**必须按字符串打印**，即 `23200 → 00232`；如果用整数打印就会变成 `232`。指南里特意强调过：**别用 `printf("%d %s")` 打整型数组**，这个坑的样例恰好走的是 `if` 分支，测不出来。
- 边界：个位数（`1*1=1`）、末尾有 0（`10 → 10 01`）。

**伪代码**

```
读字符串 s；len = |s|
n = 把 s 读成整数
r = s 倒序（数字串）
m = 把 r 读成整数
if m % n == 0: 输出 n, '*', m/n, '=', m
else:          输出 n, ' ', r          // 按串打印，保住前导 0
```

**代码**

```c
/* 2016 年北航复试上机 题目一：逆序数
 * 考点：字符串 ↔ 整数（关键在于倒序后的前导 0）
 * 输入 n（0 < n < 1000000），m = n 各位倒过来
 *   m 是 n 的整数倍（k = m/n）→ 输出「n*k=m」
 *   否则输出「n m」，其中 m 要按“数字串”打印，比如 23200 → 00232
 */
#include <stdio.h>
#include <string.h>

int main(void) {
    static char s[32], r[32];
    int n = 0, m = 0, i, len;

    if (scanf("%s", s) != 1) return 0;
    len = (int)strlen(s);
    for (i = 0; i < len; i++) n = n * 10 + (s[i] - '0');
    for (i = 0; i < len; i++) r[i] = s[len - 1 - i];     /* 倒序后的数字串 */
    r[len] = '\0';
    for (i = 0; i < len; i++) m = m * 10 + (r[i] - '0'); /* 前导 0 在读成整数时自动消失 */

    if (m % n == 0) printf("%d*%d=%d\n", n, m / n, m);
    else            printf("%d %s\n", n, r);             /* 必须按串打印，保住前导 0 */
    return 0;
}
```

### 题目二 · enum 输出

**考查**：字符串解析（找 `{`，按 `,` 切项，`=` 显式赋值否则前项 +1） ｜ **代码**：`2016_2_enum.c`

**手搓要点（C89）**

- **结构**：一个 `static char s[1000005]` 收整个输入（长度 10⁶，**必须静态区**）+ 一个 `static char name[1005]` 装当前项名字（模板 C-10）。
- **一次读完**：`while ((c = getchar()) != EOF && len < 1000000) s[len++] = (char)c;` —— 不用管输入里有没有换行。
- **手工扫描三件套**：游标 `i` + "跳分隔符" + "读到指定字符为止"。名字**按分隔符切**（`=` `,` `}` 空格），**不能按字符类型切**（名字里可能含数字，如 `JAN`、`_B1O2`）。
- **"前项 +1"一行搞定**：`val = (j == 0) ? 0 : last + 1;`，`last` 存上一项的值（显式赋值时用读到的整数覆盖它）。

**题目**

输入一行合法 C 的 `enum` 定义语句（长度 ≤ 10⁶，项数 ≤ 1000，每项 ≤ 1000 字符），输出每项的**名字和值**，一行一项。规则：**第一项若未显式赋值默认为 0**；某几项显式赋值后，后面的项在前一项基础上 +1。

**样例**

```
输入：enum BOOL{true,false};
输出：true 0
      false 1

输入：enum date{JAN=1,FEB,MAR,...,DEC,MON=1,TUE,...,SUN,found=1949};
输出：JAN 1
      FEB 2
      ...
      DEC 12
      MON 1
      TUE 2
      ...
      found 1949
```

> 题面写「名称与值之间有一个空格」，测试用例 1 也印证了；指南的测试用例 2 输出印成 `JAN1` 是 **PDF 讹误**，按有空格写。

**思路**

- 一次 `getchar` 读完整个输入（不管中间有没有换行），然后**从第一个 `{` 开始**解析，到 `}` 结束——不用管 `enum` 关键字和枚举名是什么。
- 每个项：**读名字**到 `=` / `,` / `}` / 空格为止；跳过空格；若当前是 `=` 就**读显式整数**，否则 = **前一项 +1**（第一项为 0）。
- 坑：① 名字里可以含数字（`JAN`、`found`、`_B1O2O3L` 都是普通名字），所以**只能按分隔符切，不能按"字符类型"切**；② 输入里可能出现**空格**（样例 `MAY ,JUN`），跳过分隔符时要连空格一起跳；③ 显式赋 0 / 前导 0（`false=02`）都要能吃。

**伪代码**

```
一次读完整个输入到 s
i = s 中第一个 '{' 的下标 + 1；j = 0（第几项）；last = 0
while s[i] != '}' 且未越界:
    跳过空格与 ','
    读名字：到 '=' / ',' / '}' / 空格为止
    跳过空格
    if s[i] == '=':
        i++；跳过空格；读整数 val
    else:
        val = (j == 0) ? 0 : last + 1
    输出 名字, val
    last = val；j++
```

**代码**

```c
/* 2016 年北航复试上机 题目二：enum 输出
 * 考点：字符串解析 —— 找 '{'，以 ',' 切项，遇到 '=' 显式赋值，否则前一项 +1
 * 输入一行 enum 定义语句（不超过 10^6 字符，项 <= 1000，每项 <= 1000 字符）
 * 输出：每项一行「名字 值」
 */
#include <stdio.h>

static char s[1000005], name[1005];

int main(void) {
    int c, len = 0, i = 0, k, j = 0, val, last = 0;

    while ((c = getchar()) != EOF && len < 1000000) s[len++] = (char)c;
    s[len] = '\0';

    while (i < len && s[i] != '{') i++;        /* 跳过 "enum 名字"，找到 '{' 才是起点 */
    if (i < len) i++;

    while (i < len && s[i] != '}') {
        while (i < len && (s[i] == ' ' || s[i] == ',')) i++;   /* 跳过分隔符/空格 */
        if (i >= len || s[i] == '}') break;

        k = 0;                                 /* 名字：读到 '=' ',' '}' 或空格为止 */
        while (i < len && s[i] != '=' && s[i] != ',' && s[i] != '}'
               && s[i] != ' ' && k < 1000)
            name[k++] = s[i++];
        name[k] = '\0';
        while (i < len && s[i] == ' ') i++;    /* 跳过名字与 '=' 之间可能的空格 */

        if (i < len && s[i] == '=') {          /* 显式赋值 */
            i++;
            while (i < len && s[i] == ' ') i++;
            val = 0;
            while (i < len && s[i] >= '0' && s[i] <= '9') { val = val * 10 + (s[i] - '0'); i++; }
        } else {
            val = (j == 0) ? 0 : last + 1;     /* 第一项默认 0，其余前项 +1 */
        }
        printf("%s %d\n", name, val);
        last = val;
        j++;
    }
    return 0;
}
```

### 题目一 · 相亲数

**考查**：因子枚举（扫到 `n/2`） ｜ **代码**：`2015_1_amicable.c`

**手搓要点（C89）**

- **不需要任何结构**：一趟 `for (i=2; i<=a/2; i++) if (a % i == 0) { sumA += i; printf("+%d", i); }` —— **边枚举、边累加、边打印**，不用存因子数组（模板 C-12）。
- **给 `1` 手工铺路**：先 `printf("%d, 1", a); sumA = 1;` 让循环从 2 开始，省一个特判分支。
- **判定必须双向**：`sumA == b && sumB == a`；只判一向能过官方样例，但过不了"反向"数据（1952 / 1954）。
- `n < 10⁶` 时 `n/2` 最坏 50 万次，秒过；若上界升到 10⁹ 要改成试除到 `√n` 再配对累加。

**题目**

输入两个正整数 `a b`（`1 < a, b < 1000000`）。若 `a` 的**全部因子（含 1、不含自身）之和等于 b**，且 `b` 的因子和等于 `a`，则二者是相亲数。要求两行分别输出 `a` 和它的因子和式（**因子从小到大**），再一行输出 `1`（是）或 `0`（否）。

**样例**

```
输入：220 284
输出：220, 1+2+4+5+10+11+20+22+44+55+110=284
      284, 1+2+4+71+142=220
      1

输入：5 7
输出：5, 1=1
      7, 1=1
      0
```

**思路**

- 因子枚举扫到 `n/2` 即可（`n` 本身不算），**边枚举边求和边打印**——一趟循环干三件事，代码最短。
- `1` 必定是因子，先手动打印 `"a, 1"`，和先置 1。
- 坑：判断必须**双向**（`sumA == b && sumB == a`）。只判 `sumA == b` 也能过题目给的样例，但过不了"反向"数据（如 `1952 1954`：1952 的因子和 = 1954，但 1954 的因子和 = 980 ≠ 1952 → 应输出 0）。

**伪代码**

```
读 a, b；sumA = sumB = 1
输出 "a, 1"
for i = 2 .. a/2:  if a % i == 0: sumA += i；输出 "+i"
输出 "=sumA"
对 b 重复同样的过程（用 sumB）
输出 (sumA == b 且 sumB == a) ? 1 : 0
```

**代码**

```c
/* 2015 年北航复试上机 题目一：相亲数（亲和数）
 * 考点：因子枚举（扫描到 n/2）
 * 输入 a b（1 < a,b < 1000000）
 * 输出：两行「a, 1+2+...+x=sum」，因子从小到大；再一行 1/0 表示是否互为对方因子和
 * 注意：1 是因子（要计入和），本身不算；输出是边枚举边打印，不用存因子
 */
#include <stdio.h>

int main(void) {
    int a, b, sumA = 1, sumB = 1, i;

    if (scanf("%d %d", &a, &b) != 2) return 0;

    printf("%d, 1", a);                       /* 1 必定是因子，先打出来 */
    for (i = 2; i <= a / 2; i++)
        if (a % i == 0) { sumA += i; printf("+%d", i); }
    printf("=%d\n", sumA);

    printf("%d, 1", b);
    for (i = 2; i <= b / 2; i++)
        if (b % i == 0) { sumB += i; printf("+%d", i); }
    printf("=%d\n", sumB);

    printf("%d\n", (sumA == b && sumB == a) ? 1 : 0);   /* 两个方向都要判 */
    return 0;
}
```

### 题目二 · 模拟鼠标点击窗口

**考查**：模拟 + 顺序表（「被点窗口提到最前」） ｜ **代码**：`2015_2_windows.c`

**手搓要点（C89）**

- **结构**：`static int ord[MAXN];` 当"从上到下"的**顺序表**，里面存**下标**（业务数据一个都不搬）—— `ord[0]` 就是最上层（模板 C-2）。
- **提到最前**：`tmp = ord[hit]; for (k=hit;k>0;k--) ord[k] = ord[k-1]; ord[0] = tmp;` —— 本质是"数组整体后移一格 + 插到头部"，比链表好写也不容易错。
- **等价链表版**：`static int nx[MAXN];` 静态单链表，摘结点 `nx[pre] = nx[b]`、接表头 `nx[b] = head; head = b;`（指南用的就是这版 two pointers）。
- **命中判定**：注意 y 是**左上角大**，闭区间四个不等号 `px>=lx && px<=rx && py>=ry && py<=ly`。
- 输出 `for (k=0;k<n;k++) printf("%d ", id[ord[k]]);` —— 空格写进格式串，天然满足"每个 ID 后面都有空格"。

**题目**

输入 `n` 个窗口，每行「**ID 右下角 x 右下角 y 左上角 x 左上角 y**」（坐标以屏幕**左下角为原点**；**先输入的窗口叠在上层**）；再输入 `m` 次点击坐标。每次点击：**从最上层往下**找**第一个包含该点的窗口**（**边框也算**）并把它**提到最上层**（点到桌面 / 本来就最上层则不动）。最后从上到下输出所有窗口 ID，**每个 ID 后面都有一个空格**，末尾换行。

**样例**

```
输入：
2
1 5 1 1 5
2 7 1 3 5
3
1 2
4 3
6 4
输出：2 1␣

输入：
3
3 5 1 1 4
4 7 3 3 6
2 8 2 4 5
3
5 3
8 4
4 4
输出：2 3 4␣
```

> 输出行末那**一个空格是必须的**（`2 1 `），题面写明「每个 ID 的后面都有一个空格」；md 里保留不了行尾空格。

**思路**

- 坐标范围：x ∈ `[lx, rx]`、y ∈ `[ry, ly]`（**左上角纵坐标更大**），闭区间。命中判断一行搞定。
- 用 `ord[0..n-1]` 表示**从上到下**的窗口下标（初始就是输入顺序），点击时**从 `ord[0]` 往下扫**，找到第一个命中的下标 `k`，`k > 0` 时把它搬到 `ord[0]`（前面元素整体后移）。
- 关键理解：**点的判定从最上层开始**，第一个命中的就是被点到的窗口——这样**不用单独处理窗口重叠**。
- 输出用一个循环 `for (k = 0; k < n; k++) printf("%d ", id[ord[k]]);` 再 `putchar('\n')`，行尾空格天然满足。
- （换个思路就是链表：把命中的结点摘下来接到表头，指南用的静态链表 + two pointers。数组搬移在这个规模下更短。）

**伪代码**

```
读 n 个窗口，ord[i] = i                      // 下标越小越靠上
for 每次点击 (px, py):
    hit = -1
    for k = 0 .. n-1:                        // 从上往下
        j = ord[k]
        if lx[j] <= px <= rx[j] 且 ry[j] <= py <= ly[j]: hit = k；跳出
    if hit > 0:                              // 命中且不是最上层 → 提到最前
        把 ord[hit] 取出，ord[0..hit-1] 整体后移一格，取出的放 ord[0]
for k = 0 .. n-1: 输出 id[ord[k]] 和一个空格
换行
```

**代码**

```c
/* 2015 年北航复试上机 题目二：模拟鼠标点击窗口
 * 考点：模拟 + 顺序表（“把被点窗口提到最前”用数组搬移）
 * 输入 n，接着 n 行「ID 右下x 右下y 左上x 左上y」（先输入的在上层）
 *      再输入 m，接着 m 行点击坐标
 * 每次点击：从最上层往下找第一个包含该点的窗口（边框也算，即闭区间），
 *           命中则把它提到最上层（点到桌面或本来就最上层则什么都不做）
 * 输出：最终从上到下的窗口 ID，每个 ID 后跟一个空格，末尾换行
 */
#include <stdio.h>

#define MAXN 10005

static int id[MAXN], rx[MAXN], ry[MAXN], lx[MAXN], ly[MAXN];
static int ord[MAXN];                 /* ord[0] 是最上层窗口的下标 */

int main(void) {
    int n, m, i, k, px, py, hit, tmp;

    if (scanf("%d", &n) != 1) return 0;
    for (i = 0; i < n; i++) {
        scanf("%d %d %d %d %d", &id[i], &rx[i], &ry[i], &lx[i], &ly[i]);
        ord[i] = i;                   /* 下标越小越靠上（先输入的在上） */
    }
    scanf("%d", &m);
    for (i = 0; i < m; i++) {
        scanf("%d %d", &px, &py);
        hit = -1;
        for (k = 0; k < n; k++) {     /* 从上往下扫，第一个命中的就是被点的那个 */
            int j = ord[k];
            if (px >= lx[j] && px <= rx[j] && py >= ry[j] && py <= ly[j]) { hit = k; break; }
        }
        if (hit > 0) {                /* 命中且不是最上层：搬到最前 */
            tmp = ord[hit];
            for (k = hit; k > 0; k--) ord[k] = ord[k - 1];
            ord[0] = tmp;
        }
    }
    for (k = 0; k < n; k++) printf("%d ", id[ord[k]]);
    putchar('\n');
    return 0;
}
```

### 题目三 · 统计词语

**考查**：字符串扫描 + 去重 + 字典序排序（**EOF 多点输入**） ｜ **代码**：`2015_3_words.c`

**手搓要点（C89）**

- **结构**：`static char w[MAXW][MAXL];` 直接当"字符串的数组"，`nw` 当长度；去重就是收词之前线性 `strcmp` 扫一遍（模板 C-10）。
- **排字符串的 `qsort`**：元素本身是 `char[105]`，传进比较器的正好是它的地址，也就是 `const char *`，所以 `return strcmp((const char *)A, (const char *)B);` —— **不用再解一层**。
- **逐行读 + EOF**：`while (fgets(line, sizeof line, stdin) != NULL)`；`static char line[100005]` 放静态区。终端里手动喂 EOF 是 **Ctrl+D**（macOS / Linux）。
- ⚠️ **满表要在写之前挡**：`if (nw >= MAXW - 1) continue;`，否则输入超量直接越界（这个坑踩过）。
- ⚠️ 连续非字母之间**不要插入空串**，否则会输出空行。

**题目**

输入一段含标点的英文语段（**若干行，到 EOF 结束**，命令行里按 Ctrl+Z / Ctrl+D），保证每行单词完整、不会被换行切开、字母全是小写。输出这段话中出现的**所有不同单词**，按**字典序**，每行一个。

**样例**

```
输入：
we are family.
you and me are family, you are my sister.
输出：
and
are
family
me
my
sister
we
you
```

**思路**

- `while (fgets(...) != NULL)` 逐行读、读到 EOF；每行里扫**连续的 `[a-z]`** 作为一个单词（标点、空格自然成了分隔符）。
- **别收空单词**：连续非字母之间不能插入空串，否则会输出空行（指南自测用例 2 专门卡这个）。
- 去重：收到一个新词时在表里线性查一遍（词数 ≤ 1000，够快）；再统一 `qsort` 按 `strcmp` 排序。
- **多点输入**：这题是 15 年考的 EOF 例子，提醒「读文件到末」和「多组数据要清空」这件事。
- 注意：`line` 缓冲要放**静态区**（每行长度可达 100000），别放栈上。

**伪代码**

```
nw = 0
while fgets 一行（EOF 结束）:
    i = 0
    while i < 行尾:
        跳过非小写字母
        读取一段连续小写字母 → 词 w
        若 w 不在表中: 收入表；nw++
按字典序排序 w[0..nw-1]
逐行输出
```

**代码**

```c
/* 2015 年北航复试上机 题目三：统计词语
 * 考点：字符串扫描 + 去重 + 字典序排序（多点输入，读到 EOF）
 * 输入：若干行英文语段（到 EOF 结束）；单词只由小写字母组成，且不会被换行切开
 * 输出：所有不同的单词按字典序，每行一个
 */
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

#define MAXW 5005      /* 单词总数 <= 1000（留足余量，满了就不再收） */
#define MAXL 105       /* 单词长度 <= 100 */

static char w[MAXW][MAXL];
static int nw = 0;

static int cmp(const void *A, const void *B) {
    return strcmp((const char *)A, (const char *)B);
}

int main(void) {
    static char line[100005];      /* 每行 <= 100000 字符，必须放静态区 */
    int i, k, j, dup;

    while (fgets(line, sizeof line, stdin) != NULL) {
        int len = (int)strlen(line);
        i = 0;
        while (i < len) {
            while (i < len && !(line[i] >= 'a' && line[i] <= 'z')) i++;   /* 跳过非字母 */
            if (i >= len) break;
            k = 0;
            while (i < len && line[i] >= 'a' && line[i] <= 'z' && k < MAXL - 1)
                w[nw][k++] = line[i++];                                   /* 取下一个单词 */
            w[nw][k] = '\0';
            if (nw >= MAXW - 1) continue;   /* 表满就丢弃后面的词，别越界 */
            dup = 0;
            for (j = 0; j < nw; j++) if (strcmp(w[j], w[nw]) == 0) { dup = 1; break; }
            if (!dup) nw++;                 /* 没有出现过才收下 */
        }
    }

    qsort(w, nw, sizeof w[0], cmp);
    for (i = 0; i < nw; i++) printf("%s\n", w[i]);
    return 0;
}
```
