# C2-G题解

## Alex 和 Marvolo 不会出题了 - 3

### 1.题意

一共有 n(1≤n≤10^6)n(1≤n≤10^6) 个节目，分别在不同的电台上播放，给定每个节目的起始时间和结束时间 si,ei,(1≤si,ei≤10^5),假设时间无限，求最多能看的节目数。

### 2.分析

这是一个典型的贪心算法问题， 贪心算法（又称贪婪算法）是指，在对问题求解时，总是做出在当前看来是最好的选择。也就是说，不从整体最优上加以考虑，他所做出的仅是在某种意义上的局部最优解。贪心算法不是对所有问题都能得到整体最优解，但对范围相当广泛的许多问题他能产生整体最优解或者是整体最优解的近似解。

显然，只要先看结束时间早的节目，就能为后面看节目留下更多的时间，因此贪心算法得到的就是最优解。

代码思路如下，建立结构体，结构体有两个整型变量，分别储存节目的起始时间和结束时间，申请结构体数组a，将数据输入，再以节目的结束时间为关键字对数组进行快速排序。接下来再遍历数组，若当前节目的起始时间大于刚看完的上一个节目的结束时间，则计数器加一，并更新结束时间。

快速排序时间复杂度O(nlog<sub>2</sub>n)，遍历数组时间复杂度O(n)，因此该算法的时间复杂度为O(nlog<sub>2</sub>n)。

### 3.代码

```
#include <stdio.h>
#include <stdlib.h>
struct node{
	int st;
	int ed;
};
int cmp(const void *a ,const void *b)
{
	struct node* pa=(struct node*)a;
	struct node* pb=(struct node*)b;
	if(pa->ed!=pb->ed)
		return pa->ed-pb->ed;
	return pb->st-pa->st;
}
int main(int argc, char *argv[]) {
	int n, i, end;
	int ans=0;
	scanf("%d",&n);
	struct node* a=(struct node*)malloc(n*sizeof(struct node));
	for(i=0;i<n;i++)
	{
		scanf("%d %d",&a[i].st,&a[i].ed);
	}
	qsort(a,n,sizeof(a[0]),cmp);
	end=a[0].ed;
	ans++;
	for(i=1;i<n;i++)
	{
		if(a[i].st>=end)
		{
			ans++;
			end=a[i].ed;
		}
	}
	printf("%d\n",ans);
	return 0;
}
```
