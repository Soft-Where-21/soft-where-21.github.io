## 题目分析

首先思考某个地块有水的条件是它左边的最高地块和右边的最高地块比它要高，积水数量为左右最高地块的较小值减去当前地块的高度。为了防止时间复杂度过大，先预处理一下左边最大值和右边最大值数组，最终时间复杂度为$O(n)$

## 代码

```c++
#include<stdio.h>
#include<algorithm>
#include<cmath>
#include<string>
#include<string.h>
#include<ctype.h>
#include<stdlib.h>
#define rep(i,st,en) for(int i=st;i<=en;i++)
typedef long long ll;
using namespace std;
int n,a[2000010],max_le[2000010],max_ri[2000010];
ll ans;
int main()
{ 
	scanf("%d",&n);
	rep(i,1,n)
	{
		scanf("%d",&a[i]);
		max_le[i]=max(max_le[i-1],a[i]); 
	}
	for(int i=n;i>=1;i--)
	{
		max_ri[i]=max(max_ri[i+1],a[i]);
	}
	rep(i,1,n)
	{
		int minn=min(max_le[i],max_ri[i]);
		if(a[i]>=minn)
			continue;
		ans+=minn-a[i];
	}
	printf("%lld",ans);
	return 0;
}
```
