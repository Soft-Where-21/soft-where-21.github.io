## 题解思路

由于想要避免运算过程中的溢出，我们建立一个1000003的数组tab，用来存前1000003个数据的卡特兰数。

在main函数中初始化，tab[1]=1,tab[2]=2,tab[3]=5，其余全为0。

而在cal函数中，采用递归，若tab[n]不等于0，即为已经得到了n的卡特兰数，直接输出。若为0，则进行递归：

若n<1000003,则递归中心式为

tab[a] = cal(a - 1) * (4 * a - 2) / (a + 1);

*return* cal(a - 1) * (4 * a - 2) / (a + 1);

其他情况

*return* cal(a - 1) * (4 * a - 2) / (a + 1);

再进行打印，题解完成。
