# 数据库

### 数据库系统特点

1. 数据结构化

2. 数据共享

3. 数据独立性

   1. 物理独立性

      是指修改数据库的物理存储模式而不必重写应用程序的能力。有时为了提高系统的性能等原因，偶尔会在数据库的物理层做一修改（比如将数据从光盘上挪到磁盘上），物理独立性可以使应用程序不受影响。

   2. 逻辑数据独立性

      是指修改数据库的逻辑模式而不必重写应用程序的能力。当数据库的逻辑结构发生了变化，逻辑层就需要做一些修改，但可以控制这种修改带来的影响，尽量使应用程序保持稳定

4. 方便的用户接口

   1. 通过标准化的非过程式语言SQL，很方便的操纵数据库

      数据定义语言（DDL） 

      数据查询语言（DQL）

      数据操纵语言（DML） 

      数据控制语言（DCL）

      综合统一，处理数据库所有事务

   2. 交互式和嵌入式相结合

      1. 独立使用：联机交互的方式，直接操作数据库
      2. 嵌入式：可以嵌入到高级编程语言中，使得应用程序能够操作数据库

5. 统一的数据管理与控制功能

   1. 数据的完整性

      数据的完整性指数据的正确性、有效性和相容性。实际上，是指数据库中的数据应与现实世界中的实际情况相符。为了保证DB的正确性，要使用数据库系统提供的存取方法设计一些完整性规则，对数据值进行校验。

   2. 数据的安全性

      1. 主动安全

         有效地防止数据库中的数据被非法使用或非法修改

      2. 被动安全

         数据遭到破坏时能立刻将数据完全恢复

   3. 并发控制

      当多个用户同时存取、修改DB中的数据时，可能会发生相互干扰，使DB中数据的完整性受到破坏，而导致数据的不一致性。DB的并发控制防止了这种现象的发生，提高了DB的利用率

### 范式

1NF：同一列中不能有多个值

2NF：在 1NF 基础上消除非主属性的**部分函数依赖**

3NF：在 2NF 基础上消除非主属性的**传递函数依赖**

BCNF：在 1NF 基础上消除任何属性（主属性或非主属性）对键的部分函数依赖和传递函数依赖
